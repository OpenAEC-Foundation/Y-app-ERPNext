# Donner son avis

Objectif : signaler une erreur ou transmettre une idée, éventuellement avec une capture d'écran, afin qu'elle devienne une issue sur GitHub.

## Quand en avez-vous besoin

Le planning calcule quelque chose que vous ne comprenez pas, un bouton ne fait pas ce qu'il doit faire, ou il vous manque quelque chose dans l'application. Un bon signalement aide les développeurs à trouver le problème. C'est pourquoi l'application ajoute elle-même la version, le système d'exploitation et la langue à votre signalement. Ce que vous décrivez vous-même décide s'ils peuvent en faire quelque chose : ce que vous avez fait, ce que vous attendiez et ce qui s'est passé.

## Étapes

1. Cliquez sur le bouton *Donner mon avis* en haut de la fenêtre. Ce bouton se trouve toujours dans la barre de titre. Son texte change toutes les dix minutes : *Donner mon avis*, *Signaler un bug* et *Proposer une nouvelle fonctionnalité*. C'est toujours le même bouton. La fenêtre *Envoyer un commentaire* s'ouvre.
2. Choisissez *Bug* pour quelque chose qui ne fonctionne pas comme il le devrait, ou *Demande de fonctionnalité* pour une idée. *Bug* est sélectionné par défaut.
3. Remplissez le champ *Titre*. Sans titre, le bouton *Envoyer à GitHub* est gris. Remplissez aussi la *Description*, par exemple : quelle tâche vous avez modifiée, ce que vous attendiez et ce que vous avez vu.
4. Si vous voulez montrer quelque chose, activez *Joindre une capture d'écran*. L'application prend alors une image de l'application, sans cette fenêtre. Un instant plus tard, vous voyez un petit aperçu. Avec *Annoter*, un éditeur s'ouvre dans lequel vous placez des flèches, des rectangles, des traits libres et du texte sur l'image. Là, vous choisissez la couleur, annulez votre dernière action avec *Annuler* ou recommencez avec *Tout effacer*. Cliquez sur *Terminé* quand le résultat vous convient.
5. Cliquez sur *Envoyer à GitHub*.
6. Vous n'avez pas joint de capture d'écran ? Alors la page GitHub sur laquelle vous créez une nouvelle issue s'ouvre tout de suite dans votre navigateur. Continuez à l'étape 8.
7. Vous avez joint une capture d'écran ? Alors vous voyez d'abord *Presque terminé — votre capture d'écran est dans le presse-papiers.* avec quatre étapes. Cliquez sur *OK, aller sur GitHub*, cliquez dans la grande zone de texte de la page de l'issue et appuyez sur Ctrl+V (Cmd+V sur un Mac). L'image est envoyée et apparaît dans le texte.
8. En bas de la page de l'issue, cliquez sur *Soumettre une nouvelle issue*. Ce n'est qu'alors que votre signalement est envoyé. Connectez-vous à GitHub si ce n'est pas déjà fait.

Sur la page de l'issue, votre titre et votre description sont déjà remplis. L'application propose le libellé *bug* ou *enhancement* et ajoute une ligne sous votre description avec le type, la version d'Open Planner Studio, votre système d'exploitation et la langue de l'application.

## Pièges et ce que fait l'application dans ce cas

**L'application n'envoie rien toute seule.** *Envoyer à GitHub* ouvre seulement la page de l'issue, déjà remplie. Si vous fermez cette page sans cliquer sur *Soumettre une nouvelle issue*, rien n'a été signalé. Pour cela, vous avez besoin d'un compte GitHub.

**Votre signalement se retrouve sur GitHub.** N'y mettez aucune information que vous ne voulez pas partager. Cela vaut aussi pour la capture d'écran : l'image montre tout ce qui est visible dans l'application à ce moment-là, comme les noms de tâches et les ressources de votre projet. L'application prend la capture au moment où vous activez *Joindre une capture d'écran*. Vérifiez donc que l'écran est correct avant de l'activer, et masquez ce que vous ne voulez pas montrer.

**Le collage ne fonctionne pas.** La capture d'écran est aussi enregistrée comme fichier sur votre ordinateur. Dans l'application de bureau, la fenêtre indique le chemin : *Impossible de coller ? Nous avons aussi enregistré la capture d'écran dans* ce chemin *— faites glisser ce fichier dans la zone de texte.* Dans le navigateur, l'application télécharge l'image sous le nom `feedback-` suivi d'un numéro et de l'extension `.png`. Vous la trouvez dans votre dossier de téléchargements et vous la faites glisser dans la zone de texte.

**La capture d'écran échoue.** Le message *La capture d'écran a échoué. Vous pouvez toujours envoyer un commentaire sans capture d'écran.* s'affiche. La case se décoche et vous pouvez envoyer votre signalement sans image.

**Vous avez beaucoup écrit et cliquez à côté de la fenêtre par erreur.** Cela ne ferme pas la fenêtre, donc votre texte reste. Échap ou *Annuler* ferme la fenêtre, et alors votre texte est perdu.
