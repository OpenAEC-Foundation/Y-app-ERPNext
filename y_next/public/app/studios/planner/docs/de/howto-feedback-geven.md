# Feedback geben

Ziel: einen Fehler melden oder eine Idee weitergeben, optional mit einem Screenshot, damit daraus ein Issue auf GitHub wird.

## Wann Sie dies brauchen

Der Terminplan berechnet etwas, das Sie nicht verstehen, eine Schaltfläche tut nicht, was sie tun soll, oder Ihnen fehlt etwas in der App. Eine gute Meldung hilft den Entwicklern, das Problem zu finden. Darum fügt die App selbst die Version, das Betriebssystem und die Sprache in Ihre Meldung ein. Was Sie selbst beschreiben, entscheidet, ob die Entwickler damit etwas anfangen können: was Sie getan haben, was Sie erwartet haben und was passiert ist.

## Schritte

1. Klicken Sie oben im Fenster auf die Schaltfläche *Feedback geben*. Diese Schaltfläche steht immer in der Titelleiste. Ihr Text wechselt alle zehn Minuten: *Feedback geben*, *Einen Fehler melden* und *Neue Funktion vorschlagen*. Es ist immer dieselbe Schaltfläche. Das Fenster *Feedback geben* öffnet sich.
2. Wählen Sie *Fehler* für etwas, das nicht so funktioniert, wie es soll, oder *Funktionswunsch* für eine Idee. *Fehler* ist standardmäßig ausgewählt.
3. Tragen Sie den *Titel* ein. Ohne Titel ist die Schaltfläche *An GitHub senden* grau. Tragen Sie auch die *Beschreibung* ein, zum Beispiel: welchen Vorgang Sie geändert haben, was Sie erwartet haben und was Sie gesehen haben.
4. Wenn Sie etwas zeigen wollen, schalten Sie *Screenshot anhängen* ein. Die App macht dann ein Bild der App ohne dieses Fenster. Kurz danach sehen Sie eine kleine Vorschau. Mit *Anmerken* öffnet sich ein Editor. Darin setzen Sie Pfeile, Rechtecke, Freihandlinien und Text auf das Bild. Dort wählen Sie die Farbe. Mit *Rückgängig* nehmen Sie Ihre letzte Aktion zurück, oder Sie beginnen neu mit *Alles löschen*. Klicken Sie auf *Fertig*, wenn Sie zufrieden sind.
5. Klicken Sie auf *An GitHub senden*.
6. Haben Sie keinen Screenshot angehängt? Dann öffnet sich sofort die GitHub-Seite, auf der Sie ein neues Issue erstellen, in Ihrem Browser. Fahren Sie mit Schritt 8 fort.
7. Haben Sie einen Screenshot angehängt? Dann sehen Sie zuerst *Fast fertig — Ihr Screenshot ist in der Zwischenablage*, mit vier Schritten. Klicken Sie auf *OK, zu GitHub*, klicken Sie im großen Textfeld der Issue-Seite und drücken Sie Strg+V (Cmd+V auf dem Mac). Das Bild wird hochgeladen und erscheint im Text.
8. Klicken Sie unten auf der Issue-Seite auf *Neues Issue absenden*. Erst dann ist Ihre Meldung gesendet. Melden Sie sich bei GitHub an, falls Sie das noch nicht getan haben.

Auf der Issue-Seite sind Ihr Titel und Ihre Beschreibung schon ausgefüllt. Die App schlägt das Label *bug* oder *enhancement* vor und setzt eine Zeile unter Ihre Beschreibung. Diese Zeile enthält den Typ, die Version von Open Planner Studio, Ihr Betriebssystem und die Sprache der App.

## Fallen und was die App dann tut

**Die App sendet nichts von selbst.** *An GitHub senden* öffnet nur die Issue-Seite, schon ausgefüllt. Wenn Sie diese Seite schließen, ohne auf *Neues Issue absenden* zu klicken, ist nichts gemeldet. Dafür brauchen Sie ein GitHub-Konto.

**Ihre Meldung landet auf GitHub.** Schreiben Sie nichts hinein, was Sie nicht teilen wollen. Das gilt auch für den Screenshot: Das Bild zeigt alles, was in diesem Moment in der App sichtbar ist, zum Beispiel Vorgangsnamen und Ressourcen Ihres Projekts. Die App macht den Screenshot in dem Moment, in dem Sie *Screenshot anhängen* einschalten. Prüfen Sie also, was auf dem Bildschirm zu sehen ist, bevor Sie das tun, und lassen Sie weg, was Sie nicht zeigen wollen.

**Einfügen funktioniert nicht.** Der Screenshot wird auch als Datei auf Ihrem Computer gespeichert. In der Desktop-App nennt das Fenster den Pfad: *Einfügen funktioniert nicht? Wir haben den Screenshot auch unter* diesem Pfad *gespeichert — ziehen Sie diese Datei in das Textfeld.* Im Browser lädt die App das Bild als `feedback-` mit einer Nummer und der Endung `.png` herunter. Sie finden es in Ihrem Downloads-Ordner und ziehen es in das Textfeld.

**Der Screenshot schlägt fehl.** Das Fenster zeigt: *Screenshot-Erstellung fehlgeschlagen. Sie können Feedback trotzdem ohne Screenshot senden*. Das Kontrollkästchen wird ausgeschaltet, und Sie können Ihre Meldung ohne Bild senden.

**Sie haben viel geschrieben und klicken versehentlich neben das Fenster.** Das schließt das Fenster nicht, Ihr Text bleibt also erhalten. Mit Esc oder *Abbrechen* schließen Sie es. Dann ist Ihr Text weg.
