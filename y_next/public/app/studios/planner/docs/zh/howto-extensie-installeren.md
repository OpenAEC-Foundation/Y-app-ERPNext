# 安装和管理扩展

目标：安装扩展，阅读权限询问，之后可以禁用或移除该扩展。

## 何时需要此操作

扩展可以在无需等待新版本的情况下为应用添加功能。例如，扩展可以添加一种导入格式，它会出现在 *文件 › 导入* 中，也可以在功能区中放置按钮，或为 PDF 导出提供字体。官方目录将扩展分为以下类别：*导入/导出*、*计划*、*报表*、*实用工具*、*字体* 和 *其他*。

安装前请仔细考虑。扩展是与应用本身拥有相同权限运行的程序代码，应用无法对其加以限制。因此，应用会在每次安装时请求你的许可。你在该询问中看到的内容，下文有所说明。

## 步骤

### 从目录安装扩展

1. 选择 *文件 › 扩展*。
2. 选择选项卡 *浏览*。应用在显示 *正在加载目录...* 时获取目录。目录内容由维护它的 OpenAEC 基金会决定，内容可能会变化。
3. 使用 *搜索扩展...* 字段搜索扩展。搜索范围包括名称、描述、作者和标签。
4. 每张卡片显示名称、版本、类别、描述和作者。点击 *安装*。
5. 窗口 *安装扩展？* 会打开。请阅读该窗口，然后看下一步。
6. 点击 *安装* 继续。点击 *不安装* 则什么都不会发生。按 Esc 键或点击窗口外部同样视为拒绝，此时应用不显示错误消息。

安装后，扩展会立即启用。在 *浏览* 中的卡片上，现在会显示 *已安装*。扩展添加的内容会显示在应用中：功能区中的新按钮，或 *文件 › 导入* 中的导入格式。部分扩展还会显示消息。这类消息以 *扩展* 为前缀，后面是该扩展的名称。

### 从文件安装扩展

如果你收到的是文件形式的扩展，请按以下方式安装。

1. 选择 *文件 › 扩展*。
2. 在右上角，ZIP 文件请点击 *ZIP*，单独的 JavaScript 文件请点击 *JS*。
3. 选择文件。如上所述，会打开 *安装扩展？* 窗口。

ZIP 文件必须包含 `manifest.json` 和扩展的主文件。如果你要安装的扩展已经安装过，新版本会替换旧版本。如果应用无法安装该文件，例如因为 ZIP 文件已损坏，则什么都不会发生：应用对 ZIP 和 JS 不显示错误消息，扩展也不会出现在列表中。不过，原因会记录在调试终端中。在 *设置 › 项目 › 设置* 中打开选项卡 *高级*，启用 *启用调试终端*，然后点击状态栏中的按钮 *显示调试终端* 即可打开它。例如，其中会显示 *[Extensies] ZIP-installatie mislukt: Error: Geen manifest.json gevonden in ZIP*（应用中此技术文本为荷兰语）。

### 阅读权限询问

该询问显示你需要决定的内容。

- *作者*和*代码仓库*说明扩展的作者，以及源代码位于何处。
- *来源*说明文件来自何处：*来自在线扩展目录*、*来自本机的 ZIP 文件* 或 *来自本机的 JavaScript 文件*。其下方说明文件是否已经过检查。对于目录中的扩展，会显示 *已使用目录中的校验和验证此次下载。* 如果目录未提供校验和，会以红色显示 *目录未提供校验和——本次下载未经验证。* 对于你自己选择的文件，会显示 *此文件由你自行选择；没有外部来源可供校验。*
- *你同意的内容*说明：*扩展是与 Open Planner Studio 本身拥有相同权限运行的程序代码，没有任何机制加以限制。请只安装你信任其作者的扩展。* 其下方说明这对你的平台意味着什么。在桌面应用中，会显示 *在桌面应用中，这包括：读写你用户目录下任意位置的文件，以及访问你的项目、设置和剪贴板。* 在浏览器中，会显示 *在浏览器中，这意味着：访问你已保存的项目和设置、你已授权的文件，以及网络。*
- *此扩展声明会使用的功能*以小标签的形式显示作者声明的权限。这是作者的声明，而不是限制：*这是作者的声明，而非限制——代码无论如何都能做得更多。* 如果没有标签，会显示 *未声明任何内容。* 这并不表示扩展什么都做不了：即使没有标签，扩展也能读取和更改你的计划数据，并显示消息。

这些标签的含义如下：

- *功能区*：扩展会在功能区中放置按钮。
- *事件*：扩展会监听应用中的事件。
- *后台视图*：扩展会在 *文件 › 导入* 中添加导入格式。
- *pdf-fonts*：扩展为 PDF 导出提供字体。
- *importSource*：扩展可以读取你导入的每个文件的完整原始字节，例如原始的 Primavera 文件，包括未进入项目的字段。窗口本身也会说明这一点。
- *help*：扩展可以添加帮助文章、将随附的项目作为新文档打开，并显示指向应用各部分的指南。窗口本身也会说明这一点。
- *filesystem* 和 *network*：这些只是作者意图的指示。应用没有对应的功能。

### 禁用、重新启用或移除扩展

1. 选择 *文件 › 扩展*，然后选择选项卡 *已安装*。每个扩展都有一张卡片，显示名称、版本、类别、描述和作者。
2. 通过卡片上的开关，你可以禁用扩展（*禁用*），或重新启用扩展（*启用*）。禁用后，扩展添加的按钮和导入格式会消失，但扩展仍保持安装。重启应用后，它也保持禁用。已启用的扩展会在应用启动时自动启动。
3. 点击 *移除*。按钮会变为 *确认*，并显示说明 *再次点击以永久移除*。再点击一次即可移除扩展。应用也会清理该扩展保存的设置。

## 常见问题及应用的处理方式

**目录无法加载。** 会显示 *无法加载目录：*，后面是技术原因，并显示按钮 *重试*。这可能是因为你没有网络连接。

**目录中某张卡片下方显示 *安装失败*。** 下载或安装失败，例如校验和不符。此时没有安装任何内容。这与拒绝安装不同：拒绝时不会显示错误消息。

**列表上方显示 *已跳过目录项：1*。** 目录中包含应用无法使用的项目。你可以照常安装其他扩展。

**扩展无法启动。** 卡片会显示错误消息，例如扩展需要更新版本的 Open Planner Studio（并显示你当前的版本），或扩展本身给出的错误。此时扩展不会处于活动状态。请更新应用，或移除该扩展。

**卡片上显示 *隔离*。** 应用无法使用已保存的扩展。名称下方会显示 *原因：* 及其原因。点击 *从存储中移除* 即可清理。

**自行编写扩展。** 扩展作者指南（manifest、API、权限）位于 GitHub 上的代码仓库 `OpenAEC-Foundation/open-planner-studio` 中，文件为 `docs/extensions.md`。

**扩展不属于某个项目。** 扩展保存在应用中：在桌面应用中保存在这台电脑上，在浏览器中保存在该浏览器的存储里。它们适用于你的所有项目，不属于项目文件。如果你清除浏览器中的网站数据，扩展也会消失。
