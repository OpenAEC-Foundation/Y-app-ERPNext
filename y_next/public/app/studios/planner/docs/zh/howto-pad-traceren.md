# 路径追踪

目标：让任务之前或之后的任务链可见，这样你就能看到是什么决定了某个任务的日期，以及任务延迟时哪些任务会随之移动。

## 何时需要这个功能

屋顶工程要等三周后才开始，你想知道是哪个任务决定了这个日期。或者砌砖工晚了一周，你想看看其后哪些任务会随之移动。在有几十条关系的计划中，只看连线你无法看出这一点。使用**路径追踪**，应用会给所有**前置任务**（位于所选任务之前的任务，直接或通过其他任务）和**后续任务**（位于其之后的任务）上色，并将其余任务变暗。

## 步骤

1. 选择要查看其路径的任务。你可以在任务表中选择，也可以点击 Gantt 中的任务条。如果你选择了多个任务，应用会从你最先选择的那个任务开始追踪。
2. 选择 *计划 › 路径追踪 › 前置任务*，查看位于该任务之前的所有任务。或者选择 *计划 › 路径追踪 › 后续任务*，查看位于其之后的所有任务。两个按钮可以同时开启。同样的两个按钮也位于 *表格* 选项卡的 *路径追踪* 组中。
3. 如果你想一次查看两个方向，请在 Gantt 或任务表中右键点击任务，然后选择 *追踪路径*。
4. 在 Gantt 和任务表中查看结果。下文说明如何解读结果。
5. 再次点击已开启的按钮即可停止追踪。你也可以右键点击任务并选择 *停止路径追踪*，或按 Esc。Esc 还会清除选择。

如果你在追踪时选择了另一个任务，路径会跟随新的选择。

## 解读结果

- 前置任务为金色，后续任务为紫色。在 Gantt 中，任务条会变色。在任务表中，行的左侧会出现一条色条：前置任务为实线，后续任务为虚线。所选任务有轮廓。
- 颜色更深的部分（在任务表中为更粗的色条并加粗文字）标出**驱动关系**链，即真正决定日期的关系。其含义在 [关系与延隔](docs://uitleg-relaties) 中说明。
- 路径之外的所有任务都会变暗。不属于该路径的关系线颜色较淡，并显示为点线。

## 常见问题与应用的行为

**没有选择任务。** 没有选中任务时就无法追踪。按钮已开启，但屏幕上不会有任何变化。请先选择一个任务。

**驱动关系链没有突出显示。** 突出显示基于上一次计算的结果。如果计划尚未计算，或计算出错，应用会将所有前置任务和后续任务同样强度地着色。请按 **计算**（F5），例如通过 *首页 › 进度 › 计算*，然后再次查看路径。只要状态栏显示 *已过期 — 请重新计算（F5）*，突出显示就仍基于之前的计算结果。

**阶段上的关系。** 追踪会沿着你建立的关系进行。与阶段（摘要任务）相连的关系，连接的是阶段本身。在计算中，该关系适用于阶段内的每个任务，但路径不会继续延伸到阶段内部的任务。如果你追踪的是某个阶段内的任务，而该阶段通过阶段本身的关系与另一任务相连，那么你就看不到这条关系。这时请直接选择阶段本身。

**只显示所选方向。** 如果只开启了 *前置任务*，你就看不到该任务之后的内容，反之亦然。
