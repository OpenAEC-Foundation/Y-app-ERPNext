# 开启自动保存

目标：让应用在你工作时更新项目文件，这样你就不必一直按 Ctrl+S。

## 何时需要

你长时间处理同一个计划，或者经常忘记保存，并且希望磁盘上或共享文件夹中的文件能及时跟上。自动保存不能替代崩溃恢复：崩溃恢复始终开启，与此功能分开工作。两者有何区别，请阅读[文件和格式](docs://uitleg-bestanden)。

## 步骤

1. 如果项目还没有文件，请先用 *首页 › 文件 › 另存为* 保存一次。只要没有文件，开关就是灰色的，提示文字是：*请先保存此项目，然后才能使用自动保存。*
2. 在顶部栏的左上角，点击 *自动保存* 开关。开启后，提示文字是：*自动保存已开启：更改将写入此文件。*
3. 继续工作。项目一有更改，应用就会将其写入你的文件，无需弹出窗口，且最多每十秒写入一次。之后，*未保存* 标记会自动消失。
4. 如果你想停止，再点击一次开关。提示文字随后是：*自动保存已关闭。崩溃恢复仍保持启用。*

Chrome 和 Edge 一开始只允许你读取打开的文件。在你用 *保存*（Ctrl+S）保存一次，并且浏览器已授予写入权限之前，开关在这些浏览器中不起作用。之后你就可以开启它。在 Firefox 中，开关始终是灰色的：应用无法写入该处的文件。

## 注意事项，以及应用此时的行为

**开关只属于一个项目。** 每个标签页都有自己的状态。打开项目后，开关总是关闭的，应用不会为下次保留这个设置。

**自动保存只写入项目已有的文件。** 如果你选择 *另存为*，之后它就会写入新文件。应用只在有更改时才写入。

**写入可能失败。** 例如，如果文件已消失或被锁定，会出现消息 *自动保存失败*，并附上原因。如果浏览器没有（或不再有）写入权限，应用会静默跳过该次写入：它不会请求权限。

**文件也会得到你不想保留的更改。** 自动保存会写入项目当时的状态。如果你用 Ctrl+Z 撤销某个操作，文件也会在十秒内得到撤销后的状态。如果你想保留旧版本，请先用 *另存为* 做一份副本。

**崩溃仍可能丢失最后几秒的工作。** 应用最多每十秒写入一次，因此两次写入之间你所做的操作还不在文件中。崩溃恢复也有同样的限制。

**在浏览器中恢复后，开关又变成灰色。** 崩溃后在浏览器中恢复的项目，不再与其文件相连。请保存一次，开关就会再次可用。请参阅[崩溃后恢复](docs://howto-herstellen-na-een-crash)。

**项目来自其他格式时没有文件。** CSV、XML、`.mpp` 或 `.xer` 文件只有在你保存时才会得到 IFC 文件。之后你就可以开启自动保存。
