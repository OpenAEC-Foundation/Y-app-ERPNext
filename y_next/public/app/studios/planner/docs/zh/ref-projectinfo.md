# 新建项目和项目信息

*新建项目* 窗口和 *项目信息* 的字段：每个字段的作用、默认值，以及它在哪里生效。两者是同一张表单的两个部分。*新建项目* 用于创建新项目，并有几个额外字段。*项目信息* 用于更改你已打开的项目。

## 打开

**新建项目** — *文件 › 新建*、Ctrl+N，或文档标签右侧的加号（*开始项目*，然后 *新建项目*）。窗口打开时，光标位于 *项目名称* 中。

**项目信息** — *设置 › 项目 › 项目信息* 将该表单作为标题为 *项目信息* 的窗口打开。*文件 › 项目信息* 在 *文件* 屏幕中显示同一张表单。*计算配置文件和选项* 块位于两处的底部；其中的内容见 [计算选项和约定](docs://ref-rekenopties-en-conventies)。

## 创建、应用和取消

**创建**（在 *新建项目* 中）会创建项目，并在它自己的标签页中打开。**应用**（在 *项目信息* 中）将你的更改写入项目。

- **仅在应用时生效。** 你在草稿中输入内容。只有点击 *应用* 时，项目才会更改。*应用* 只写入你实际更改的内容，并在 *撤销* 中形成一个步骤。如果你未更改任何内容就点击 *应用*，什么都不会发生，也不会添加步骤。
- **取消、叉号和 Esc** 会关闭窗口，且不保存任何内容。点击窗口旁边不会关闭它：你已输入的内容会保留。
- **Enter** 的作用与 *创建* 或 *应用* 相同，但在 *描述* 字段中以及已展开的下拉列表中除外。
- **在文件屏幕中**，只要草稿与当前设置不同，*项目信息* 底部就会显示 *更改尚未应用——点击“应用”以保留。* 之后如果离开该屏幕，软件会询问你要应用、放弃还是取消。见 [功能区，按标签页说明](docs://ref-lint)。
- **没有名称的自定义计算配置文件** 会阻止 *应用* 和 *创建*。请为它命名，或放弃该更改。

## 两个窗口共有的字段

**项目名称** — 项目在标题栏、标签页上的名称，以及保存时文件名中的名称。默认值：空。允许留空：此时项目称为 *新建计划*，并在字段中以灰色文字显示。位置：整个屏幕。

**描述** — 自由文本。默认值：空。作用：与项目一起保存，写入 IFC 文件，并导出到 Primavera P6 XML，但对计划没有影响。

**作者** — 自由文本。默认值：空。作用：写入 IFC 文件，并在报表页眉中以 *作者：* 的形式显示。你无法在报表中修改它。

**资源库** — 项目关联到哪个资源库。可从 *无(独立项目)*、你现有的资源库和 *+ 新建资源库…* 中选择。默认值：在 *新建项目* 中为默认资源库，在 *项目信息* 中为当前关联。作用：见 [使用资源库](docs://howto-resourcebibliotheek-gebruiken)。使用 *+ 新建资源库…* 时，你在下方的字段中输入名称。资源库只会在点击 *创建* 或 *应用* 时创建，因此取消不会留下任何内容。只有当你自己修改此字段时，*项目信息* 中的关联才会更改。

**客户/组织** — 自由文本。默认值：空。作用：写入 IFC 文件，并在报表页眉中以 *公司：* 的形式显示。

**开始日期** — 项目开始的日期。默认值：在 *新建项目* 中为今天。该字段的作用见下文 *开始日期的作用*。

**结束日期** — 项目计划的结束日期。默认值：空。作用：这是一项信息，而不是要求：软件不会以此日期为目标进行计划。它会出现在报表页眉和导出文件中，并决定假日生成到哪一年。只有对 Primavera 文件并启用了设置 *计算浮时至项目完成日期*（见 [计算选项和约定](docs://ref-rekenopties-en-conventies)）时，浮时计算才会一直运行到此日期。

**新任务的默认单位** — 仅当 *启用小时计划* 开启时可见。可选 *天* 和 *小时*。默认值：*天*。作用和条件：见 [开启小时计划](docs://howto-urenplanning-aanzetten)。

**计算配置文件和选项** — 在 *项目信息* 中是整个块；在 *新建项目* 中只有下拉列表 *计算配置文件*，可选 *Primavera P6*、*Microsoft Project* 和 *Open Planner Studio*。默认值：*Open Planner Studio*。选择配置文件时，也会设置该配置文件的默认选项。见 [计算选项和约定](docs://ref-rekenopties-en-conventies)。

## 只在新建项目窗口中

**阶段模板** — 项目开始时包含哪些阶段。可选 *空白*、*住宅建筑* 和 *公共建筑 / 改造*。默认值：*空白*。作用：*空白* 会创建没有任务的项目。另外两个选项会预先放入八个阶段任务，每个任务的工期为项目默认单位中的 5（5 个工作日；如果在 *新任务的默认单位* 中选择 *小时*，则为 5 小时），且没有关系。你可以自行重命名、移动和延长它们。对于 *住宅建筑*，这些任务是：Bouwplaats & grondwerk、Fundering、Ruwbouw / casco、Dak、Gevel & afbouw、Installaties (W/E)、Afwerking 和 Oplevering。对于 *公共建筑 / 改造*，这些任务是：Sloop & strip-out、Grondwerk & fundering、Hoofddraagconstructie、Gevel & dak、Installaties (W/E)、Afbouw、Inregelen & testen 和 Oplevering。这些名称是项目数据，即使界面语言不同，也保持荷兰语。如果 *启用施工模式* 关闭，则只有 *空白* 可选。见 [设置](docs://ref-instellingen)。

**班次** — 仅当 *启用小时计划* 开启时可见。可选 *白班*、*两班倒*、*三班倒* 和 *24/7*。默认值：*白班*。作用：*白班* 保持标准日历不变，即周一至周五的普通日历。其他三个选项会在项目日历中放入工作时段，与 *日历* 窗口中同名按钮的作用相同。具体时间见 [设置工作时间](docs://howto-werktijden-instellen)。选择 *白班* 时，在 *新任务的默认单位* 下无法选择 *小时*，因为日历没有工作时段。

**假日集** — 项目日历会有哪些假日。在 *国家* 中，你可以选择 *荷兰*（默认）、*德国*、*比利时*、*法国*、*英国*、*奥地利*、*瑞士*、*无假日* 或 *自定义…*。如果该国家有地区，则会添加下拉列表 *地区*。如果开启了 *启用施工模式*，选择荷兰时还要选择 *建筑业假期*：*无*（默认）、*北部*、*中部* 或 *南部*。其下方是一行类似 *36 个假日，2025–2029* 的文字，展开后可查看列表。年份范围从开始日期的前一年到结束日期的后一年；如果没有结束日期，则到开始年份后的三年。*自定义…* 会创建没有假日的日历，并在创建后立即打开 *日历* 窗口，方便你自行填写。项目日历名为 *Bouwkalender NL*；如果 *启用施工模式* 关闭，则名为 *Standaardkalender*。此时的选项还包括 *无假日*。假日生成器的工作方式见 [生成假日和建筑业假期](docs://howto-feestdagen-genereren)。

## 开始日期的作用

开始日期是项目的锚点。三条规则如下：

- **新任务从开始日期开始。** 你添加的任务，其计划的开始日期为项目开始日期。
- **带有前置任务的任务绝不会早于开始日期开始。** 如果前置任务的结束更早，该任务会等到开始日期。*没有*前置任务的任务保留自己的日期，即使该日期早于开始日期。这是为了按来源程序的方式显示 Microsoft Project 或 Primavera 的计划。约束 *必须开始于 (MSO)* 或 *必须完成于 (MFO)* 会打破这两条规则：这类任务停在其日期上，即使该日期早于开始日期。
- **较晚的开始日期会带动独立任务。** 如果你在 *项目信息* 中将开始日期设置得更晚并点击 *应用*，则没有前置任务、且没有下限约束（*不得早于…开始*、*必须开始于*、*不得早于…完成* 或 *必须完成于*）的任务，若其日期早于新日期，就会移动到该日期。这一移动在 *撤销* 中是同一个步骤。软件会显示移动了多少个任务。这只在你自己更改开始日期时发生，打开文件时从不发生。将开始日期设置得更晚不会移动计划的其余部分：这由 *移动项目* 完成，见 [移动项目](docs://howto-project-verplaatsen)。
