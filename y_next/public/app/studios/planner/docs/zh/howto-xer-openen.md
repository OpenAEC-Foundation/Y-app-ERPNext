# 打开 Primavera P6 文件（.xer）

目标：直接在应用中打开 Primavera P6 的计划，无需先导出为 XML。

## 何时需要此操作

客户或总承包商在 Primavera 中工作，并以 `.xer` 文件交付他们的计划。你想查看、计算或添加内容。应用只读取 `.xer` 文件：它不会写入 `.xer`，也不会更改你的文件。应用从文件中读取 WBS 结构，以及带有工期、日期、约束和进度的任务，带延隔的关系，日历，带分配的资源，还有活动代码、自定义字段（UDF）、备注和 P6 的计划设置。类型为 *工作量级别* 的任务会成为吊床任务。

## 步骤

1. 选择 *首页 › 文件 › 打开*，或按 Ctrl+O。选择 `.xer` 文件。
2. 每个包含任务的项目会打开一个标签页。任务最多的项目是当前标签页。如果 P6 项目 ID 与名称不同，标签页名称为 *项目名称（项目 ID）*。
3. 阅读底部的消息。例如，包含三个项目的文件可能显示如下：*已打开 XER 文件：3 个项目文档。* 其下方是说明应用所做操作的行。见下方的标题。
4. 检查功能区下方的消息栏是否显示：*你正在查看 Primavera 记录的进度计划；重新计算将使 1 个任务偏移。* Primavera 会在文件中记录其自身计算出的日期。如果应用的计算与之不同，只要你不做任何更改，应用就会显示 Primavera 的日期。其含义以及如何切换到应用自己的计算，见 [按记录的日期](docs://uitleg-datums-zoals-opgeslagen)。消息 *此文件包含按小时的计划。* 也可能出现，并带有按钮 *启用小时计划*。见 [启用小时计划](docs://howto-urenplanning-aanzetten)。
5. 用 Ctrl+S 保存项目。由于 `.xer` 从不会被覆盖，应用会询问新的 IFC 文件保存位置。它建议以 *项目名称（项目 ID）* 作为文件名。

### 消息下方的行

消息的第一行给出已打开的标签页数量。其下方只显示适用的行。以下几行需要你注意：

- *此项目按 Primavera P6 计算。可通过 文件 → 项目信息 → 计算配置文件和选项 更改。* 应用使用 Primavera 的计算规则计算此项目。选择 *打开计算配置文件*，即可进入该设置。
- *已排除的基线项目：1* 和 *已具体化的基线：1*。如果 P6 中的某个项目将另一个项目指定为其基线，那个项目不会作为单独的标签页打开。它会成为引用它的项目的当前基线。
- *已使用保护性基线回退。* 如果指定基线会导致没有任何项目打开，如果某个项目引用自身，或者项目之间形成循环互相引用，应用就会直接打开所有项目，且不创建基线。
- *已保留的外部关系：1* 两个项目之间的一种关系。应用将其保留为源数据，但不会将其转为你计划中的关系。
- *显示 Primavera 记录日期（未重新计算）的任务：1 个。* 这是你在 *按记录的日期* 视图中看到的任务数量。

其他行是对读取过程本身的诊断信息：找到的项目数量、应用跳过的空项目、应用忽略的悬空基线引用、纯 UTF-8 以外的文本编码，以及表、日历和数字中发现问题的计数、未知字段值的计数，以及应用替换为安全选择的 P6 计划设置的计数。这些行不需要你做任何操作。*了解更多* 会打开帮助中关于打开 Primavera 文件的内容。

## 易错点与应用随后的处理方式

**并非所有内容都会变成标签页或关系。** 没有任务的项目不会打开，基线项目不会作为单独的标签页打开，两个项目之间的关系也不会变成你计划中的关系。应用会在消息下方的行中报告这些情况。

**每个标签页都是一个独立项目。** 如果你保存其中一个，IFC 文件会同时保留完整的原始 `.xer`。如果你之后重新打开该 IFC 文件，应用仍然知道 Primavera 的日期。如果该源存档已损坏，或另一个 IFC 程序改写了该文件，应用会报告：*此文件中的 XER 源存档不可用，已被略去；项目本身已完整打开。* 计划、计算配置文件和所有项目数据都是完整的。缺少的是：Primavera 保存的日期，以及供 AI 和扩展使用的来源信息。再次打开原始 `.xer`，即可恢复该存档。

**导出为 CSV、MS Project XML 或 P6 XML 会丢失数据。** 应用会发出警告：*导出为 CSV 会丢失 XER 源信息。* IFC 不会丢失任何数据。

**应用无法读取的文件。** 你会收到一条错误消息，并附有原因。以下是几个例子：

- *这不是有效或受支持的 XER 文件。*
- *XER 表缺少必填列。*
- *此 XER 文件中的 P6 项目不包含作业。*

这时不会打开任何内容。请在 P6 中检查该文件，或要求发送方重新导出。
