# 日历窗口

*日历* 窗口管理项目的日历库：有哪些工作日、工作时间和假日，以及哪个日历是项目日历。列表旁边的表单与 *资源日历* 窗口中的相同。本文说明每个字段的作用、默认值以及你会看到的效果。如何创建日历并将其分配给任务，请见 [创建并分配日历](docs://howto-kalender-maken-en-toewijzen)；应用如何计算工作日，请见 [日历与工作日](docs://uitleg-kalenders)。

## 查找位置

- **日历** — *计划 › 日历 › 日历* 或 *设置 › 日历 › 日历*。
- **任务的日历** — 在 *编辑任务* 窗口或 *属性* 面板中的 *日历* 字段。参见 [任务对话框与属性面板](docs://ref-taak-eigenschappen)。
- **资源日历** — 在 *资源* 面板的 *日历* 列中：选择一个日历，或选择 *+ 资源日历* 以新建一个，或点击铅笔图标（*编辑…*）编辑所选日历。参见 [资源面板](docs://ref-resourcepaneel)。

## 日历窗口中的资源库

左侧是日历列表，右侧是所选日历的表单。*项目日历* 带有星标。含无效输入的日历带有红色三角形（*此日历包含无效输入*）。

- **新建日历**（加号）— 添加一个名为 *新建日历* 的日历，内容为应用的默认值：周一至周五，07:00 至 16:00，每天净工时 8 小时。若 *启用施工模式* 已开启（默认），其中也包含荷兰假日，但不含建筑业假期；若已关闭，列表为空。若你不需要这些假日，请选择 *生成假日…*，并在其中选择 *无假日*。（*Bouwkalender NL* 和 *Standaardkalender* 这两个名称在所有语言中均保持荷兰语。）
- **复制** — 以 *{name}（副本）* 为名称复制所选日历。
- **删除**（垃圾桶图标）— 删除所选日历。只剩一个日历时此按钮不可用。若它是项目日历，则剩余的第一个日历成为项目日历。使用该日历的任务和资源将改用项目日历。
- **设为项目默认** — 将所选日历设为项目日历。在已是项目日历的日历上，会以星标显示 *项目日历*。效果：没有自己日历的每个任务都按此日历计算，没有自己日历的资源也是如此。你自己为其指定日历的任务保留该日历。
- **应用** — 一次性将列表中的所有更改写入项目，重新计算计划并关闭窗口。若总体上没有任何更改，则不会重新计算。任一日历中有无效输入时，此按钮不可用。在普通文本框中按 Enter 效果相同，但窗口保持打开。
- **取消** — 关闭窗口，并放弃自打开窗口或上次按 Enter 以来的所有更改。Esc 键和叉号的作用与 *取消* 相同。点击窗口旁边不会有任何效果，因此你不会丢失输入。

默认情况下，项目使用日历 *Bouwkalender NL*（施工模式开启）或 *Standaardkalender*（施工模式关闭），工作时间为周一至周五 07:00 至 16:00。

## 表单

### 基本信息

- **名称** — 列表中以及任务和资源下拉列表中显示的名称。
- **工作日** — 每个星期几各有一个按钮，从 *周一* 到 *周日*；按下的按钮表示工作日。顺序取决于 *一周起始日*（*设置*，*计划* 选项卡）。默认值：*周一* 至 *周五*。两个快捷按钮：*周一至周五* 将设置为周一至周五，07:00 至 16:00，8 小时；已设置的休息会恢复为默认的 12:00 起、60 分钟休息；*连续（24/7）* 将设置全部七天，00:00 至 24:00，24 小时。效果：任务仅在工作日进行。若没有工作日，应用无法计算日历（*日历中未设置工作日*）。
- **开始（时）** 和 **结束（时）** — 工作日的开始和结束时间，采用 24 小时制 HH:MM 格式。默认值：07:00 和 16:00。箭头（或方向键）按 15 分钟为步长调整；结束时间可为 24:00，开始时间必须早于结束时间。效果：与休息时间一起决定每天的净工时。按天计算任务日期时它们不计入；按小时计算的任务则会计入。当 *启用小时计划* 开启且日历按星期设有工作时间时，这些字段会消失：此时以工作时间为准。
- **休息开始** 和 **休息时长（分钟）** — 休息的开始时间和时长，步长同样为 15 分钟。默认值：12:00 和 60 分钟。若将时长设为 0，则工作日连续不间断。休息必须完全位于工作日内，且不能占满整个工作日。效果：净工时等于结束时间减开始时间再减休息时长；对于按小时计算的任务，休息期间不安排工作。在与 *开始（时）* 相同的条件下，这些字段同样会消失。
- **每日净工时** — 只读：工作日的推算长度，保留两位小数，例如 *8.00 h*。默认值：8。效果：在天与小时之间换算时，以及对于按小时计算的任务，都以此长度作为一天的长度。参见 [天与小时](docs://uitleg-dagen-en-uren)。

### 工作时间

只有在 *启用小时计划* 开启时（*设置*，*计划* 选项卡）才会显示此区块。在这里，你按星期设置工作时间和班次。参见 [设置工作时间](docs://howto-werktijden-instellen)。

- **预设** — 一次性设置工作时间的按钮：*白班*（周一至周五 08:00 至 16:00，普通按天日历）、*两班倒*（周一至周五 06:00 至 22:00，16 小时）、*三班倒*（周一至周五 06:00 至次日 06:00，24 小时）、*夜班*（周一至周五 22:00 至 06:00，8 小时）以及 *24/7*（全部七天 00:00 至 24:00）。内置按钮之后是你自己的预设，每个预设旁有一个叉号可将其删除。
- **另存为预设…** — 将当前工作时间保存为你自己的预设，保存在此设备上，以便在任何项目中重复使用。输入名称（*预设名称*），然后点击 *保存* 或 *取消*。
- **按星期设置…** — 将按天日历转为按小时计算的日历：当前时间会成为每个工作日的工作时段，休息时间作为间隔。对于按小时计算的日历，此按钮显示为 *隐藏工作时间* 或 *显示工作时间*，用于收起或展开编辑器。对于按小时计算的日历，编辑器默认是展开的。
- **编辑器** — 每个星期几各有一个时段列表（*时段*），每个时段有开始和结束时间。勾选 *次日* 可让时段跨过午夜（夜班）。*添加时段*（加号）会添加 08:00 至 16:00 的时段。*复制到所有工作日*（仅在周一至周五可用）会将该日的时段复制到周一至周五。没有时段的日期显示为 *非工作*。底部是 *推算的小时/天：*。一天有多个时段时，会出现提示 *两个时段之间的间隔即为休息——可按需调整时间。* 效果：时段优先。有时段的星期即为工作日，*开始（时）*、*结束（时）* 字段以及休息时间字段会消失。

### 假日

- **生成假日…** — 打开生成器。*国家* 可选择 *荷兰*、*德国*、*比利时*、*法国*、*英国*、*奥地利*、*瑞士* 或 *无假日*。*地区* 仅在该国有地区时显示；默认值为 *全国*。*建筑业假期* 仅在选择荷兰且 *启用施工模式* 开启时显示，可选 *无*（默认）、*北部*、*中部* 和 *南部*，并附有提示 *仅供参考的日期 — 请与 Bouwend Nederland 核实*。预览行会显示将生成多少个假日（*…个假日，…–…*），可展开查看列表。*生成* 会将结果放入你正在编辑的日历中（只有在 *应用* 之后才生效），*取消* 则关闭生成器。效果：整个 *假日* 列表会被替换，包括你自己添加的内容。生成器覆盖的年份，从项目开始年份的前一年起，到项目结束年份的后一年止（若没有项目结束日期，则至开始后三年为止）。参见 [生成假日与建筑业假期](docs://howto-feestdagen-genereren)。
- **重新生成** — 当已生成的假日不再覆盖项目期间时，会出现在该按钮旁边，并显示文字 *假日覆盖 …–…；项目持续至 …。是否重新生成？* 点击后会为新期间再次按相同选择（国家、地区、建筑业假期）生成。若不重新生成，已生成年份之外的日期即为普通工作日。
- **假日** — 假日列表：*描述*、*起始于* 和 *至*，每行有一个垃圾桶图标。*添加假日* 会添加一行，*起始于* 为今天，*至* 留空。*至* 留空表示单日。若没有任何行，则显示 *尚无假日。* 效果：该期间内的所有日期在此日历中都计为非工作时间，适用于使用此日历的任务和资源。无效的行会出现红色边框和提示文字（*请输入有效的开始日期。*、*请输入有效的结束日期，或留空表示单日。* 或 *结束日期早于开始日期。*），并阻止 *应用*。

### 错误信息与例外

工作时间中的错误会显示在字段下方，并阻止 *应用*：*请输入有效的开始时间，格式为 HH:MM。*、*请输入有效的结束时间，格式为 HH:MM。*、*开始时间必须早于结束时间。*、*请输入有效的休息开始时间，格式为 HH:MM。*、*休息时长必须是大于或等于 0 的整数分钟。*、*休息必须完全在设定的工作日内。* 以及 *休息不能占用整个工作日。*

日历只把假日记为例外。来自 MS Project 或 Primavera 文件的日历还可能有工作例外，即额外的工作日；窗口不显示也不编辑这些例外。

## 资源日历窗口

- **资源日历** — 上文的表单，位于仅有 *应用* 和 *取消* 两个按钮的窗口中。Esc 键和叉号的作用与 *取消* 相同；点击窗口旁边不会有任何效果，在此窗口中按 Enter 也没有作用。你在此编辑一个日历：可以是已有的日历，也可以是新日历（默认名称为 *资源日历*）。在 *应用* 之后，它会链接到该资源（若点击 *取消*，则不会留下任何内容）。如果你在资源面板的 *资源库* 视图中打开它，则编辑的是资源库中的日历；在 *项目* 视图中，则编辑项目的日历，即使该日历来自资源库。效果：资源日历决定资源在直方图、过度分配和资源平衡中何时可用；它不会改变任务的日期。*应用* 不会重新计算。如果该日历也用于任务或是项目日历，计划确实会变化：此时计划会被标记为过期，点击 *计算* 即可重新计算。参见 [设置资源日历](docs://howto-resourcekalender-instellen)。
