# 打开 MS Project 文件（.mpp）

目标：直接在应用中打开 Microsoft Project 的计划，无需先导出。

## 何时需要

承包商、顾问或客户将他们的计划以 `.mpp` 文件发给你。你想查看、计算或进一步编辑它。应用可读取 MS Project 2010 至 2021（含）的 `.mpp` 文件。它只读取，不写入 `.mpp`，也绝不更改你的文件。应用从文件中获取计划本身：带结构、工期和约束的任务、带延隔的关系、日历、资源、分配和进度。它也会读取 MS Project 自行计算的日期和浮时，但这些仅用于视图 *按记录的日期*，绝不作为输入使用。

## 步骤

1. 选择 *首页 › 文件 › 打开*，或按 Ctrl+O。选择 `.mpp` 文件。
2. 项目会在新标签页中打开；若当前标签页仍为空且未更改，则在当前标签页中打开。该项目没有文件：之后使用 *保存* 会写入新的 IFC 文件。
3. 阅读底部的消息：*此项目按 Microsoft Project 计算。可通过 文件 → 项目信息 → 计算配置文件和选项 更改。* 应用使用 MS Project 的计算规则计算此项目，即计算配置文件 *Microsoft Project*。点击 *打开计算配置文件* 可进入该设置，点击 *了解更多* 可打开关于计算配置文件的帮助。
4. 检查功能区下方是否有一条提示栏：*你正在查看文件中记录的日期；重新计算将使 4 个任务偏移。* 在这些任务上，应用的结果与 MS Project 保存的日期不同。在第 3 步的消息下方，还会有一行：*显示文件中记录日期（未重新计算）的任务：4 个*。其含义以及如何切换到应用自身的计算，请参阅 [按记录的日期](docs://uitleg-datums-zoals-opgeslagen)。
5. 如果出现 *此文件包含按小时的计划。* 以及按钮 *启用小时计划*，表示文件包含以小时计的数据。请参阅 [开启小时计划](docs://howto-urenplanning-aanzetten)。

如果文件包含拆分、资源平衡或按资源驱动计划的任务，还会增加一条消息，例如 *此 MS Project 文件中有 3 项任务的计划被拆分、资源平衡或按资源驱动调整过。系统会按原样导入并显示。* 只有一项任务时，消息措辞不同。

## 注意事项以及应用随后的行为

**并非所有内容都会导入。** 应用不会接管 MS Project 中的基线、成本和费率、备注以及自定义字段。应用会接管你在 MS Project 中自行填写的 WBS 代码；否则，应用会按结构为任务编号。

**来自 MS Project 2007 或更早版本的文件。** 应用会拒绝打开该文件，并显示：*此 .mpp 文件使用较旧的格式（Project 2007 或更早版本）。请在 MS Project 中将其导出为 XML（文件 → 另存为 → XML），然后打开该文件。* 消息下方，应用会以英文附上技术原因。

**带密码的文件。** 应用会显示：*此 .mpp 文件受密码保护。请在 MS Project 中将其导出为 XML（文件 → 另存为 → XML），然后打开该文件。* 此处同样会以英文附上技术原因。

**实际不是 `.mpp` 的文件。** 你会看到 *打开文件失败*，并附上技术原因。

**XML 路径的计算方式不同。** 如果你打开 MS Project 的 XML 导出文件而不是 `.mpp`，应用会使用计算配置文件 *Open Planner Studio* 计算，且不会显示关于 *Microsoft Project* 的消息。因此日期结果可能与 `.mpp` 文件不同。

**编辑会解除 MS Project 的驱动。** 如果你编辑了一项计划原本由 MS Project 日期窗口驱动的任务，应用每个项目只会显示一次：*此次编辑后，MS Project 的工时分布不再驱动 2 项任务；原始分布仍保留在文件中。* 只有一项任务时，消息措辞不同。

**保存不会覆盖你的 `.mpp`。** 该项目没有文件。*保存* 会询问新的 IFC 文件应存放在哪里。
