# 选择、删除和撤销任务

目标：选择任务，删除任务，并撤销错误。

## 何时需要这些操作

计划中几乎所有操作都作用于你选中的任务：删除、复制、降级、开启或关闭里程碑。当工作取消或计划被修订时，你会删除任务。删除时应用不会要求你确认，因此 *撤销* 是你的安全网。

## 操作步骤

### 选择任务

- **一个任务。** 单击任务表中的行，或 Gantt 中的任务条。
- **多个任务。** Ctrl+单击（Mac 上为 ⌘+单击）可将任务加入选择，或从选择中移除。在任务表中，Shift+单击会选中从活动任务到你所单击任务之间的所有任务。
- **所有可见任务。** 按 Ctrl+A，焦点需在任务表或 Gantt 中。被筛选隐藏的任务不在其中，折叠阶段中的子任务也不在其中。
- **Gantt 中的框选。** 按住 Ctrl，并在空白背景上拖动：框线所接触行中的所有任务都会被选中，即使其任务条位于框的旁边。只有框的高度有效，时间轴不影响结果。如果你在松开鼠标按钮之后才松开 Ctrl，这些任务会加入现有选择；否则会替换现有选择。不按 Ctrl 时，在默认设置下，这种拖动会滚动时间轴。
- **不选任何任务。** 按 Esc，或单击 Gantt 的空白背景。

如果你选择摘要任务，其子任务不会一同被选中。删除和复制时，子任务会一并处理。

### 删除任务

选中任务，然后选择以下方式之一：

- *首页 › 编辑 › 删除*。同一按钮也在 *表格* 选项卡上。
- 按 Delete 或 Backspace，前提是焦点不在任务表中。因此，请先单击 Gantt 中的任务条。
- 右键菜单中的 *删除*。如果你单击的任务属于选择范围，操作会作用于整个选择；否则只作用于该任务。
- *属性* 面板顶部的小垃圾桶图标（提示为 *删除任务*）。它会删除面板显示的任务。

应用不会要求确认。一次删除多个任务时，*撤销* 只算一步。

一并消失的内容：已删除摘要任务的所有子任务，已删除任务进出两个方向的所有关系，以及它们的资源分配。如果你删除摘要任务的最后一个子任务，摘要任务会保留下来，成为普通任务。如果 *WBS auto* 已开启，应用会重新编号任务树。之后计划已过时：请按 **计算**（F5），除非 *自动计算* 已开启。

### 折叠和展开

摘要任务在任务表中名称前有一个三角形；单击它可隐藏或显示其子任务。使用 *视图 › 大纲 › 折叠* 和 *展开*，可作用于选中的摘要任务；如果未选中任何任务，则作用于所有摘要任务。摘要任务的右键菜单中也有 *折叠* 和 *展开*。在分组视图中，这些按钮作用于各组。

应用会为每个打开的文档分别保存折叠和展开状态。它不属于 *撤销*，也不保存在项目文件中。

### 撤销和重做

- *首页 › 编辑 › 撤销* 和 *重做*（也在 *表格* 选项卡上）、标题栏中的箭头，或用 Ctrl+Z 撤销，用 Ctrl+Y 或 Ctrl+Shift+Z 重做。
- 在 *撤销* 之后执行新操作，*重做* 将不可用。

*撤销* 涵盖对项目数据的更改（任务、关系、资源、日历等），以及套用布局。对任务表列的更改也算作步骤：添加、移除、移动、调整宽度、自动调整宽度、固定，以及将列布局重置为默认值。这些列步骤属于任务表本身，作用于整个应用，而不是某一个文档。应用会为每个文档保留最近一百步，超大项目保留的步数更少。

## 易错点及应用的行为

**在任务表中按 Delete 不会删除任务。** 如果焦点在任务表中，Delete（或 Backspace）会清除所选单元格的内容。对于必填或计算出的单元格，例如名称或工期，应用会拒绝清除，并在任务表下方显示提示，例如名称的提示为 *此值为必填项，不能留空。* 此时任何内容都不会被清除，包括其他所选单元格。请单击 Gantt 中的任务条，或使用 *删除*（在没有 Gantt 的 *表格* 选项卡上，使用 *表格 › 编辑 › 删除* 或右键菜单）。

**整个阶段会一次性消失。** 如果你删除摘要任务，其子任务、关系和分配会一并删除。*撤销*（Ctrl+Z）会全部恢复，包括关系和分配。

**不会恢复的内容。** 选择、折叠和展开，以及位于 *筛选/分组/排序时不可用* 栏中的 *清除* 按钮，都不属于 *撤销*。因此，在按下 *清除* 之后按 Ctrl+Z，你撤销的是之前的步骤，而不是清除操作。

**删除其他任务依赖的任务。** 该任务进出的关系也会一并消失。仅与它相连的任务会脱离关系，并在 **计算** 之后重新按各自计划的开始日期排定。如有需要，请添加新关系，参见 [添加关系](docs://howto-relaties-leggen)。
