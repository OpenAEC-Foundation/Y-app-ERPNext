# 与另一个项目的外部关系

目标：把本项目中的一个任务链接到另一个项目文件中的任务，让你的计划考虑在别处计划的工作。

## 何时需要此操作

你的扩建工程只能在场地为施工做好准备后才能开始，而这项工作在承包商的项目中。或者，安装工作只能在你的结构完成后才能开始，而安装方在他自己的文件中计划。普通关系只适用于同一项目中的任务。**外部关系**把一个任务链接到另一个文件中的任务。

外部关系不会与另一个项目实时计算。应用会保存一个固定的**锚点日期**：你建立链接那一刻外部任务的日期。计算会把该日期用作限制。如果另一个项目发生变化，在你刷新锚点之前，你的项目不会有任何变动。

## 步骤

1. 在本项目中只选择一个任务：依赖外部任务的任务，或外部任务所依赖的任务。
2. 选择 *首页 › 任务 › 关联 ▾ › 添加外部关系…*。同一菜单也位于 *计划 › 关系* 和 *表格 › 任务* 中。只有恰好选中一个任务时，该项才可用。
3. 在 *外部（跨项目）链接* 窗口中选择两种方式之一。使用 *源文件* 时，你在 *选择最近使用的文件* 下选择项目文件，然后选择 *源任务*。应用只读取该文件，不会将其作为文档打开，并自行获取锚点日期。此方式只在桌面版应用中可用，并且只适用于最近使用的文件列表中的文件；否则 *源文件* 按钮不可用。使用 *手动（备用方式）* 时，你填写外部任务的 *项目 ID* 和 *任务 ID*，可选填 *任务名称（可选）*，以及 *锚点日期*。在浏览器版本中，这是唯一的方式。
4. 在 *方向* 下选择外部任务是你的前置任务还是后续任务：*前置任务（外部 → 我）* 或 *后续任务（我 → 外部）*。
5. 选择 *关系类型*（FS、SS、FF 或 SF）。如有需要，填写 *延迟（工作日）*，例如 `0d` 或 `2d`。
6. 点击 *添加链接*，然后按 **计算**（F5）。

对于手动链接，你输入的锚点日期取决于方向和类型：

- 外部**前置任务**时，类型的第一个字母起作用：F 表示外部任务的完成日期，S 表示开始日期。因此对于 FS 和 FF，你输入完成日期；对于 SS 和 SF，你输入开始日期。
- 外部**后续任务**时，类型的第二个字母起作用：S 表示外部任务的开始日期，F 表示完成日期。因此对于 FS 和 SS，你输入开始日期；对于 FF 和 SF，你输入完成日期。

如果你按小时计划（已开启小时计划，且任务位于带工作时间的日历上），*锚点日期* 字段还会要求输入时间。

示例：工地项目在2027年6月18日（星期五）完成。你以类型为 FS 的外部前置任务链接 *Groundwork*，锚点日期为2027年6月18日。按下 **计算** 后，地基工程从2027年6月21日（星期一）开始，即锚点之后的第一个工作日。外部后续任务的作用相反：它限制你的任务最晚可以完成的时间。

## 你会看到什么以及如何管理

- 外部关系以文字形式显示在任务表的 *前置任务* 和 *后续任务* 列中（使用表头中的 **+** 添加，位于 *关系* 下），并显示项目名称、任务名称和类型。带有 *缺少源* 的小三角表示尚未读取源文件。将鼠标悬停在链接上，可查看项目（一旦已知，*项目 ID* 行会显示项目名称）、任务 ID、锚点日期和源状态。
- 在 Gantt 中，任务上有一个灰色的半透明任务条。若是前置任务，它结束于锚点；若是后续任务，它从锚点开始。带虚线边框和红色标签 *已过期* 表示源文件尚未读取。使用手动链接时，始终如此。
- 在链接所在的列中右键点击链接，选择 *编辑外部关系…* 或 *删除关系*。如果链接有源文件，*刷新源* 也在此处。
- 选择 *关联 ▾ › 刷新所有外部关系*，以重新读取源文件并更新锚点。这只适用于桌面版应用。如果你只有手动链接，应用会显示 *没有可刷新的外部源（缺少文件路径）。* 刷新后，按 **计算**。
- 如果你更改类型或方向，使锚点需要外部任务的另一侧（开始而非完成，或反过来），对于手动链接，应用会要求你输入新的锚点：*请选择新的锚点：关系类型现在使用源任务的另一侧。* 对于带有源文件的链接，应用会自行重新读取锚点。

## 常见问题以及应用的处理方式

**另一个项目不会随之移动。** 如果外部任务的日期发生变化，在你刷新或更改锚点之前，你的计划仍会以旧锚点计算。使用手动方式时，你需要自己更改锚点日期：右键点击链接，选择 *编辑外部关系…*。

**外部前置任务是下限。** 如果你的任务因自身的前置任务而晚于锚点开始，则以该关系为准。锚点只会把任务向后推。

**外部后续任务是上限。** 如果锚点过于紧迫，你会在你的任务和它之前的任务上看到负浮时。不会出现单独的警告，因此请留意 *总浮时* 列。

**只允许固定延隔。** 对于外部关系，你不能设置以日历天或百分比计的延隔；应用会显示 *外部关系仅支持以工作日或工作时间计的固定延迟。* 工作日按你自己任务的日历计算。以小时计的延隔只对按小时计划的任务有效；对于按天计划的任务，计算会忽略它。这种情况请使用工作日。

**另一个文件的项目 ID。** 项目 ID 不在字段或列中，而是保存在该项目的 IFC 中，名为 `InternalProjectId`。打开该项目，进入 *IFC* 标签页，选择 *生成 IFC*。计算只使用锚点日期；但 ID 不只是一个标签。刷新时，应用首先通过项目 ID 识别源文件（然后通过文件路径）。如果你为手动链接输入的 ID 与某个源文件的项目 ID 相同，则刷新该文件时，该链接会一并更新。你可以在该项目的表格中，于 *技术信息* 下的 *任务 ID* 列中找到另一个项目中任务的 *任务 ID*。
