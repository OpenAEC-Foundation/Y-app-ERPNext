# MS Project 파일(.mpp) 열기

목표: Microsoft Project 일정을 먼저 내보내지 않고 앱에서 바로 엽니다.

## 이런 때 필요합니다

도급업자, 컨설턴트 또는 고객이 일정을 `.mpp` 파일로 보내 줍니다. 그러면 이 일정을 보거나, 계산하거나, 더 발전시키려고 합니다. 앱은 MS Project 2010부터 2021까지의 `.mpp` 파일을 읽습니다. 앱은 읽기만 합니다. `.mpp` 파일을 쓰지 않으며 파일을 절대 바꾸지 않습니다. 앱은 파일에서 일정 자체를 가져옵니다. 구조, 기간, 제약 조건이 있는 작업, 지연이 있는 관계, 달력, 리소스, 할당과 진행률이 여기에 포함됩니다. 앱은 또한 MS Project가 스스로 계산한 날짜와 여유도 읽습니다. 하지만 이 값은 *파일에 기록된 날짜* 보기에만 쓰며, 입력값으로는 절대 쓰지 않습니다.

## 단계

1. *홈 › 파일 › 열기*를 선택하거나 Ctrl+O를 누릅니다. `.mpp` 파일을 선택합니다.
2. 프로젝트는 새 탭에서 열리거나, 아직 비어 있고 변경되지 않은 현재 탭에서 열립니다. 프로젝트에는 연결된 파일이 없습니다. 나중에 *저장*을 선택하면 새 IFC 파일로 기록됩니다.
3. 하단 메시지를 읽으세요: *이 프로젝트는 Microsoft Project(으)로 계산됩니다. 파일 → 프로젝트 정보 → 계산 프로필 및 옵션에서 변경하세요*. 앱은 MS Project의 계산 규칙으로 이 프로젝트를 계산합니다. 계산 프로필 *Microsoft Project*를 사용합니다. *계산 프로필 열기*를 선택하면 설정으로 이동합니다. *더 알아보기*를 선택하면 계산 프로필에 대한 도움말이 열립니다.
4. 리본 아래에 표시줄이 있는지 확인하세요: *파일에 기록된 날짜를 보고 있습니다. 다시 계산하면 4개의 작업이 이동합니다*. 그러면 이 작업들에서 앱의 결과가 MS Project가 저장한 날짜와 다릅니다. 3단계의 메시지 아래에도 다음 줄이 표시됩니다: *파일에 기록된 날짜를 그대로 표시하는 작업: 4개(다시 계산하지 않음)*. 이것이 무엇을 뜻하는지, 그리고 앱 자체 계산으로 바꾸는 방법은 [파일에 기록된 날짜](docs://uitleg-datums-zoals-opgeslagen)에서 확인하세요.
5. 메시지에 *이 파일에는 시간 단위 계획이 포함되어 있습니다*라고 표시되고 *시간 단위 계획 사용* 버튼이 있으면, 파일에 시간 단위 데이터가 들어 있습니다. [시간 단위 계획 켜기](docs://howto-urenplanning-aanzetten)를 참조하세요.

파일에 분할, 평준화 또는 리소스 기반 일정이 있는 작업이 있으면 다른 메시지가 추가로 표시됩니다. 예를 들면 *이 MS Project 파일에는 분할되었거나 평준화되었거나 리소스 기반으로 조정된 작업이 3개 포함되어 있습니다. 있는 그대로 가져와 표시됩니다*와 같습니다. 작업이 하나뿐이면 메시지는 단수형으로 표시됩니다.

## 주의할 점과 그때 앱의 동작

**모든 항목이 함께 넘어오지는 않습니다.** 앱은 MS Project의 기준선, 비용과 단가, 메모와 사용자 지정 필드를 가져오지 않습니다. MS Project에서 직접 입력한 WBS 코드는 가져옵니다. 그렇지 않으면 앱은 구조에 따라 작업에 번호를 매깁니다.

**MS Project 2007 이하 파일.** 앱은 이 파일을 열지 않고 다음 메시지를 표시합니다: *이 .mpp 파일은 이전 형식(Project 2007 이하)을 사용합니다. MS Project에서 XML로 내보낸 후(파일 → 다른 이름으로 저장 → XML) 해당 파일을 여세요*. 메시지 아래에 앱이 영어로 된 기술적 이유를 덧붙입니다.

**암호가 걸린 파일.** 앱은 다음 메시지를 표시합니다: *이 .mpp 파일은 암호로 보호되어 있습니다. MS Project에서 XML로 내보낸 후(파일 → 다른 이름으로 저장 → XML) 해당 파일을 여세요*. 여기서도 메시지에 영어로 된 기술적 이유가 함께 나옵니다.

**`.mpp`가 아닌 파일.** *파일을 열 수 없습니다*라는 메시지와 기술적 이유가 표시됩니다.

**XML 경로는 다르게 계산합니다.** `.mpp` 대신 MS Project XML 내보내기를 열면, 앱은 계산 프로필 *Open Planner Studio*로 계산합니다. 그러면 *Microsoft Project* 메시지가 표시되지 않습니다. 날짜가 `.mpp` 파일과 다르게 나올 수 있습니다.

**편집하면 MS Project의 제어에서 벗어납니다.** MS Project의 날짜 창이 일정을 제어하던 작업을 편집하면, 앱은 프로젝트마다 한 번 다음 메시지를 표시합니다: *이 편집 이후 MS Project의 시간 분배가 더 이상 2개 작업을 제어하지 않습니다. 원래 분배는 파일에 그대로 보존됩니다*. 작업이 하나뿐이면 메시지는 단수형으로 표시됩니다.

**저장해도 `.mpp` 파일은 절대 덮어쓰지 않습니다.** 프로젝트에는 연결된 파일이 없습니다. *저장*을 선택하면 앱이 새 IFC 파일을 어디에 저장할지 묻습니다.
