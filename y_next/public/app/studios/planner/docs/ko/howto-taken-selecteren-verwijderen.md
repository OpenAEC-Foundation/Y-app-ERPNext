# 작업 선택, 삭제 및 실행 취소

목표: 작업을 선택하고, 작업을 제거하며, 실수를 되돌립니다.

## 이런 경우에 필요합니다

일정에서 거의 모든 동작은 선택한 작업에 대해 실행됩니다. 삭제, 복사, 들여쓰기, 마일스톤 설정 켜기 또는 끄기가 그렇습니다. 작업이 필요 없게 되거나 일정을 수정하면 작업을 제거합니다. 삭제할 때 앱은 확인을 묻지 않으므로 *실행 취소*가 안전장치입니다.

## 절차

### 작업 선택하기

- **작업 하나.** 작업 표에서 행을 클릭하거나 Gantt 차트에서 막대를 클릭합니다.
- **여러 작업.** Ctrl+클릭(Mac에서는 ⌘+클릭)은 작업을 선택에 추가하거나 선택에서 뺍니다. 작업 표에서 Shift+클릭은 현재 작업부터 클릭한 작업까지 모든 작업을 선택합니다.
- **표시된 모든 작업.** 포커스가 작업 표 또는 Gantt 차트에 있을 때 Ctrl+A를 누릅니다. 필터로 숨긴 작업은 이 선택에 포함되지 않습니다. 접힌 요약 작업의 하위 작업도 마찬가지입니다.
- **Gantt 차트에서 선택 상자 그리기.** Ctrl을 누른 채 빈 배경 위에서 끕니다. 선택 상자가 닿는 행의 모든 작업이 선택됩니다. 막대가 상자 옆에 있어도 마찬가지입니다. 상자의 높이만 중요하며 시간 축은 중요하지 않습니다. 마우스 버튼을 놓은 뒤에야 Ctrl을 놓으면 선택한 작업이 기존 선택에 추가됩니다. 그렇지 않으면 기존 선택을 대체합니다. Ctrl 없이 끌면 기본 설정에서 타임라인이 스크롤됩니다.
- **아무것도 선택하지 않기.** Esc를 누르거나 Gantt 차트의 빈 배경을 클릭합니다.

요약 작업을 선택해도 하위 작업은 함께 선택되지 않습니다. 하지만 삭제와 복사는 하위 작업도 함께 처리합니다.

### 작업 삭제하기

작업을 선택하고 다음 방법 중 하나를 사용합니다:

- *홈 › 편집 › 삭제*. 같은 버튼이 *테이블* 탭에도 있습니다.
- Delete 또는 Backspace는 포커스가 작업 표에 없을 때 사용합니다. 그러므로 먼저 Gantt 차트에서 막대를 클릭합니다.
- 마우스 오른쪽 버튼 메뉴의 *삭제*. 클릭한 작업이 선택에 포함되어 있으면 전체 선택에 적용됩니다. 그렇지 않으면 그 작업 하나에만 적용됩니다.
- *속성* 패널 위쪽의 작은 휴지통 아이콘(툴팁 *작업 삭제*). 이 아이콘은 패널에 표시된 작업을 삭제합니다.

앱은 확인을 묻지 않습니다. 작업 여러 개를 한 번에 삭제하면 *실행 취소*에서는 한 단계입니다.

함께 사라지는 항목은 다음과 같습니다. 삭제한 요약 작업의 모든 하위 작업, 삭제한 작업과 연결된 모든 관계, 그리고 그 리소스 할당입니다. 요약 작업의 마지막 하위 작업을 삭제하면 그 요약 작업은 일반 작업으로 남습니다. *WBS auto*가 켜져 있으면 앱은 트리의 번호를 다시 매깁니다. 그 뒤 일정은 최신 상태가 아닙니다. *자동 계산*이 켜져 있지 않으면 **계산**(F5)을 누릅니다.

### 접기 및 펼치기

요약 작업은 작업 표에서 이름 앞에 삼각형이 있습니다. 삼각형을 클릭하면 하위 작업을 숨기거나 표시합니다. *보기 › 개요 › 접기*와 *펼치기*를 사용하면 선택한 요약 작업에 적용합니다. 아무것도 선택하지 않으면 모든 요약 작업에 적용합니다. 요약 작업의 마우스 오른쪽 버튼 메뉴에도 *접기*와 *펼치기*가 있습니다. 그룹화된 보기에서는 이 버튼이 그룹에 적용됩니다.

앱은 접기 및 펼치기 상태를 열린 문서마다 유지합니다. 이 상태는 *실행 취소*에 포함되지 않으며 프로젝트 파일에도 없습니다.

### 실행 취소 및 다시 실행

- *홈 › 편집 › 실행 취소*와 *다시 실행*(*테이블* 탭에도 있음), 제목 표시줄의 화살표, 또는 실행 취소에는 Ctrl+Z, 다시 실행에는 Ctrl+Y 또는 Ctrl+Shift+Z.
- *실행 취소* 뒤에 새 변경을 하면 *다시 실행*은 사라집니다.

*실행 취소*는 프로젝트 데이터(작업, 관계, 리소스, 달력 등)의 변경과 레이아웃 적용을 다룹니다. 작업 표의 열을 바꾸는 것도 실행 취소 단계입니다. 열 추가, 제거, 이동, 크기 조정, 자동 맞춤, 고정, 열 레이아웃을 기본값으로 재설정하는 작업이 포함됩니다. 이 열 단계는 작업 표 자체에 속하며, 한 문서가 아니라 앱 전체에 적용됩니다. 앱은 문서마다 최근 백 단계를 유지합니다. 매우 큰 프로젝트에서는 더 적게 유지합니다.

## 주의할 점과 앱의 동작

**작업 표에서 Delete 키를 눌러도 작업은 삭제되지 않습니다.** 포커스가 작업 표에 있으면 Delete(또는 Backspace)는 선택한 셀의 내용을 지웁니다. 이름이나 기간처럼 필수이거나 계산되는 셀은 앱이 지우지 않습니다. 이때 앱은 작업 표 아래에 메시지를 표시합니다. 이름의 경우 예를 들어 *이 값은 필수이며 비워 둘 수 없습니다*라는 메시지가 표시됩니다. 그러면 다른 선택된 셀에서도 아무것도 지워지지 않습니다. Gantt 차트의 막대를 클릭하거나 *삭제*를 사용합니다. *테이블* 탭에는 Gantt 차트가 없으므로 *테이블 › 편집 › 삭제* 또는 마우스 오른쪽 버튼 메뉴를 사용합니다.

**요약 작업은 통째로 사라집니다.** 요약 작업을 삭제하면 그 하위 작업, 관계, 할당도 함께 사라집니다. *실행 취소*(Ctrl+Z)를 누르면 관계와 할당을 포함하여 모든 항목이 돌아옵니다.

**돌아오지 않는 항목.** 선택, 접기 및 펼치기, 그리고 *필터링/그룹화/정렬 중에는 사용할 수 없습니다* 영역의 *지우기* 버튼은 *실행 취소*에 포함되지 않습니다. *지우기* 뒤에 Ctrl+Z를 누르면 지우기가 아니라 이전 단계를 되돌립니다.

**다른 작업이 의존하는 작업을 제거하는 경우.** 그 작업과 연결된 관계도 함께 사라집니다. 그 작업에만 연결되어 있던 작업은 연결이 끊어집니다. **계산** 후에는 연결이 끊어진 작업이 자체 계획 시작 날짜로 돌아갑니다. 필요하면 새 관계를 추가하세요. 자세한 내용은 [관계 추가하기](docs://howto-relaties-leggen)를 참조하세요.
