# 경로 추적

목표: 작업 앞이나 뒤에 있는 작업 연쇄를 보이게 합니다. 그래서 무엇이 작업의 날짜를 정하는지, 작업이 늦어지면 무엇이 함께 밀리는지 볼 수 있습니다.

## 이 기능이 필요한 경우

지붕 공사는 세 주 뒤에야 시작됩니다. 그 날짜를 어떤 작업이 정하는지 알고 싶습니다. 또는 벽돌공 작업이 일주일 늦어지고, 그 뒤의 어떤 작업이 함께 밀리는지 보고 싶습니다. 관계가 수십 개인 일정에서는 선만 보고 이것을 알 수 없습니다. **경로 추적**을 사용하면 앱은 모든 **선행 작업**(선택한 작업 앞에 오는 작업이며, 직접 또는 다른 작업을 거쳐 연결된 작업을 포함합니다)과 **후속 작업**(선택한 작업 뒤에 오는 작업)을 색으로 표시하고, 나머지는 흐리게 합니다.

## 절차

1. 보고 싶은 경로의 작업을 작업 표에서 또는 Gantt 차트의 해당 막대에서 선택하세요. 여러 작업을 선택하면, 앱은 먼저 선택한 작업부터 추적합니다.
2. 작업 앞에 오는 작업을 보려면 *계획 › 경로 추적 › 선행 작업*을 선택하세요. 작업 뒤에 오는 작업을 보려면 *계획 › 경로 추적 › 후속 작업*을 선택하세요. 두 버튼을 동시에 켤 수 있습니다. 같은 두 버튼은 *테이블* 탭의 *경로 추적* 그룹에도 있습니다.
3. 두 방향을 한 번에 보려면 Gantt 차트에서 또는 작업 표에서 작업을 마우스 오른쪽 버튼으로 클릭하고 *경로 추적*을 선택하세요.
4. Gantt 차트와 작업 표에서 결과를 보세요. 읽는 방법은 아래에 설명합니다.
5. 켜진 버튼을 다시 클릭하거나, 작업을 마우스 오른쪽 버튼으로 클릭하고 *경로 추적 중지*를 선택하거나, Esc를 눌러 추적을 중지합니다. Esc는 선택도 해제합니다.

추적 중에 다른 작업을 선택하면, 경로는 새 선택을 따릅니다.

## 결과 읽기

- 선행 작업은 금색이고, 후속 작업은 보라색입니다. Gantt 차트에서는 막대의 색이 바뀌고, 작업 표에서는 행 왼쪽에 줄이 나타납니다. 선행 작업은 실선, 후속 작업은 점선입니다. 선택한 작업에는 윤곽선이 있습니다.
- 더 짙은 색(작업 표에서는 더 두꺼운 줄과 굵은 글씨)은 **주도 관계**의 연쇄를 표시합니다. 주도 관계는 실제로 날짜를 정하는 관계입니다. 이것이 무엇을 뜻하는지는 [관계와 지연](docs://uitleg-relaties)에서 설명합니다.
- 경로 밖의 모든 작업은 흐리게 표시됩니다. 경로에 속하지 않는 관계선은 더 옅고 점선으로 표시됩니다.

## 주의할 점과 앱의 동작

**선택한 작업이 없습니다.** 선택한 작업이 없으면 추적할 것이 없습니다. 버튼은 켜져 있지만 화면에서 바뀌는 것은 없습니다. 먼저 작업을 선택하세요.

**주도 관계 강조가 없습니다.** 강조는 마지막 계산에서 나옵니다. 일정을 아직 계산하지 않았거나 계산에 오류가 있으면, 앱은 모든 선행 작업과 후속 작업을 같은 세기로 강조합니다. 예를 들어 *홈 › 일정 › 계산*에서 **계산** (F5)을 누르고, 경로를 다시 보세요. 변경 후에는 상태 표시줄에 *오래됨 — 다시 계산하세요 (F5)*가 표시되는 동안 강조는 이전 계산을 따릅니다.

**단계의 관계.** 추적은 직접 설정한 대로 관계를 따릅니다. 단계(요약 작업)에서 또는 단계로 가는 관계는 단계 자체를 연결합니다. 계산에서는 이 관계가 그 단계의 모든 작업에 적용되지만, 경로는 그 안의 작업까지 이어지지 않습니다. 따라서 단계 자체에 건 관계로 다른 작업과 연결된 단계 안의 작업을 추적하면, 그 관계는 보이지 않습니다. 이 경우에는 단계 자체를 선택하세요.

**선택한 방향만 보입니다.** *선행 작업*만 켜져 있으면 작업 뒤에 오는 것은 보이지 않습니다. 반대의 경우도 마찬가지입니다.
