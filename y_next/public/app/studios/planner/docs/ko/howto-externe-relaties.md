# 다른 프로젝트와의 외부 관계

목표: 이 프로젝트의 작업을 다른 프로젝트 파일의 작업과 연결합니다. 그러면 일정에 다른 곳에서 계획을 세운 작업이 반영됩니다.

## 이 기능이 필요한 경우

부지의 건축 준비가 끝나야 증축 공사를 시작할 수 있습니다. 그 작업은 시공사의 프로젝트에 있습니다. 또는 설치 업체는 구조물이 완성된 뒤에야 시작할 수 있으며, 자체 파일에서 계획합니다. 일반 관계는 같은 프로젝트의 작업 사이에서만 작동합니다. **외부 관계**는 작업을 다른 파일의 작업과 연결합니다.

외부 관계는 다른 프로젝트와 실시간으로 계산하지 않습니다. 앱은 고정된 **앵커 날짜**를 저장합니다. 이 날짜는 연결하는 시점의 외부 작업 날짜입니다. 계산은 이 날짜를 한계로 사용합니다. 다른 프로젝트가 바뀌어도 앵커를 새로 고치기 전까지는 이 프로젝트에서 아무것도 움직이지 않습니다.

## 단계

1. 이 프로젝트에서 작업을 하나만 선택합니다. 외부 작업에 의존하는 작업이거나, 외부 작업이 의존하는 작업입니다.
2. *홈 › 작업 › 연결 ▾ › 외부 관계 추가…*를 선택합니다. 같은 메뉴가 *계획 › 관계*와 *테이블 › 작업*에도 있습니다. 이 항목은 작업을 하나만 선택했을 때만 사용할 수 있습니다.
3. *외부(프로젝트 간) 링크* 창에서 두 경로 중 하나를 선택합니다. *소스 파일*을 선택하면 *최근 파일 선택*에서 프로젝트 파일을 고른 뒤 *소스 작업*을 고릅니다. 앱은 파일을 읽기 전용으로 읽습니다. 파일을 문서로 열지 않습니다. 앵커 날짜도 앱이 직접 가져옵니다. 이 경로는 데스크톱 앱에서만, 최근 파일 목록에 있는 파일에만 작동합니다. 그렇지 않으면 *소스 파일* 버튼이 비활성화됩니다. *수동(대체)*를 선택하면 외부 작업의 *프로젝트 ID*와 *작업 ID*를 입력합니다. 선택 사항으로 *작업 이름(선택 사항)*을 입력하고, *앵커 날짜*를 입력합니다. 브라우저 버전에서는 이 경로만 사용할 수 있습니다.
4. *방향*에서 외부 작업이 선행 작업인지 후속 작업인지 선택합니다: *선행(외부 → 나)* 또는 *후행(나 → 외부)*.
5. *관계 유형*(FS, SS, FF 또는 SF)을 선택합니다. 필요하면 *지연(작업일)*을 입력합니다(예: `0d` 또는 `2d`).
6. *링크 추가*를 선택하고 **계산**(F5)를 누릅니다.

수동 외부 관계의 앵커로 입력할 날짜는 방향과 유형에 따라 다릅니다:

- 외부 **선행 작업**이면 유형의 첫 글자가 기준입니다. F는 외부 작업의 완료 날짜, S는 시작 날짜를 뜻합니다. 따라서 FS와 FF에서는 완료 날짜를, SS와 SF에서는 시작 날짜를 입력합니다.
- 외부 **후속 작업**이면 유형의 두 번째 글자가 기준입니다. S는 외부 작업의 시작 날짜, F는 완료 날짜를 뜻합니다. 따라서 FS와 SS에서는 시작 날짜를, FF와 SF에서는 완료 날짜를 입력합니다.

시간 단위로 계획하면(시간 단위 계획이 켜져 있고 작업이 근무 시간이 있는 달력에 있는 경우), *앵커 날짜* 필드에 시간도 입력합니다.

예: 현장 프로젝트는 2027년 6월 18일 금요일에 끝납니다. *Groundwork*를 FS 유형의 외부 선행 작업과 연결합니다. 앵커 날짜는 2027년 6월 18일입니다. **계산** 후 groundwork는 6월 21일 월요일에 시작합니다. 이는 앵커 날짜 다음의 첫 근무일입니다. 외부 후속 작업은 반대 방향으로 작동합니다. 작업이 끝날 수 있는 가장 늦은 날짜를 제한합니다.

## 무엇이 보이고 어떻게 관리하는지

- 외부 관계는 작업 표의 *선행 작업* 열과 *후속 작업* 열에 텍스트로 나타납니다. 추가하려면 표 머리글의 **+**를 사용합니다. 이 항목은 *관계* 아래에 있습니다. 외부 관계에는 프로젝트 이름, 작업 이름, 유형이 표시됩니다. *소스 누락*이 있는 작은 삼각형은 소스를 아직 읽지 않았음을 나타냅니다. 외부 관계 위에 마우스 포인터를 올리면 프로젝트, 작업 ID, 앵커 날짜, 소스 상태를 볼 수 있습니다. 프로젝트 이름은 알려지면 *프로젝트 ID* 줄에 표시됩니다.
- Gantt 차트에서 작업 위치에 회색 반투명 막대가 있습니다. 선행 작업이면 막대는 앵커 날짜에서 끝납니다. 후속 작업이면 막대는 앵커 날짜에서 시작합니다. 빨간색 *오래됨* 표시가 있는 점선 테두리는 소스를 읽지 않았다는 뜻입니다. 수동 외부 관계에서는 항상 이 표시가 나타납니다.
- 열의 외부 관계를 마우스 오른쪽 버튼으로 클릭하면 *외부 관계 편집…*과 *관계 삭제*를 선택할 수 있습니다. 외부 관계에 소스 파일이 있으면 *소스 새로 고침*도 있습니다.
- *연결 ▾ › 모든 외부 관계 새로 고침*을 선택하면 소스 파일을 다시 읽고 앵커를 갱신합니다. 이 기능은 데스크톱 앱에서만 작동합니다. 수동 외부 관계만 있으면 앱에 *새로 고칠 수 있는 외부 소스가 없습니다(파일 경로 없음).*가 표시됩니다. 새로 고친 뒤에는 **계산**을 누릅니다.
- 유형이나 방향을 바꿔서 앵커에 외부 작업의 다른 쪽이 필요해지면(완료 대신 시작, 또는 그 반대), 수동 외부 관계에서 앱이 새 앵커를 묻습니다: *새 앵커를 선택하세요. 이제 관계 유형이 원본 작업의 반대쪽을 사용합니다.* 소스 파일이 있는 외부 관계에서는 앱이 앵커를 스스로 다시 읽습니다.

## 주의할 점과 앱의 동작

**다른 프로젝트는 함께 움직이지 않습니다.** 외부 작업의 날짜가 바뀌면 일정은 앵커를 새로 고치거나 바꿀 때까지 이전 앵커로 계속 계산합니다. 수동 경로에서는 외부 관계를 마우스 오른쪽 버튼으로 클릭하고 *외부 관계 편집…*을 선택해 앵커 날짜를 직접 바꿉니다.

**외부 선행 작업은 하한입니다.** 작업이 자체 선행 작업 때문에 앵커가 요구하는 것보다 늦게 시작하면 그 관계가 우선합니다. 앵커는 작업을 뒤로 밀기만 합니다.

**외부 후속 작업은 상한입니다.** 앵커가 너무 빠듯하면 작업과 그 앞의 작업에 음수 여유로 나타납니다. 이때 별도 경고는 나타나지 않습니다. *총 여유* 열을 확인하세요.

**고정 지연만 사용할 수 있습니다.** 외부 관계에는 달력 일수나 백분율로 지연을 입력할 수 없습니다. 앱에 *외부 관계는 근무일 또는 근무 시간 단위의 고정 지연만 지원합니다.*가 표시됩니다. 근무일은 내 작업의 달력 기준으로 계산합니다. 시간 단위 지연은 시간 단위 계획을 사용하는 작업에만 적용됩니다. 일 단위 작업에서는 계산이 이를 무시합니다. 그럴 때는 근무일을 사용하세요.

**다른 파일의 프로젝트 ID.** 프로젝트 ID는 필드나 열에 없습니다. 대신 그 프로젝트의 IFC에 `InternalProjectId`로 저장됩니다. 프로젝트를 열고 *IFC* 탭으로 이동한 뒤 *IFC 생성*을 선택하세요. 계산에는 앵커 날짜만 사용합니다. 하지만 ID는 단순한 이름표가 아닙니다. 새로 고칠 때 앱은 먼저 프로젝트 ID로, 그다음 파일 경로로 소스 파일을 알아봅니다. 수동 외부 관계에 소스 파일과 같은 프로젝트 ID를 입력하면, 그 파일을 새로 고칠 때 외부 관계도 함께 업데이트됩니다. 다른 프로젝트 작업의 *작업 ID*는 그 프로젝트의 표에서 *기술 정보* 아래의 *작업 ID* 열에서 찾습니다.
