# ການຕິດຕັ້ງ ແລະ ການຈັດການສ່ວນເສີມ

ເປົ້າໝາຍ: ຕິດຕັ້ງສ່ວນເສີມ ອ່ານຄຳຖາມກ່ຽວກັບສິດ ແລະ ໃນພາຍຫຼັງ ປິດໃຊ້ງານ ຫຼື ລຶບສ່ວນເສີມອອກ.

## ເມື່ອທ່ານຕ້ອງການສິ່ງນີ້

ສ່ວນເສີມເພີ່ມບາງຢ່າງໃຫ້ແອັບ ໂດຍທ່ານບໍ່ຕ້ອງລໍຖ້າເວີຊັນໃໝ່. ຕົວຢ່າງ ສ່ວນເສີມສາມາດເພີ່ມຮູບແບບການນຳເຂົ້າທີ່ປາກົດໃນ *ໄຟລ໌ › ນຳເຂົ້າ*, ໃສ່ປຸ່ມໃນ ແຖບເຄື່ອງມື ຫຼື ໃຫ້ຟອນສຳລັບການສົ່ງອອກ PDF. ລາຍການທາງການແບ່ງສ່ວນເສີມເປັນໝວດໝູ່ດັ່ງນີ້: *ນຳເຂົ້າ/ສົ່ງອອກ*, *ການວາງແຜນ*, *ລາຍງານ*, *ເຄື່ອງມືຊ່ວຍ*, *ຟອນ* ແລະ *ອື່ນໆ*.

ຄິດໃຫ້ດີກ່ອນທ່ານຕິດຕັ້ງສ່ວນເສີມ. ສ່ວນເສີມແມ່ນໂຄດໂປຣແກຣມທີ່ເຮັດວຽກດ້ວຍສິດທຽບເທົ່າກັບແອັບເອງ ແລະ ແອັບບໍ່ສາມາດຈຳກັດມັນໄດ້. ນັ້ນແມ່ນເຫດຜົນທີ່ແອັບຖາມຂໍອະນຸຍາດທຸກຄັ້ງທີ່ຕິດຕັ້ງ. ສິ່ງທີ່ທ່ານເຫັນໃນຄຳຖາມນັ້ນ ອະທິບາຍຢູ່ດ້ານລຸ່ມ.

## ຂັ້ນຕອນ

### ຕິດຕັ້ງສ່ວນເສີມຈາກລາຍການ

1. ເລືອກ *ໄຟລ໌ › ສ່ວນເສີມ*.
2. ເລືອກແຖບ *ຄົ້ນຫາ*. ແອັບດຶງລາຍການສ່ວນເສີມ ໃນຂະນະທີ່ສະແດງ *ກຳລັງໂຫຼດລາຍການສ່ວນເສີມ...* ສິ່ງທີ່ຢູ່ໃນລາຍການສ່ວນເສີມ ຖືກກຳນົດໂດຍ OpenAEC Foundation ທີ່ດູແລມັນ ແລະ ມັນອາດປ່ຽນແປງໄດ້.
3. ຄົ້ນຫາສ່ວນເສີມດ້ວຍຊ່ອງ *ຄົ້ນຫາສ່ວນເສີມ...* ມັນຄົ້ນຫາໃນຊື່, ຄຳອະທິບາຍ, ຜູ້ພັດທະນາ ແລະ ແທັກ.
4. ແຕ່ລະກາດສະແດງຊື່, ເວີຊັນ, ໝວດໝູ່, ຄຳອະທິບາຍ ແລະ ຜູ້ພັດທະນາ. ກົດ *ຕິດຕັ້ງ*.
5. ໜ້າຕ່າງ *ຕິດຕັ້ງສ່ວນເສີມຫຼືບໍ່?* ເປີດຂຶ້ນ. ອ່ານມັນ ແລະ ເບິ່ງຂັ້ນຕອນຕໍ່ໄປ.
6. ກົດ *ຕິດຕັ້ງ* ເພື່ອດຳເນີນຕໍ່. ຖ້າກົດ *ບໍ່ຕິດຕັ້ງ* ຈະບໍ່ມີຫຍັງເກີດຂຶ້ນ. ກົດ Esc ຫຼື ກົດນອກໜ້າຕ່າງ ກໍນັບວ່າປະຕິເສດເຊັ່ນກັນ. ແອັບຈະບໍ່ສະແດງຂໍ້ຄວາມຜິດພາດ.

ຫຼັງຕິດຕັ້ງ ສ່ວນເສີມເປີດໃຊ້ງານທັນທີ. ໃນກາດຂອງແຖບ *ຄົ້ນຫາ* ມັນຂຽນວ່າ *ຕິດຕັ້ງແລ້ວ*. ທ່ານເຫັນສິ່ງທີ່ສ່ວນເສີມເພີ່ມ ໃນແອັບເອງ: ປຸ່ມໃໝ່ໃນ ແຖບເຄື່ອງມື ຫຼື ຮູບແບບການນຳເຂົ້າໃນ *ໄຟລ໌ › ນຳເຂົ້າ*. ບາງສ່ວນເສີມກໍສະແດງຂໍ້ຄວາມ. ທ່ານຈຳມັນໄດ້ຈາກຄຳນຳໜ້າ *ສ່ວນເສີມ* ຕາມດ້ວຍຊື່ຂອງສ່ວນເສີມ.

### ຕິດຕັ້ງສ່ວນເສີມຈາກໄຟລ໌

ຖ້າທ່ານໄດ້ຮັບສ່ວນເສີມເປັນໄຟລ໌ ໃຫ້ຕິດຕັ້ງດັ່ງນີ້.

1. ເລືອກ *ໄຟລ໌ › ສ່ວນເສີມ*.
2. ຢູ່ເທິງຂວາ ກົດ *ZIP* ສຳລັບໄຟລ໌ ZIP ຫຼື *JS* ສຳລັບໄຟລ໌ JavaScript ແຍກຕ່າງຫາກ.
3. ເລືອກໄຟລ໌. ໜ້າຕ່າງ *ຕິດຕັ້ງສ່ວນເສີມຫຼືບໍ່?* ເປີດຂຶ້ນ ຄືກັບຂ້າງເທິງ.

ໄຟລ໌ ZIP ຕ້ອງມີ `manifest.json` ແລະ ໄຟລ໌ຫຼັກຂອງສ່ວນເສີມ. ຖ້າທ່ານຕິດຕັ້ງສ່ວນເສີມທີ່ຕິດຕັ້ງແລ້ວ ເວີຊັນໃໝ່ຈະແທນທີ່ເວີຊັນເກົ່າ. ຖ້າແອັບຕິດຕັ້ງໄຟລ໌ບໍ່ໄດ້ ຕົວຢ່າງ ເພາະໄຟລ໌ ZIP ເສຍຫາຍ ຈະບໍ່ມີຫຍັງເກີດຂຶ້ນ. ແອັບບໍ່ສະແດງຂໍ້ຄວາມຜິດພາດສຳລັບ ZIP ແລະ JS ແລະ ສ່ວນເສີມບໍ່ປາກົດໃນລາຍການ. ແຕ່ສາເຫດຢູ່ໃນໜ້າຈໍແກ້ໄຂບັນຫາ. ເປີດມັນດ້ວຍ *ການຕັ້ງຄ່າ › ໂຄງການ › ການຕັ້ງຄ່າ*, ແຖບ *ຂັ້ນສູງ*, *ເປີດໃຊ້ໜ້າຈໍແກ້ໄຂບັນຫາ*. ແລ້ວເປີດມັນດ້ວຍປຸ່ມ *ສະແດງໜ້າຈໍແກ້ໄຂບັນຫາ* ໃນ ແຖບສະຖານະ. ທີ່ນັ້ນຈະມີຂໍ້ຄວາມ ເຊັ່ນ *[Extensies] ZIP-installatie mislukt: Error: Geen manifest.json gevonden in ZIP* (ແອັບສະແດງຂໍ້ຄວາມທາງເທກນິກນີ້ເປັນພາສາດັດ).

### ອ່ານຄຳຖາມກ່ຽວກັບສິດ

ຄຳຖາມສະແດງສິ່ງທີ່ທ່ານຕ້ອງຕັດສິນໃຈ.

- *ຜູ້ພັດທະນາ* ແລະ *ແຫຼ່ງເກັບໂຄດ (Repository)* ບອກວ່າໃຜເປັນຜູ້ສ້າງສ່ວນເສີມ ແລະ ໂຄດຕົ້ນສະບັບຢູ່ໃສ.
- *ແຫຼ່ງທີ່ມາ* ບອກວ່າໄຟລ໌ມາຈາກໃສ: *ຈາກລາຍການສ່ວນເສີມອອນລາຍ*, *ຈາກໄຟລ໌ ZIP ໃນເຄື່ອງນີ້* ຫຼື *ຈາກໄຟລ໌ JavaScript ໃນເຄື່ອງນີ້*. ດ້ານລຸ່ມບອກວ່າໄຟລ໌ຖືກກວດສອບແລ້ວຫຼືບໍ່. ສຳລັບລາຍການ ມັນບອກວ່າ *ການດາວໂຫຼດໄດ້ຮັບການກວດສອບຄວາມຖືກຕ້ອງກັບລະຫັດ checksum ຈາກລາຍການແລ້ວ*. ຖ້າລາຍການບໍ່ມີລະຫັດ checksum ມັນຈະສະແດງເປັນສີແດງວ່າ *ລາຍການບໍ່ມີລະຫັດ checksum — ການດາວໂຫຼດນີ້ຍັງບໍ່ໄດ້ຮັບການກວດສອບ*. ສຳລັບໄຟລ໌ຂອງທ່ານເອງ ມັນບອກວ່າ *ທ່ານເປັນຜູ້ເລືອກໄຟລ໌ນີ້ເອງ; ຈຶ່ງບໍ່ມີແຫຼ່ງຂໍ້ມູນພາຍນອກເພື່ອກວດສອບຄວາມຖືກຕ້ອງ*.
- *ຂໍ້ຕົກລົງທີ່ທ່ານຍິນຍອມ* ບອກວ່າ: *ສ່ວນເສີມຄືໂຄດໂປຣແກຣມທີ່ເຮັດວຽກດ້ວຍສິດທຽບເທົ່າກັບ Open Planner Studio ເອງ. ບໍ່ມີສິ່ງໃດຈຳກັດສິດຂອງມັນ. ຄວນຕິດຕັ້ງສະເພາະສ່ວນເສີມຈາກຜູ້ພັດທະນາທີ່ທ່ານເຊື່ອຖືເທົ່ານັ້ນ.* ດ້ານລຸ່ມບອກວ່າສິ່ງນັ້ນໝາຍເຖິງຫຍັງໃນແພລດຟອມຂອງທ່ານ. ໃນແອັບ Desktop ມັນບອກວ່າ *ສຳລັບແອັບ Desktop ຈະລວມເຖິງ: ການອ່ານ ແລະ ຂຽນໄຟລ໌ໃນໂຟນເດີຜູ້ໃຊ້ຂອງທ່ານທຸກບ່ອນ, ລວມທັງການເຂົ້າເຖິງໂຄງການ, ການຕັ້ງຄ່າ ແລະ ຄລິບບອດ*. ໃນບຣາວເຊີ ມັນບອກວ່າ *ສຳລັບບຣາວເຊີ ໝາຍເຖິງ: ການເຂົ້າເຖິງໂຄງການ ແລະ ການຕັ້ງຄ່າທີ່ບັນທຶກໄວ້, ໄຟລ໌ທີ່ທ່ານອະນຸຍາດ, ແລະ ເຄືອຂ່າຍອິນເຕີເນັດ*.
- *ສິ່ງທີ່ສ່ວນເສີມນີ້ແຈ້ງວ່າຈະໃຊ້* ສະແດງສິດທີ່ຜູ້ພັດທະນາແຈ້ງໄວ້ ເປັນປ້າຍນ້ອຍໆ. ນີ້ແມ່ນຂໍ້ຄວາມແຈ້ງຈາກຜູ້ພັດທະນາ ເຊິ່ງບໍ່ແມ່ນການຈຳກັດສິດ — ຕົວໂຄດຕົວຈິງອາດເຮັດວຽກຫຼາຍກວ່ານັ້ນໄດ້. ຖ້າບໍ່ມີປ້າຍ ມັນສະແດງ *ບໍ່ມີການແຈ້ງການໃຊ້ງານໃດໆ*. ນັ້ນບໍ່ໄດ້ໝາຍຄວາມວ່າສ່ວນເສີມເຮັດບໍ່ໄດ້ຫຍັງ: ເຖິງບໍ່ມີປ້າຍ ສ່ວນເສີມກໍອ່ານ ແລະ ປ່ຽນຂໍ້ມູນແຜນງານຂອງທ່ານ ແລະ ສະແດງຂໍ້ຄວາມໄດ້.

ປ້າຍເຫຼົ່ານີ້ໝາຍຄວາມວ່າ:

- *ແຖບເຄື່ອງມື*: ສ່ວນເສີມໃສ່ປຸ່ມໃນແຖບເຄື່ອງມື.
- *ເຫດການ*: ສ່ວນເສີມຟັງເຫດການທີ່ເກີດຂຶ້ນໃນແອັບ.
- *ເມນູໄຟລ໌*: ສ່ວນເສີມເພີ່ມຮູບແບບການນຳເຂົ້າໃນ *ໄຟລ໌ › ນຳເຂົ້າ*.
- *ຟອນ PDF*: ສ່ວນເສີມໃຫ້ຟອນສຳລັບການສົ່ງອອກ PDF.
- *ແຫຼ່ງການນຳເຂົ້າ*: ສ່ວນເສີມອາດອ່ານໄບຕ໌ຕົ້ນສະບັບທັງໝົດຂອງທຸກໄຟລ໌ທີ່ທ່ານນຳເຂົ້າ ຕົວຢ່າງ ໄຟລ໌ Primavera ດິບ ລວມທັງຊ່ອງທີ່ບໍ່ໄດ້ຢູ່ໃນໂຄງການຂອງທ່ານ. ໜ້າຕ່າງກໍອະທິບາຍເລື່ອງນີ້ເອງ.
- *ຊ່ວຍເຫຼືອ*: ສ່ວນເສີມອາດເພີ່ມບົດຊ່ວຍເຫຼືອ ເປີດໂຄງການທີ່ມາພ້ອມເປັນເອກະສານໃໝ່ ແລະ ສະແດງຄູ່ມືທີ່ຊີ້ໄປຍັງສ່ວນຕ່າງໆຂອງແອັບ. ໜ້າຕ່າງກໍອະທິບາຍເລື່ອງນີ້ເອງ.
- *ລະບົບໄຟລ໌* ແລະ *ເຄືອຂ່າຍ*: ນີ້ເປັນພຽງສິ່ງທີ່ຜູ້ພັດທະນາຕັ້ງໃຈ. ແອັບບໍ່ມີຟັງຊັນສຳລັບສິ່ງເຫຼົ່ານີ້.

### ປິດໃຊ້ງານ, ເປີດໃຊ້ງານອີກຄັ້ງ ຫຼື ລຶບສ່ວນເສີມ

1. ເລືອກ *ໄຟລ໌ › ສ່ວນເສີມ* ແລ້ວເລືອກແຖບ *ຕິດຕັ້ງແລ້ວ*. ແຕ່ລະສ່ວນເສີມມີກາດທີ່ມີຊື່, ເວີຊັນ, ໝວດໝູ່, ຄຳອະທິບາຍ ແລະ ຜູ້ພັດທະນາ.
2. ດ້ວຍສະວິດໃນກາດ ທ່ານປິດໃຊ້ງານສ່ວນເສີມ (*ປິດໃຊ້ງານ*) ຫຼື ເປີດໃຊ້ງານອີກຄັ້ງ (*ເປີດໃຊ້ງານ*). ເມື່ອປິດໃຊ້ງານ ປຸ່ມ ແລະ ຮູບແບບການນຳເຂົ້າທີ່ສ່ວນເສີມເພີ່ມຈະຫາຍໄປ ແຕ່ສ່ວນເສີມຍັງຕິດຕັ້ງຢູ່. ມັນຍັງປິດຢູ່ ຫຼັງຈາກທ່ານເປີດແອັບໃໝ່. ສ່ວນເສີມທີ່ເປີດໃຊ້ງານຈະເລີ່ມເອງເມື່ອແອັບເລີ່ມ.
3. ກົດ *ລຶບອອກ*. ປຸ່ມຈະປ່ຽນເປັນ *ຢືນຢັນ* ພ້ອມຄຳອະທິບາຍ *ກົດອີກຄັ້ງເພື່ອລຶບອອກຖາວອນ*. ກົດອີກຄັ້ງເພື່ອລຶບສ່ວນເສີມ. ແອັບຍັງລຶບການຕັ້ງຄ່າທີ່ສ່ວນເສີມບັນທຶກໄວ້ອອກນຳ.

## ຈຸດທີ່ຕ້ອງລະວັງ ແລະ ສິ່ງທີ່ແອັບເຮັດ

**ລາຍການສ່ວນເສີມບໍ່ໂຫຼດ.** ແອັບສະແດງ *ບໍ່ສາມາດໂຫຼດລາຍການສ່ວນເສີມໄດ້:* ພ້ອມເຫດຜົນທາງເທກນິກ ແລະ ປຸ່ມ *ລອງໃໝ່*. ອາດເປັນເພາະທ່ານບໍ່ມີການເຊື່ອມຕໍ່ອິນເຕີເນັດ.

**ແອັບສະແດງ *ການຕິດຕັ້ງບໍ່ສຳເລັດ.* ພາຍໃຕ້ກາດໃນລາຍການສ່ວນເສີມ.** ການດາວໂຫຼດ ຫຼື ການຕິດຕັ້ງບໍ່ສຳເລັດ ຕົວຢ່າງ ເພາະລະຫັດ checksum ບໍ່ກົງກັນ. ຈາກນັ້ນບໍ່ມີຫຍັງຖືກຕິດຕັ້ງ. ນີ້ຕ່າງຈາກການປະຕິເສດຄຳຖາມ: ເມື່ອນັ້ນບໍ່ມີຂໍ້ຄວາມຜິດພາດ.

**ເທິງລາຍການມີ *ຂ້າມລາຍການໃນລາຍການສ່ວນເສີມ: 1*.** ລາຍການສ່ວນເສີມມີລາຍການໜຶ່ງທີ່ແອັບໃຊ້ບໍ່ໄດ້. ທ່ານສາມາດຕິດຕັ້ງສ່ວນເສີມອື່ນຕາມປົກກະຕິ.

**ສ່ວນເສີມບໍ່ເລີ່ມ.** ກາດຈະສະແດງຂໍ້ຄວາມຜິດພາດ ເຊັ່ນ ສ່ວນເສີມຕ້ອງການແອັບເວີຊັນໃໝ່ກວ່າ ພ້ອມເວີຊັນປັດຈຸບັນຂອງທ່ານ ຫຼື ຂໍ້ຜິດພາດທີ່ສ່ວນເສີມເອງໃຫ້. ສ່ວນເສີມນັ້ນບໍ່ເຮັດວຽກ. ປັບປຸງແອັບ ຫຼື ລຶບສ່ວນເສີມອອກ.

**ກາດທີ່ມີ *ກັກໄວ້*.** ແອັບບໍ່ສາມາດໃຊ້ສ່ວນເສີມທີ່ບັນທຶກໄວ້ໄດ້. ພາຍໃຕ້ຊື່ມັນສະແດງ *ສາເຫດ:* ພ້ອມສາເຫດ. ກົດ *ລຶບອອກຈາກບ່ອນເກັບຂໍ້ມູນ* ເພື່ອລຶບມັນອອກ.

**ການຂຽນສ່ວນເສີມເອງ.** ຄູ່ມືສຳລັບຜູ້ສ້າງສ່ວນເສີມ (manifest, API, ສິດ) ຢູ່ໃນແຫຼ່ງເກັບໂຄດ `OpenAEC-Foundation/open-planner-studio` ໃນ GitHub, ໃນໄຟລ໌ `docs/extensions.md`.

**ສ່ວນເສີມບໍ່ຢູ່ໃນໂຄງການ.** ສ່ວນເສີມຖືກເກັບໄວ້ໃນແອັບ: ໃນແອັບ Desktop ຢູ່ໃນຄອມພິວເຕີນີ້ ແລະ ໃນບຣາວເຊີ ຢູ່ໃນບ່ອນເກັບຂໍ້ມູນຂອງບຣາວເຊີນັ້ນ. ມັນໃຊ້ກັບໂຄງການທັງໝົດຂອງທ່ານ ແລະ ບໍ່ແມ່ນສ່ວນໜຶ່ງຂອງໄຟລ໌ໂຄງການ. ຖ້າທ່ານລຶບຂໍ້ມູນເວັບໄຊໃນບຣາວເຊີ ສ່ວນເສີມທັງໝົດຈະຫາຍໄປ.
