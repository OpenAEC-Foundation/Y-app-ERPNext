# ຂໍ້ຄວາມແຈ້ງ ແລະ ຄຳເຕືອນ

ແອັບບອກທ່ານວ່າມີຫຍັງເກີດຂຶ້ນໃນສາມບ່ອນ: ແຖບສະຖານະທາງລຸ່ມ, *ຄຳເຕືອນ* ໃນຖັນເບື້ອງຂວາ ແລະ ຂໍ້ຄວາມແຈ້ງທີ່ປາກົດສັ້ນໆທາງລຸ່ມຂອງໜ້າຈໍ. ບົດຄວາມນີ້ອະທິບາຍແຕ່ລະບ່ອນ: ທ່ານເຫັນຫຍັງ, ມັນປາກົດເມື່ອໃດ ແລະ ທ່ານເຮັດຫຍັງໄດ້. ເຫດຜົນທີ່ແຜນງານເປັນວິກິດ ຫຼື ໃຊ້ງານເກີນກຳລັງ ຢູ່ໃນ [ເສັ້ນທາງວິກິດ ແລະ float](docs://uitleg-kritiek-pad); ການແກ້ໄຂການໃຊ້ງານເກີນກຳລັງ ຢູ່ໃນ [ການແກ້ໄຂການໃຊ້ງານເກີນກຳລັງ](docs://howto-overbezetting-oplossen); ການສ້າງສາຍສຳພັນ ຢູ່ໃນ [ການສ້າງສາຍສຳພັນ](docs://howto-relaties-leggen).

## ຄວາມແຕກຕ່າງຂອງທັງສາມຢ່າງ

- **ແຖບສະຖານະ** — ແຖວຄົງທີ່ທີ່ມີຕົວນັບ. ຕົວນັບມາຈາກການຄິດໄລ່ຄັ້ງຫຼ້າສຸດ ແລະ ຢູ່ຈົນກວ່າທ່ານຈະຄິດໄລ່ອີກຄັ້ງ.
- **ແຜງຄຳເຕືອນ** — ລາຍການທີ່ຢູ່ເບື້ອງຫຼັງຕົວນັບເຫຼົ່ານັ້ນ, ມີທຸກສິ່ງທີ່ການຄິດໄລ່ຄັ້ງຫຼ້າສຸດພົບ. ການກົດຈະພາທ່ານໄປທີ່ໜ້າວຽກ, ສາຍສຳພັນ ຫຼື ຊັບພະຍາກອນ. ມັນມາຈາກການຄິດໄລ່ຄັ້ງຫຼ້າສຸດ; ບໍ່ມີຫຍັງຖືກເກັບໄວ້.
- **ຂໍ້ຄວາມແຈ້ງ** — ຂໍ້ຄວາມສັ້ນກ່ຽວກັບສິ່ງທີ່ທ່ານເພິ່ງເຮັດ (ການບັນທຶກລົ້ມເຫຼວ, ສາຍສຳພັນຖືກປະຕິເສດ, ອ່ານການນຳເຂົ້າ). ພວກມັນຫາຍໄປອີກ ແລະ ບໍ່ຢູ່ໃນແຜງ.

## ແຖບສະຖານະ

ແຖບທາງລຸ່ມສະແດງ ຈາກຊ້າຍໄປຂວາ:

- **ໜ້າວຽກ:** — ຈຳນວນໜ້າວຽກຍ່ອຍສຸດທ້າຍ (ໜ້າວຽກຫຼັກບໍ່ນັບ).
- **ຫຼັກໝາຍ:** — ຈຳນວນຫຼັກໝາຍ.
- **ເສັ້ນທາງວິກິດ: N ໜ້າວຽກ, N ມື້ເຮັດວຽກ** — ຈຳນວນໜ້າວຽກວິກິດ ແລະ ໄລຍະເວລາຂອງໂຄງການ. ປາກົດພຽງຫຼັງຈາກການຄິດໄລ່.
- **ສິ້ນສຸດ:** — ວັນສິ້ນສຸດໂຄງການຈາກການຄິດໄລ່. ປາກົດພຽງຫຼັງຈາກການຄິດໄລ່; ໂຄງການຫວ່າງເປົ່າບໍ່ມີວັນສິ້ນສຸດ.
- **N ກຳນົດສົ່ງຖືກພາດ**, **N ລະເມີດເງື່ອນໄຂ**, **N ສາຍສຳພັນຂ້າມລຳດັບ** ແລະ **N ຊັບພະຍາກອນໃຊ້ງານເກີນກຳລັງ** — ແຕ່ລະອັນເປັນປຸ່ມທີ່ມີເຄື່ອງໝາຍເຕືອນ. ປາກົດພຽງເມື່ອຕົວນັບສູງກວ່າ 0 ແລະ ມີການຄິດໄລ່. ການກົດຈະເປີດແຜງ *ຄຳເຕືອນ* (ຂໍ້ຄວາມຊ່ວຍ: *ເປີດແຜງຄຳເຕືອນ (ລາຍລະອຽດ ແລະ ການນຳທາງ)*). ຖ້າທ່ານຢູ່ແຖບ *IFC* ຫຼື *ລາຍງານ*, ແອັບຈະໄປທີ່ *ໜ້າຫຼັກ* ພ້ອມກັນ, ເພາະຖັນເບື້ອງຂວາບໍ່ມີຢູ່ໃນແຖບນັ້ນ. ຕົວນັບ *ຊັບພະຍາກອນໃຊ້ງານເກີນກຳລັງ* ຍັງປ່ຽນເມື່ອມີການປ່ຽນແປງຊັບພະຍາກອນ ແລະ ການມອບໝາຍ. ຕົວນັບອື່ນປ່ຽນພຽງຫຼັງຈາກ *ຄິດໄລ່*. ຕົວນັບສີ່ອັນນີ້ເປັນພຽງຊຸດຍ່ອຍ. ສິ່ງທີ່ແຜງສະແດງເພີ່ມ (ໄລຍະນຳໜ້າທີ່ຖືກຕັດ, ສາຍສຳພັນທີ່ຖືກລະເລີຍ, ແຮມມັອກບໍ່ມີຕົວຄວບຄຸມການສິ້ນສຸດ, ວັນສິ້ນສຸດທີ່ຖືກຈຳກັດ, ຂໍ້ຜິດພາດແຜນງານ) ບໍ່ປາກົດໃນແຖບສະຖານະ.
- **ຍັງບໍ່ເປັນປັດຈຸບັນ — ຄິດໄລ່ຄືນໃໝ່ (F5)** — ມີເຄື່ອງໝາຍເຕືອນ (ຂໍ້ຄວາມຊ່ວຍ: *ແຜນງານຍັງບໍ່ເປັນປັດຈຸບັນ — ຄິດໄລ່ຄືນໃໝ່ (F5)*). ປາກົດທັນທີທີ່ທ່ານປ່ຽນສິ່ງທີ່ມີຜົນຕໍ່ແຜນງານ ແລະ ທ່ານຍັງບໍ່ໄດ້ຄິດໄລ່ຄືນໃໝ່. ຖ້າ *ຄິດໄລ່ອັດຕະໂນມັດ* ເປີດຢູ່, ມັນຈະບໍ່ປາກົດ, ຍົກເວັ້ນເມື່ອການຄິດໄລ່ໃຫ້ຂໍ້ຜິດພາດ: ໃນກໍລະນີນັ້ນມັນຈະປາກົດຢູ່.
- **ການເລືອກ: N ໜ້າວຽກ** — ຈຳນວນໜ້າວຽກທີ່ເລືອກ; ປາກົດພຽງເມື່ອມີການເລືອກ.
- **ມາດຕາສ່ວນ:** ແລະ **ຊູມ: Npx/ມື້** — ມາດຕາສ່ວນເວລາຂອງແກນເວລາ ແລະ ລະດັບການຊູມ. ມາດຕາສ່ວນຂຶ້ນກັບການຊູມ.
- **ຍັງບໍ່ໄດ້ບັນທຶກ** — ຕາບໃດທີ່ເອກະສານມີການປ່ຽນແປງທີ່ບໍ່ຢູ່ໃນໄຟລ໌.
- **AI** — ຈຸດສີທີ່ມີຄຳວ່າ AI, ປາກົດພຽງເມື່ອໂໝດ AI ເປີດຢູ່. ຂໍ້ຄວາມຊ່ວຍເວົ້າວ່າ *AI bridge:* ພ້ອມ ໜຶ່ງໃນນີ້: *ປິດ*, *ພວມເຮັດວຽກຢູ່ພອດ N*, *ພອດ N ພວມຖືກໃຊ້ງານ* ຫຼື *ເກີດຂໍ້ຜິດພາດ*. ການກົດຈະເປີດແຖບ *AI*.
- **ໜ້າຈໍແກ້ໄຂບັນຫາ** — ປຸ່ມທີ່ປາກົດພຽງເມື່ອເປີດໃຊ້ໜ້າຈໍແກ້ໄຂບັນຫາ. ມັນສະແດງ ຫຼື ເຊື່ອງໜ້າຈໍນັ້ນ (*ສະແດງໜ້າຈໍແກ້ໄຂບັນຫາ* / *ເຊື່ອງໜ້າຈໍແກ້ໄຂບັນຫາ*).

## ແຜງຄຳເຕືອນ

- **ການເປີດ** — *ການວາງແຜນ › ຕາຕະລາງເວລາ › ຄຳເຕືອນ*, *ມຸມມອງ › ແຜງຄວບຄຸມ › ຄຳເຕືອນ*, ຫຼື ຕົວນັບໃນແຖບສະຖານະ. ແຜງຢູ່ໃນຖັນເບື້ອງຂວາ, ຢູ່ລຸ່ມ *ຄຸນສົມບັດ* ແລະ ແຜງຊັບພະຍາກອນ, ແລະ ມັນຂະຫຍາຍຖັນທີ່ຖືກຫຍໍ້. ຕາມຄ່າເລີ່ມຕົ້ນ ມັນຖືກປິດຢູ່ ແລະ ບໍ່ຖືກຈື່ໄວ້ລະຫວ່າງການໃຊ້ງານ. ທ່ານລາກຄວາມສູງຂອງມັນທີ່ຂອບ ເມື່ອມັນຢູ່ລຸ່ມແຜງອື່ນ, ແລະ ຄວາມສູງນັ້ນຖືກຈື່ໄວ້. ເຄື່ອງໝາຍ × ທີ່ມຸມຂວາເທິງປິດມັນ (*ປິດຄຳເຕືອນ*).
- **ແຖວຫົວ** — *ຂໍ້ຜິດພາດ N ລາຍການ, ຄຳເຕືອນ N ລາຍການ*. ຖ້າຍັງບໍ່ໄດ້ຄິດໄລ່ຫຍັງ ມັນເວົ້າວ່າ *ຍັງບໍ່ໄດ້ຄິດໄລ່ — ກົດ ຄິດໄລ່ (F5) ເພື່ອກວດສອບ*.
- **ຄິດໄລ່** — ປຸ່ມໃນແຖວຫົວ, ປາກົດຕາບໃດທີ່ແຜນງານຍັງບໍ່ເປັນປັດຈຸບັນ ຫຼື ຍັງບໍ່ໄດ້ຄິດໄລ່. ມັນເຮັດຄືກັບ *ຄິດໄລ່* ໃນແຖບເຄື່ອງມື.
- **ເຄື່ອງໝາຍເຕືອນໃນແຖວຫົວ** — ເມື່ອແຜນງານຍັງບໍ່ເປັນປັດຈຸບັນ, ພ້ອມຂໍ້ຄວາມຊ່ວຍ *ແຜນງານຍັງບໍ່ເປັນປັດຈຸບັນ — ລາຍການນີ້ມາຈາກການຄິດໄລ່ຄັ້ງຫຼ້າສຸດ. ກະລຸນາຄິດໄລ່ຄືນໃໝ່ (F5)*. ລາຍການບໍ່ຖືກເຊື່ອງ, ພຽງແຕ່ໝາຍວ່າຍັງບໍ່ເປັນປັດຈຸບັນ.
- **ລາຍການຫວ່າງ** — *ບໍ່ມີຄຳເຕືອນ. ແຜນງານຜ່ານການກວດສອບທັງໝົດ*.
- **ແຖວ** — ດ້ານເທິງແມ່ນສະຖານທີ່ (ໜ້າວຽກ, ສາຍສຳພັນ, ຊັບພະຍາກອນ ຫຼື ໂຄງການ) ແລະ ດ້ານລຸ່ມແມ່ນຄຳອະທິບາຍ. ຂໍ້ຜິດພາດມີເຄື່ອງໝາຍແປດແຈ, ຄຳເຕືອນມີເຄື່ອງໝາຍສາມຫຼ່ຽມ. ໜ້າວຽກປາກົດເປັນ `ຊື່ WBS`. ສາຍສຳພັນປາກົດເປັນ `ໜ້າວຽກກ່ອນໜ້າ → ໜ້າວຽກຖັດໄປ (FS+2d)`, ພ້ອມປະເພດ ແລະ ຄ່າ Lag. ການກົດຈະໄປຫາສະຖານທີ່ (ຂໍ້ຄວາມຊ່ວຍ: *ໄປທີ່: …*), ເບິ່ງດ້ານລຸ່ມ. ແຖວຂອງໜ້າວຽກທີ່ກຳລັງໃຊ້ຢູ່ (ສຳລັບສາຍສຳພັນ: ໜ້າວຽກຖັດໄປຂອງມັນ) ຫຼື ຂອງຊັບພະຍາກອນທີ່ເລືອກໃນຮິສໂຕແກຣມ ຈະຖືກໄຮໄລ້.
- **ລຳດັບ** — ຂໍ້ຜິດພາດມາກ່ອນ; ຈາກນັ້ນແຕ່ລະປະເພດຕາມລຳດັບໃນລາຍການຂ້າງລຸ່ມ; ພາຍໃນປະເພດດຽວກັນ ຕາມລຳດັບໃນເອກະສານ (ສຳລັບສາຍສຳພັນ ແມ່ນຂອງໜ້າວຽກຖັດໄປ, ສຳລັບຊັບພະຍາກອນ ແມ່ນຕາມລຳດັບລາຍການຊັບພະຍາກອນ). ໜ້າວຽກ, ສາຍສຳພັນ ຫຼື ຊັບພະຍາກອນທີ່ຖືກລຶບຫຼັງການຄິດໄລ່ຄັ້ງຫຼ້າສຸດ ຈະຫາຍໄປຈາກລາຍການ.

### ປະເພດຂອງຄຳເຕືອນ

- **ຂໍ້ຜິດພາດແຜນງານ** — *ບໍ່ສາມາດຄິດໄລ່ແຜນງານໄດ້: …* ພ້ອມເຫດຜົນຕາມຫຼັງ, ເບິ່ງດ້ານລຸ່ມ. ການກົດ: ສຳລັບການເຊື່ອມໂຍງວົນລູບ ແອັບຈະເລືອກໜ້າວຽກທັງໝົດໃນວົງວົນ ແລະ ໄປທີ່ອັນທຳອິດ; ສຳລັບຂໍ້ຜິດພາດອື່ນ ບໍ່ມີບ່ອນໃຫ້ໄປ ແລະ ແຖວນັ້ນບໍ່ແມ່ນປຸ່ມ.
- **ກາຍກຳນົດສົ່ງ** — *ກາຍກຳນົດສົ່ງ {date} — ສຳເລັດໄວສຸດແມ່ນ {date}*. ໜ້າວຽກມີກຳນົດສົ່ງ ແລະ ການຄິດໄລ່ບໍ່ໄດ້ຕາມນັ້ນ. ການກົດຈະໄປທີ່ໜ້າວຽກ. ວິທີແກ້: ປັບຫຼັກເຫດຜົນ ຫຼື ໄລຍະເວລາ, ຫຼື ຍ້າຍກຳນົດສົ່ງ.
- **ລະເມີດເງື່ອນໄຂ** — *ເງື່ອນໄຂຜູກມັດ {type and date} ຖືກຂັດໂດຍຕາມຫຼັກເຫດຜົນ (float ຕິດລົບ)*. ເງື່ອນໄຂບໍ່ສາມາດບັນລຸໄດ້ໂດຍບໍ່ທຳລາຍຫຼັກເຫດຜົນ; float ເປັນລົບ. ການກົດຈະໄປທີ່ໜ້າວຽກ. ເບິ່ງ [ເງື່ອນໄຂຜູກມັດ](docs://uitleg-constraints).
- **ຂ້າມລຳດັບ** — *ຂ້າມລຳດັບ: ຄວາມຄືບໜ້າຂອງໜ້າວຽກຖັດໄປຂັດກັບສາຍສຳພັນທີ່ຕັ້ງໄວ້*. ຄວາມຄືບໜ້າຂອງໜ້າວຽກຖັດໄປບໍ່ກົງກັບປະເພດສາຍສຳພັນ, ຕົວຢ່າງ ໜ້າວຽກຖັດໄປກຳລັງດຳເນີນຢູ່ແລ້ວ ໃນຂະນະທີ່ໜ້າວຽກກ່ອນໜ້າຍັງບໍ່ແລ້ວ ພາຍໃຕ້ສາຍສຳພັນ ສຳເລັດ-ເລີ່ມຕົ້ນ. ການກົດຈະເລືອກທັງສອງໜ້າວຽກ ໂດຍໜ້າວຽກຖັດໄປເປັນໜ້າວຽກທີ່ໃຊ້ຢູ່. ກວດວັນທີຕົວຈິງ ຫຼື ສາຍສຳພັນ.
- **ໄລຍະນຳໜ້າຖືກຕັດ** — *ໄລຍະນຳໜ້າ (Lead) ຖືກຕັດເນື່ອງຈາກວັນເລີ່ມໂຄງການ — ສາຍສຳພັນບໍ່ຖືກນຳໃຊ້ຢ່າງຄົບຖ້ວນ*. ໄລຍະນຳໜ້າ (ຄ່າ Lag ລົບ) ຂອງສາຍສຳພັນ ຢຽດໄປກ່ອນວັນເລີ່ມຕົ້ນໂຄງການ. ການກົດຈະເລືອກໜ້າວຽກທັງສອງ.
- **ລະເລີຍສາຍສຳພັນ** — *ລະເລີຍສາຍສຳພັນ: ໜ້າວຽກກ່ອນໜ້າ ຫຼື ໜ້າວຽກຖັດໄປຂາດຫາຍ ຫຼື ບໍ່ແມ່ນໜ້າວຽກຍ່ອຍສຸດທ້າຍ*. ການຄິດໄລ່ບໍ່ໃຊ້ສາຍສຳພັນນີ້. ການກົດຈະເລືອກໜ້າວຽກທີ່ຍັງມີຢູ່. ເບິ່ງ [ສາຍສຳພັນ](docs://uitleg-relaties).
- **ແຮມມັອກບໍ່ມີຕົວຄວບຄຸມການສິ້ນສຸດ** — *ໜ້າວຽກ Hammock ບໍ່ມີຕົວກຳນົດວັນສິ້ນສຸດ (ບໍ່ມີໜ້າວຽກກ່ອນໜ້າແບບ FF/SF): ໄລຍະເວລາຈຶ່ງປັບເປັນສູນ*. ການກົດຈະໄປທີ່ໜ້າວຽກ. ເບິ່ງ [ໜ້າວຽກແຮມມັອກ](docs://howto-hammock).
- **ວັນສິ້ນສຸດຖືກຈຳກັດ** — *ວັນສິ້ນສຸດຖືກຈຳກັດ: ປະຕິທິນບໍ່ມີຊ່ວງເວລາເຮັດວຽກທີ່ເຫຼືອໃຫ້ໜ້າວຽກນີ້*. ການຄິດໄລ່ໄປຮອດຂີດຈຳກັດຂອງຈຳນວນມື້ທີ່ມັນຄົ້ນຫາ, ຕົວຢ່າງ ເພາະມີຊ່ວງມື້ພັກຍາວຕໍ່ເນື່ອງໃນປະຕິທິນ. ການກົດຈະໄປທີ່ໜ້າວຽກ. ເບິ່ງ [ປະຕິທິນ ແລະ ມື້ເຮັດວຽກ](docs://uitleg-kalenders).
- **ໃຊ້ງານເກີນກຳລັງ** — *ໃຊ້ງານເກີນກຳລັງເປັນເວລາ N ມື້ ({first} – {last})*, ພ້ອມ *ຊັບພະຍາກອນນີ້ບໍ່ເຮັດວຽກໃນມື້ເຫຼົ່ານີ້ຕາມປະຕິທິນຂອງມັນ* ຖ້າທຸກມື້ເປັນມື້ພັກ, ຫຼື *ໃນນັ້ນ N ມື້ ຊັບພະຍາກອນນີ້ບໍ່ເຮັດວຽກຕາມປະຕິທິນຂອງມັນ* ສຳລັບກໍລະນີປະສົມ. ການກົດຈະເລືອກໜ້າວຽກທີ່ມີການມອບໝາຍໃຫ້ຊັບພະຍາກອນນັ້ນ, ເປີດຮິສໂຕແກຣມ ແລະ ເລືອກຊັບພະຍາກອນນັ້ນໃນມັນ; ຈາກ *ຕາຕະລາງ*, *IFC* ຫຼື *ລາຍງານ* ແອັບຈະໄປທີ່ *ຊັບພະຍາກອນ*. ເບິ່ງ [ແຜງຊັບພະຍາກອນ](docs://ref-resourcepaneel).

### ເຫດຜົນຂອງຂໍ້ຜິດພາດແຜນງານ

- *ມີສາຍພົວພັນວົນລູບລະຫວ່າງໜ້າວຽກ: {path}* — ສາຍສຳພັນສ້າງເປັນການເຊື່ອມໂຍງວົນລູບ. ໜ້າວຽກຢູ່ໃນເສັ້ນທາງ; ປ່ຽນທິດທາງ ຫຼື ລຶບສາຍສຳພັນໜຶ່ງອັນ.
- *ປະຕິທິນບໍ່ມີການກຳນົດມື້ເຮັດວຽກ* — ກຳນົດມື້ເຮັດວຽກໃຫ້ປະຕິທິນຢ່າງໜ້ອຍໜຶ່ງມື້, ເບິ່ງ [ຊ່ວງເວລາຂອງປະຕິທິນ](docs://ref-kalenders).
- *ໄລຍະເວລາເປັນມື້ບໍ່ຖືກຕ້ອງສຳລັບໜ້າວຽກ '{task}'* ແລະ *ໄລຍະເວລາເປັນຊົ່ວໂມງບໍ່ຖືກຕ້ອງສຳລັບໜ້າວຽກ '{task}'* — ໄລຍະເວລາຂອງໜ້າວຽກບໍ່ແມ່ນຕົວເລກທີ່ຖືກຕ້ອງ.
- *ໜ້າວຽກລາຍຊົ່ວໂມງ '{task}' ບໍ່ມີຊົ່ວໂມງເຮັດວຽກທີ່ຖືກຕ້ອງໃນປະຕິທິນ* — ໜ້າວຽກລາຍຊົ່ວໂມງ ຢູ່ໃນປະຕິທິນທີ່ບໍ່ມີຊົ່ວໂມງເຮັດວຽກ.
- *ວັນເລີ່ມຕົ້ນບໍ່ຖືກຕ້ອງສຳລັບໜ້າວຽກ '{task}'* — ວັນເລີ່ມຕົ້ນຂອງໜ້າວຽກບໍ່ຖືກຕ້ອງ.

## ການແຈ້ງເຕືອນ

ການແຈ້ງເຕືອນປາກົດຢູ່ດ້ານລຸ່ມຂອງໜ້າຈໍ, ໃນຕາຕະລາງ, ໃນ Backstage ແລະ ໃນໂໝດການນຳສະເໜີ. ການແຈ້ງເຕືອນແມ່ນ *ຂໍ້ຜິດພາດ* ຫຼື *ຂໍ້ມູນ*. ຂໍ້ຜິດພາດຈະຢູ່ຈົນກວ່າທ່ານຈະຄລິກເພື່ອປິດ. ຂໍ້ມູນຈະຫາຍໄປຫຼັງຈາກ 5 ວິນາທີ, ແລະ ຕົວນັບເວລາຈະເລີ່ມໃໝ່ທຸກຄັ້ງທີ່ຊຸດການແຈ້ງເຕືອນປ່ຽນແປງ. ການຄລິກໃສ່ການແຈ້ງເຕືອນຈະປິດມັນ (ຄຳແນະນຳ *ປິດການແຈ້ງເຕືອນ*). ສູງສຸດສາມອັນປາກົດພ້ອມກັນ. ຖ້າອັນທີສີ່ເຂົ້າມາ, ຂໍ້ມູນທີ່ເກົ່າທີ່ສຸດຈະອອກກ່ອນ. ຖ້າບໍ່ມີຂໍ້ມູນ, ການແຈ້ງເຕືອນທີ່ເກົ່າທີ່ສຸດຈະອອກກ່ອນ, ດັ່ງນັ້ນ ຂໍ້ຜິດພາດຈະບໍ່ຖືກດັນອອກໂດຍຂໍ້ມູນ. ຊຸດການແຈ້ງເຕືອນຈະຍ້າຍອອກຈາກປຸ່ມຂອງກ່ອງໂຕ້ຕອບທີ່ເປີດຢູ່ ແລະ ຈາກແຖບປຸ່ມດຳເນີນການທີ່ຕິດຢູ່.

- **ຕົວນັບ ×N** — ການແຈ້ງເຕືອນທີ່ມີຄີທີ່ຄົງທີ່ຈະລວມການເກີດຊ້ຳເປັນແຖວດຽວພ້ອມຕົວນັບ, ເຊັ່ນ ຂໍ້ຜິດພາດການບັນທຶກທີ່ກັບມາຊ້ຳ ຫຼື ສາຍສຳພັນທີ່ຖືກປະຕິເສດທີ່ທ່ານເຮັດຊ້ຳ. ບໍ່ແມ່ນທຸກການແຈ້ງເຕືອນທີ່ເຮັດແບບນັ້ນ.
- **ອ່ານເພີ່ມເຕີມ** — ບາງການແຈ້ງເຕືອນມີການເຊື່ອມຕໍ່ *ອ່ານເພີ່ມເຕີມ* ຫຼື ຫົວຂໍ້ຂອງຕົນເອງ (ເຊັ່ນ *ຄຳອະທິບາຍກົດເກນວຽກ*) ທີ່ນຳໄປຫາຄູ່ມືໃນ Backstage › ຊ່ວຍເຫຼືອ.
- **ປຸ່ມດຳເນີນການ** — ການແຈ້ງເຕືອນກ່ຽວກັບໂປຣໄຟລ໌ການຄິດໄລ່ມີປຸ່ມ *ເປີດໂປຣໄຟລ໌ການຄິດໄລ່* ທີ່ນຳໄປຫາ ຂໍ້ມູນໂຄງການ.

ລາຍການຂ້າງລຸ່ມນີ້ເປັນບາງສ່ວນທີ່ເລືອກມາ, ຈັດກຸ່ມຕາມຫົວຂໍ້. ບ່ອນທີ່ບໍ່ໄດ້ບອກໄວ້ເປັນຢ່າງອື່ນ, ມັນເປັນຂໍ້ມູນ.

### ການບັນທຶກ, ການເປີດ ແລະ ການກູ້ຄືນ

- **ການບັນທຶກບໍ່ສຳເລັດ** (ຂໍ້ຜິດພາດ) — *ບັນທຶກບໍ່ສຳເລັດ* ພ້ອມເຫດຜົນຢູ່ດ້ານລຸ່ມ. ເມື່ອບັນທຶກ, ບັນທຶກເປັນ ແລະ ສົ່ງອອກລາຍງານ.
- **ບັນທຶກເປັນການດາວໂຫລດ** (ຂໍ້ມູນ) — *ບັນທຶກເປັນການດາວໂຫລດ: '{name}' ຢູ່ໃນໂຟນເດີດາວໂຫລດຂອງທ່ານແລ້ວ. …* ໃຊ້ກັບ *ບັນທຶກເປັນ* ແລະ ການສົ່ງອອກ, ເມື່ອສະພາບແວດລ້ອມບໍ່ໃຫ້ແອັບຂຽນໂດຍກົງໄປຍັງບ່ອນທີ່ທ່ານເລືອກ. ການດາວໂຫລດສອງຄັ້ງຕິດກັນຈະລວມເປັນໜຶ່ງ.
- **ບັນທຶກເປັນການດາວໂຫລດ (ຄຳອະທິບາຍ)** (ຂໍ້ມູນ) — *ບັນທຶກເປັນການດາວໂຫລດ: '{name}' ຢູ່ໃນໂຟນເດີດາວໂຫລດຂອງທ່ານ. ເບຣາວເຊີນີ້ບໍ່ໃຫ້ແອັບຂຽນໄປບ່ອນຂອງຕົນເອງ, …* ໃຊ້ກັບ *ບັນທຶກ* ໃນເບຣາວເຊີທີ່ບັນທຶກໄດ້ພຽງແຕ່ຜ່ານການດາວໂຫລດ. ສະແດງໜຶ່ງຄັ້ງຕໍ່ເຊດຊັນ, ພ້ອມການເຊື່ອມຕໍ່ໄປຫາຄຳອະທິບາຍກ່ຽວກັບໄຟລ໌.
- **ເບຣາວເຊີບໍ່ຂຽນກັບຄືນ** (ຂໍ້ມູນ) — *ເບຣາວເຊີນີ້ບໍ່ໃຫ້ແອັບຂຽນກັບຄືນໄປຍັງ '{name}'. …* ໃຊ້ກັບ *ບັນທຶກ* ຂອງໂຄງການທີ່ມີໄຟລ໌, ເມື່ອເບຣາວເຊີຕ້ອງຂໍບ່ອນເກັບອີກຄັ້ງ. ສະແດງໜຶ່ງຄັ້ງຕໍ່ເຊດຊັນ, ພ້ອມການເຊື່ອມຕໍ່ໄປຫາຄຳອະທິບາຍກ່ຽວກັບໄຟລ໌.
- **ການບັນທຶກອັດຕະໂນມັດບໍ່ສຳເລັດ** (ຂໍ້ຜິດພາດ) — *ການບັນທຶກອັດຕະໂນມັດບໍ່ສຳເລັດ* ພ້ອມເຫດຜົນ. ໃຊ້ກັບການບັນທຶກອັດຕະໂນມັດລົງໄຟລ໌ ແລະ ລະບົບກູ້ຄືນຂໍ້ມູນ.
- **ບັນທຶກຄັງຂໍ້ມູນບໍ່ສຳເລັດ** (ຂໍ້ຜິດພາດ) — *ບໍ່ສາມາດບັນທຶກຄັງຂໍ້ມູນໄດ້*, ເມື່ອບັນທຶກຄັງຂໍ້ມູນ.
- **ການເປີດໄຟລ໌ບໍ່ສຳເລັດ** (ຂໍ້ຜິດພາດ) — *ບໍ່ສາມາດເປີດໄຟລ໌ໄດ້* ພ້ອມເຫດຜົນ. ຕົວຢ່າງເຊັ່ນ ໄຟລ໌ທີ່ເປີດຫຼ້າສຸດ ຫຼື ໄຟລ໌ທີ່ນຳເຂົ້າມາ.
- **ໄຟລ໌ .mpp ເກົ່າ ຫຼື ມີການປ້ອງກັນ** (ຂໍ້ຜິດພາດ) — *ໄຟລ໌ .mpp ນີ້ໃຊ້ຮູບແບບເກົ່າ (Project 2007 ຫຼື ກ່ອນໜ້ານັ້ນ)…* ຫຼື *ໄຟລ໌ .mpp ນີ້ມີການປ້ອງກັນດ້ວຍລະຫັດຜ່ານ…*, ທັງສອງຈະແນະນຳໃຫ້ສົ່ງອອກເປັນ XML ໃນ MS Project ແລ້ວເປີດໄຟລ໌ນັ້ນ.
- **ໄຟລ໌ XER ບໍ່ຖືກຕ້ອງ** (ຂໍ້ຜິດພາດ) — ໜຶ່ງໃນຂໍ້ຄວາມ *XER…*, ເຊັ່ນ *ນີ້ບໍ່ແມ່ນໄຟລ໌ XER ທີ່ຖືກຕ້ອງ ຫຼື ບໍ່ຮອງຮັບ*. ຫຼື *ໄຟລ໌ XER ມີຕາຕະລາງຊ້ຳຊ້ອນ*, ພ້ອມເຫດຜົນທີ່ເພີ່ມເຂົ້າມາ.
- **ອ່ານໄຟລ໌ IFC ບໍ່ໄດ້** (ຂໍ້ຜິດພາດ) — *ບໍ່ສາມາດອ່ານໄຟລ໌ IFC ໄດ້* ພ້ອມເຫດຜົນ, ໃນມຸມມອງ IFC.
- **ການກູ້ຄືນ** (ຂໍ້ຜິດພາດ) — *ບໍ່ສາມາດອ່ານໄຟລ໌ທີ່ກູ້ຄືນມາໄດ້*, *ການກູ້ຄືນຂໍ້ມູນບໍ່ສຳເລັດ* ແລະ *ບໍ່ສາມາດໂຫຼດໄຟລ໌ກູ້ຄືນໄດ້ N ໄຟລ໌ ແລະ ໄດ້ຂ້າມໄປ*. ເມື່ອກູ້ຄືນຫຼັງຈາກແອັບປິດລົງຢ່າງບໍ່ຄາດຄິດ.
- **ບັນທຶກກິ່ງງ່າເປັນແມ່ແບບ** (ຂໍ້ມູນ) — *ບັນທຶກກິ່ງງ່າເປັນແມ່ແບບ '{name}' ແລ້ວ*.
- **ຂໍ້ຄວາມຈາກສ່ວນເສີມ** (ຂໍ້ມູນ, ຫຼື ຂໍ້ຜິດພາດ ຖ້າສ່ວນເສີມລາຍງານຂໍ້ຜິດພາດ) — *ສ່ວນເສີມ {name}: {message}*. ສ່ວນເສີມສາມາດສະແດງໄດ້ສູງສຸດສາມອັນໃໝ່ຕໍ່ 10 ວິນາທີ, ເພື່ອບໍ່ໃຫ້ເຕັມຊຸດການແຈ້ງເຕືອນ. ຖ້າຂັ້ນຕອນໜຶ່ງໃນຄູ່ມືຂອງສ່ວນເສີມບໍ່ສຳເລັດ, ມັນຈະບອກວ່າ *ຂັ້ນຕອນຈາກສ່ວນເສີມ {name} ບໍ່ສຳເລັດ. ຄູ່ມືຈະດຳເນີນຕໍ່ໄປ*, ແລະ ຖ້າໄຟລ໌ໂຄງການຂອງສ່ວນເສີມບໍ່ສາມາດເປີດໄດ້, ມັນຈະບອກວ່າ *ບໍ່ສາມາດເປີດໄຟລ໌ໂຄງການ {file} ຈາກສ່ວນເສີມ {name} ໄດ້*. ທັງສອງເປັນຂໍ້ຜິດພາດ.
- **ມີການປ່ຽນແປງເຂົ້າມາລະຫວ່າງ** (ຂໍ້ມູນ) — *ມີການປ່ຽນແປງໂດຍຕົວຊ່ວຍ AI ຫຼື ສ່ວນເສີມເຂົ້າມາລະຫວ່າງ. …* ເມື່ອທ່ານຍົກເລີກກ່ອງໂຕ້ຕອບໜ້າວຽກ ໃນຂະນະທີ່ຕົວຊ່ວຍ AI ຫຼື ສ່ວນເສີມໄດ້ປ່ຽນແປງບາງຢ່າງໃນຊ່ວງເວລານັ້ນ: ການແກ້ໄຂໜ້າວຽກຈາກກ່ອນການປ່ຽນແປງນັ້ນຈະບໍ່ຖືກກັບຄືນ ແລະ ຍັງຄົງເປັນຂັ້ນຕອນທຳມະດາພາຍໃຕ້ *ຍົກເລີກຄຳສັ່ງ*.

### ການຄິດໄລ່

- **ບໍ່ສາມາດຄິດໄລ່ແຜນງານໄດ້** (ຂໍ້ຜິດພາດ) — *ບໍ່ສາມາດຄິດໄລ່ແຜນງານໄດ້* ພ້ອມເຫດຜົນຢູ່ດ້ານລຸ່ມ (ເບິ່ງ *ເຫດຜົນຂອງຂໍ້ຜິດພາດແຜນງານ*). ເມື່ອກົດ *ຄິດໄລ່*, ເມື່ອສະຫຼັບເອກະສານ ແລະ ເມື່ອເປີດໄຟລ໌.
- **ຕັ້ງວັນທີສະຖານະເປັນມື້ນີ້** (ຂໍ້ມູນ) — *ຍັງບໍ່ທັນມີວັນທີສະຖານະ: ລະບົບໄດ້ຕັ້ງເປັນມື້ນີ້ ({date}) ແລ້ວ ເນື່ອງຈາກຄວາມຄືບໜ້າຈະຖືກວັດແທກຮອດວັນທີສະຖານະ. ທ່ານສາມາດປ່ຽນໄດ້ທີ່ ການວາງແຜນ → ວັນທີສະຖານະ*. ເມື່ອປ້ອນຄວາມຄືບໜ້າໃນໂຄງການທີ່ບໍ່ມີວັນທີສະຖານະ.
- **ໄລຍະເວລາສັ້ນກວ່າວຽກທີ່ເຮັດແລ້ວ** (ຂໍ້ມູນ) — *‘{name}’ ສຳເລັດແລ້ວ {N}%: ໄລຍະເວລາບໍ່ສາມາດສັ້ນກວ່າວຽກທີ່ເຮັດສຳເລັດໄປແລ້ວ. ໄລຍະເວລາຈຶ່ງບໍ່ຖືກປ່ຽນແປງ*.

### ສາຍສຳພັນ ແລະ ລຳດັບຊັ້ນ

- **ສ້າງສາຍສຳພັນແລ້ວ** (ຂໍ້ມູນ) — *ສ້າງສາຍສຳພັນແລ້ວ: {predecessor} → {successor}*.
- **ປະຕິເສດສາຍສຳພັນ** (ຂໍ້ມູນ) — *ມີສາຍສຳພັນນັ້ນຢູ່ແລ້ວ*, *ບໍ່ອະນຸຍາດໃຫ້ສ້າງສາຍສຳພັນລະຫວ່າງໜ້າວຽກຍ່ອຍ ກັບ ໜ້າວຽກຫຼັກຂອງມັນເອງ*. ຫຼື *ສາຍສຳພັນນີ້ຈະເຮັດໃຫ້ເກີດການເຊື່ອມໂຍງວົນລູບໃນແຜນງານ ({cycle}) ຈຶ່ງບໍ່ຖືກສ້າງ*. ການເຊື່ອມໂຍງວົນລູບບອກຊື່ໜ້າວຽກ, ດັ່ງນັ້ນ ທ່ານຮູ້ວ່າຕ້ອງລຶບ ຫຼື ປີ້ນສາຍສຳພັນໃດກ່ອນ.
- **ປະຕິເສດການຍ້າຍ** (ຂໍ້ມູນ) — *ການຍ້າຍນີ້ຈະເຮັດໃຫ້ເກີດການເຊື່ອມໂຍງວົນລູບ ({cycle}): ສາຍສຳພັນຂອງໜ້າວຽກຫຼັກຈະສົ່ງຜົນຕໍ່ໜ້າວຽກຍ່ອຍນຳ. ບໍ່ມີສິ່ງໃດຖືກຍ້າຍ*.
- **ສາຍສຳພັນຫາຍໄປຫຼັງຈາກຍ້າຍ** (ຂໍ້ມູນ) — *ຫຼັງຈາກຍ້າຍ, ມີ N ສາຍສຳພັນທີ່ເຊື່ອມໜ້າວຽກຍ່ອຍໃສ່ໜ້າວຽກຫຼັກຂອງມັນເອງ; ຈຶ່ງບໍ່ນຳມາຄິດໄລ່ອີກຕໍ່ໄປ*.
- **ຂ້າມສາຍສຳພັນເມື່ອແຊກ** (ຂໍ້ມູນ) — *N ສາຍສຳພັນບໍ່ຖືກສ້າງ: ສາຍສຳພັນບໍ່ຖືກຕ້ອງ…*, ເມື່ອວາງ ຫຼື ແຊກກິ່ງງ່າ.
- **ສາຍສຳພັນບໍ່ຖືກນັບຫຼັງນຳເຂົ້າ** (ຂໍ້ມູນ) — *ບໍ່ສາມາດນຳ N ສາຍສຳພັນມາຮ່ວມຄິດໄລ່ໄດ້. ກະລຸນາກວດສອບຖັນ ໜ້າວຽກກ່ອນໜ້າ (Predecessors) ແລະ ໜ້າວຽກຖັດໄປ (Successors)*.
- **id ຊ້ຳກັນຫຼັງນຳເຂົ້າ** (ຂໍ້ມູນ) — *ອົບເຈັກທີ່ມີ id ຊ້ຳກັນໃນໄຟລ໌ນີ້: N. ພວກມັນໄດ້ຮັບ id ຂອງຕົນເອງ…*

### ການແກ້ໄຂໜ້າວຽກ

- **ບັນທຶກວັນເລີ່ມເປັນເງື່ອນໄຂ** (ຂໍ້ມູນ) — *'{name}' ມີໜ້າວຽກກ່ອນໜ້າ: ວັນເລີ່ມຕົ້ນໃໝ່ກາຍເປັນເງື່ອນໄຂເລີ່ມຕົ້ນບໍ່ກ່ອນໜ້າ (SNET) ໃນວັນທີ {date}. ຫຼັງຈາກຄິດໄລ່ຄືນ (F5) ໜ້າວຽກຈະບໍ່ເລີ່ມກ່ອນວັນນັ້ນ*. ເມື່ອທ່ານປ່ຽນວັນເລີ່ມຕົ້ນຂອງໜ້າວຽກທີ່ມີໜ້າວຽກກ່ອນໜ້າ. ຖ້າໜ້າວຽກນັ້ນມີເງື່ອນໄຂແບບນັ້ນຢູ່ແລ້ວ, ການແຈ້ງເຕືອນຈະບອກວ່າມັນຖືກຍ້າຍ. ຖ້າຫຼາຍໜ້າວຽກພ້ອມກັນ, ມັນຈະໃຫ້ຈຳນວນ.
- **ວັນເລີ່ມຕົ້ນບໍ່ຖືກນຳໃຊ້** (ຂໍ້ມູນ) — *ວັນເລີ່ມຕົ້ນໃໝ່ຂອງ '{name}' ບໍ່ຖືກນຳໃຊ້: ໜ້າວຽກມີໜ້າວຽກກ່ອນໜ້າ ແລະ ເງື່ອນໄຂ {type} {date}, ແລະ ສອງຢ່າງນີ້ກຳນົດວັນເລີ່ມຕົ້ນຂອງມັນ. ປ່ຽນເງື່ອນໄຂນັ້ນເພື່ອຍ້າຍວັນເລີ່ມຕົ້ນ*.
- **ປະຕິເສດການປ່ຽນເປັນຫຼັກໝາຍ** (ຂໍ້ມູນ) — *'{task}' ໜ້າວຽກມີການມອບໝາຍຊັບພະຍາກອນຢູ່ ຈຶ່ງບໍ່ສາມາດປ່ຽນເປັນຫຼັກໝາຍ (milestone) ໄດ້. ກະລຸນາຍົກເລີກການມອບໝາຍຊັບພະຍາກອນກ່ອນ*. ຫຼື *'{task}' ໜ້າວຽກເປັນໜ້າວຽກຫຼັກທີ່ມີໜ້າວຽກຍ່ອຍ ຈຶ່ງບໍ່ສາມາດປ່ຽນເປັນຫຼັກໝາຍ (milestone) ໄດ້*. ເມື່ອປ່ຽນໃນກ່ອງໂຕ້ຕອບໜ້າວຽກ, ແຜງຄຸນສົມບັດ, ເມນູບໍລິບົດ ແລະ ຕາຕະລາງ.
- **ການມອບໝາຍຖືກຍ້າຍໄປໜ້າວຽກຍ່ອຍ** (ຂໍ້ມູນ) — *ການມອບໝາຍ {count} ລາຍການ ({resources}) ຖືກຍ້າຍຈາກ '{phase}' ໄປຍັງໜ້າວຽກຍ່ອຍໃໝ່ '{child}': ເນື່ອງຈາກໜ້າວຽກຫຼັກບໍ່ສາມາດມີການມອບໝາຍຊັບພະຍາກອນເອງໄດ້*. ເມື່ອໜ້າວຽກທີ່ມີການມອບໝາຍໄດ້ຮັບໜ້າວຽກຍ່ອຍ.
- **ລຶບສະຖານະຫຼັກໝາຍອອກ** (ຂໍ້ມູນ) — *{count} ຫຼັກໝາຍຕອນນີ້ມີໜ້າວຽກຍ່ອຍແລ້ວ ແລະ ໄດ້ກາຍເປັນໜ້າວຽກຫຼັກ; ສະຖານະຫຼັກໝາຍຈຶ່ງຖືກຍົກເລີກ*.
- **ປະຕິເສດໜ້າວຽກຫຼັກ** (ຂໍ້ມູນ) — *'{phase}' ບໍ່ສາມາດກາຍເປັນໜ້າວຽກຫຼັກ: …* ພ້ອມເຫດຜົນ, ແລະ *ບໍ່ມີສິ່ງໃດຖືກປ່ຽນແປງ.*
- **ຂ້າມຫ້ອງເມື່ອວາງ** (ຂໍ້ມູນ) — *ຂ້າມ N ຫ້ອງ: ເນື່ອງຈາກເປັນຫ້ອງທີ່ອ່ານຢ່າງດຽວ (ເຊັ່ນ: ລະຫັດ WBS ອັດຕະໂນມັດ ຫຼື ຖັນທີ່ຄິດໄລ່)*.
- **ການອ້າງອີງຖືກລຶບເມື່ອວາງ** (ຂໍ້ມູນ) — *N ການອ້າງອີງບໍ່ມີຢູ່ໃນເອກະສານນີ້ ແລະ ຖືກລຶບລ້າງແລ້ວ (ປະຕິທິນໜ້າວຽກ, ປະເພດໜ້າວຽກກຳນົດເອງ, ລະຫັດກິດຈະກຳ ຫຼື ຊ່ອງກຳນົດເອງຈາກເອກະສານຕົ້ນທາງ)*.
- **ກົດເກນວຽກປັບໄລຍະເວລາ** (ຂໍ້ມູນ) — *ຫຼັງຈາກປ່ຽນປະຕິທິນ, ກົດເກນວຽກໄດ້ປັບໄລຍະເວລາຂອງ N ໜ້າວຽກ (ປະລິມານວຽກເທົ່າເດີມ, ແຕ່ຊົ່ວໂມງຕໍ່ມື້ປ່ຽນໄປ)*. ມີການເຊື່ອມຕໍ່ *ຄຳອະທິບາຍກົດເກນວຽກ*.

### Primavera (XER)

- **ເປີດໄຟລ໌ XER ແລ້ວ** (ຂໍ້ມູນ) — *ເປີດໄຟລ໌ XER ສຳເລັດ: ເອກະສານໂຄງການ N ລາຍການ*. ໜຶ່ງການແຈ້ງເຕືອນຕໍ່ໄຟລ໌, ເຖິງແມ່ນໄຟລ໌ເປີດຫຼາຍໂຄງການ, ພ້ອມການເຊື່ອມຕໍ່ *ອ່ານເພີ່ມເຕີມ* ແລະ ແຖວລາຍລະອຽດຢູ່ດ້ານລຸ່ມ. ສະເໝີ *ພົບ N ໂຄງການ*. ສະເພາະເມື່ອຕົວເລກຫຼາຍກວ່າ 0: *ຂ້າມ N ໂຄງການທີ່ວ່າງເປົ່າ*, *ບໍ່ລວມ N ໂຄງການແຜນຫຼັກ (baseline)*, *ສ້າງແຜນຫຼັກ (baseline) ສຳເລັດ N ລາຍການ*, *ລະເລີຍການອ້າງອີງແຜນຫຼັກທີ່ບໍ່ມີຢູ່ N ລາຍການ*, *ມີການນຳໃຊ້ແຜນຫຼັກສຳຮອງເພື່ອປ້ອງກັນຂໍ້ຜິດພາດ* ແລະ *ຮັກສາສາຍສຳພັນພາຍນອກໄວ້ N ລາຍການ*. ສະເພາະການເຂົ້າລະຫັດທີ່ບໍ່ແມ່ນ UTF-8: *ການເຂົ້າລະຫັດຂໍ້ຄວາມທີ່ເລືອກ: {encoding}*. ນອກຈາກນັ້ນ, ເມື່ອຕົວເລກຫຼາຍກວ່າ 0: *ພົບບັນຫາໃນການອ່ານໄຟລ໌ N ຈຸດ*, *ພົບບັນຫາກ່ຽວກັບປະຕິທິນ N ຈຸດ*, *ພົບບັນຫາຮູບແບບຕົວເລກ N ຈຸດ*, *ປ່ຽນໄປໃຊ້ຄ່າເລີ່ມຕົ້ນ N ຄ່າ* ແລະ *ການຕັ້ງຄ່າຕາຕະລາງ P6 ໃຊ້ຄ່າສຳຮອງທີ່ປອດໄພ N ລາຍການ*.
- **ວັນທີຕາມທີ່ Primavera ບັນທຶກໄວ້** (ແຖວລາຍລະອຽດໃນການແຈ້ງເຕືອນດຽວກັນ) — *N ໜ້າວຽກສະແດງວັນທີຕາມທີ່ Primavera ບັນທຶກໄວ້ (ບໍ່ໄດ້ຄິດໄລ່ຄືນໃໝ່)*, ຫຼື ຖ້າໂໝດບໍ່ໄດ້ເປີດ, *N ໜ້າວຽກແຕກຕ່າງຈາກວັນທີໃນໄຟລ໌ — ທ່ານສາມາດເລືອກສະແດງໄດ້*.
- **ໄຟລ໌ເກັບ XER ບໍ່ສາມາດໃຊ້ໄດ້** (ຂໍ້ມູນ) — *ໄຟລ໌ເກັບຕົ້ນສະບັບ XER ໃນໄຟລ໌ນີ້ບໍ່ສາມາດໃຊ້ງານໄດ້ ແລະ ຖືກລະເວັ້ນໄວ້; ຕົວໂຄງການເອງສາມາດເປີດໄດ້ຄົບຖ້ວນ*. ພ້ອມເຫດຜົນ (ຕົວຢ່າງເຊັ່ນ *ສາເຫດ: ຄ່າ checksum ບໍ່ກົງກັບໄຟລ໌ຕົ້ນສະບັບ — ໄຟລ໌ເກັບເສຍຫາຍ*) ແລະ ຜົນທີ່ຕາມມາ (*ແຜນງານ, ໂປຣໄຟລ໌ການຄິດໄລ່ ແລະ ຂໍ້ມູນໂຄງການທັງໝົດຈາກ IFC ຍັງຄົບຖ້ວນ. …*). ເມື່ອເປີດໄຟລ໌ IFC ທີ່ໄຟລ໌ເກັບຕົ້ນສະບັບ XER ທີ່ບັນທຶກໄວ້ກ່ອນໜ້ານີ້ບໍ່ສາມາດໃຊ້ໄດ້.
- **ການສົ່ງອອກສູນເສຍຂໍ້ມູນ XER** (ຂໍ້ມູນ) — *ການສົ່ງອອກເປັນ {format} ຈະສູນເສຍຂໍ້ມູນຕົ້ນສະບັບຂອງ XER*. ຫຼັງຈາກສົ່ງອອກສຳເລັດເປັນຮູບແບບອື່ນນອກຈາກ IFC ຂອງໂຄງການທີ່ມີຂໍ້ມູນທີ່ມີຢູ່ໃນໄຟລ໌ XER ເທົ່ານັ້ນ. ມີການເຊື່ອມຕໍ່ *ອ່ານເພີ່ມເຕີມ*.

### ການນຳເຂົ້າ, ການສົ່ງອອກ ແລະ ໂປຣໄຟລ໌ການຄິດໄລ່

- **ວັນທີຕາມໄຟລ໌** (ຂໍ້ມູນ) — *N ໜ້າວຽກສະແດງວັນທີຕາມທີ່ບັນທຶກໃນໄຟລ໌ (ບໍ່ໄດ້ຄິດໄລ່ຄືນໃໝ່)*, ຫຼື *N ໜ້າວຽກແຕກຕ່າງຈາກວັນທີໃນໄຟລ໌ — ທ່ານສາມາດເລືອກສະແດງໄດ້*. ເມື່ອເປີດໄຟລ໌ທີ່ມີວັນທີທີ່ບັນທຶກໄວ້.
- **ປະລິມານວຽກ ແລະ ກົດເກນວຽກທີ່ເຫັນໄດ້** (ຂໍ້ມູນ) — *ໄຟລ໌ນີ້ມີປະລິມານວຽກທີ່ບັນທຶກໄວ້ ຫຼື ກົດເກນວຽກທີ່ກຳນົດເອງ; ກົດເກນວຽກ ແລະ ວຽກທີ່ເຫຼືອຈະສະແດງຂຶ້ນສຳລັບໂຄງການນີ້*.
- **ການອ່ານແຜນງານ MS Project** (ຂໍ້ມູນ) — *ໄຟລ໌ MS Project ນີ້ມີ N ໜ້າວຽກທີ່ຖືກແບ່ງຊ່ວງ, ປັບສົມດຸນຊັບພະຍາກອນ ຫຼື ຂັບເຄື່ອນດ້ວຍຊັບພະຍາກອນ. ລະບົບໄດ້ນຳເຂົ້າ ແລະ ສະແດງຜົນຕາມນັ້ນ*.
- **ຊ່ວງພັກບໍ່ຖືກສົ່ງອອກ** (ຂໍ້ມູນ) — *N ໜ້າວຽກທີ່ມີຊ່ວງພັກຖືກສົ່ງອອກໂດຍບໍ່ມີຊ່ວງພັກ: ເນື່ອງຈາກ MS Project/P6 ຮອງຮັບຊ່ວງພັກໃນຮູບແບບການກະຈາຍວຽກເທົ່ານັ້ນ*. ເມື່ອສົ່ງອອກໄປ MS Project ຫຼື Primavera.
- **ວັນເລີ່ມຕົ້ນໂຄງການຖືກຍ້າຍ** (ຂໍ້ມູນ) — *ວັນເລີ່ມຕົ້ນໂຄງການຖືກຍ້າຍ: ຈຸດຍຶດໜ້າວຽກ N ລາຍການທີ່ບໍ່ມີໜ້າວຽກກ່ອນໜ້າ ຫຼື ເງື່ອນໄຂຜູກມັດ ໄດ້ຖືກຍ້າຍໄປວັນເລີ່ມຕົ້ນໃໝ່*.
- **ໜ້າຕ່າງວັນທີບໍ່ຄວບຄຸມອີກຕໍ່ໄປ** (ຂໍ້ມູນ) — *ໜ້າຕ່າງວັນທີຂອງ MS Project ບໍ່ຄວບຄຸມ N ໜ້າວຽກອີກຕໍ່ໄປຫຼັງການແກ້ໄຂນີ້; …* ສະແດງໜຶ່ງຄັ້ງຕໍ່ເອກະສານ.
- **ປັດເສດຄວາມຊັກຊ້າຈາກການປັບສົມດຸນ** (ຂໍ້ມູນ) — *ການປັບສົມດຸນໄດ້ປັດເສດເວລາທີ່ລະອຽດລະດັບນາທີຂອງ MS Project ສຳລັບ N ໜ້າວຽກ ໃຫ້ເປັນມື້ເຮັດວຽກເຕັມ*. ສະແດງໜຶ່ງຄັ້ງຕໍ່ເອກະສານ.
- **ນຳໃຊ້ໂປຣໄຟລ໌ການຄິດໄລ່ແລ້ວ** (ຂໍ້ມູນ) — *ໂຄງການນີ້ຄິດໄລ່ຕາມໂປຣໄຟລ໌ {profile}. ສາມາດປ່ຽນແປງໄດ້ຜ່ານ ໄຟລ໌ → ຂໍ້ມູນໂຄງການ → ໂປຣໄຟລ໌ການຄິດໄລ່ ແລະ ຕົວເລືອກ*. ມີປຸ່ມ *ເປີດໂປຣໄຟລ໌ການຄິດໄລ່*. ຫຼັງຈາກນຳໃຊ້ໂປຣໄຟລ໌, *ຫຼັງຈາກນຳໃຊ້, ມີ N ໜ້າວຽກຖືກຍ້າຍ* ຕາມມາ ຖ້າຈຳເປັນ.
