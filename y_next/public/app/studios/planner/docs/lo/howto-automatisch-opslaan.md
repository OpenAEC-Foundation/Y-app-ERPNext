# ການເປີດໃຊ້ການບັນທຶກອັດຕະໂນມັດ

ເປົ້າໝາຍ: ໃຫ້ແອັບອັບເດດໄຟລ໌ໂຄງການຂອງທ່ານໃນຂະນະທີ່ທ່ານເຮັດວຽກ ເພື່ອທ່ານບໍ່ຕ້ອງກົດ Ctrl+S ຊ້ຳໆ.

## ເມື່ອທ່ານຕ້ອງການອັນນີ້

ທ່ານເຮັດວຽກເປັນເວລາດົນກັບແຜນງານດຽວ ຫຼື ທ່ານມັກລືມບັນທຶກ ແລະ ທ່ານຕ້ອງການໃຫ້ໄຟລ໌ຢູ່ໃນດິສກ໌ ຫຼື ໃນໂຟລເດີທີ່ໃຊ້ຮ່ວມກັນ ທັນສະໄໝຢູ່ສະເໝີ. ບັນທຶກອັດຕະໂນມັດບໍ່ໄດ້ແທນທີ່ລະບົບກູ້ຄືນຂໍ້ມູນ. ລະບົບກູ້ຄືນຂໍ້ມູນເປີດຢູ່ສະເໝີ ແລະ ເຮັດວຽກແຍກຕ່າງຫາກຈາກນີ້. ຄວາມແຕກຕ່າງແມ່ນຫຍັງ ທ່ານອ່ານໄດ້ໃນ [ໄຟລ໌ ແລະ ຮູບແບບ](docs://uitleg-bestanden).

## ຂັ້ນຕອນ

1. ຖ້າໂຄງການຍັງບໍ່ມີໄຟລ໌, ກະລຸນາບັນທຶກໄຟລ໌ໜຶ່ງຄັ້ງກ່ອນ ດ້ວຍ *ໜ້າຫຼັກ › ໄຟລ໌ › ບັນທຶກເປັນ*. ຕາບໃດທີ່ຍັງບໍ່ມີໄຟລ໌ ສະວິດຈະເປັນສີເທົາ ແລະ ຂໍ້ຄວາມຄຳແນະນຳຈະບອກວ່າ: *ບັນທຶກໂຄງການນີ້ກ່ອນ ເພື່ອໃຊ້ການບັນທຶກອັດຕະໂນມັດ.*
2. ຢູ່ເທິງສຸດເບື້ອງຊ້າຍໃນແຖບດ້ານເທິງ ກົດສະວິດ *ບັນທຶກອັດຕະໂນມັດ*. ເມື່ອເປີດຢູ່ ຂໍ້ຄວາມຄຳແນະນຳຈະບອກວ່າ: *ການບັນທຶກອັດຕະໂນມັດເປີດຢູ່: ການປ່ຽນແປງຕ່າງໆ ຈະຖືກຂຽນລົງໃນໄຟລ໌ນີ້.*
3. ສືບຕໍ່ເຮັດວຽກ. ທັນທີທີ່ໂຄງການຂອງທ່ານມີການປ່ຽນແປງ ແອັບຈະຂຽນມັນລົງໃນໄຟລ໌ຂອງທ່ານ ໂດຍບໍ່ເປີດກ່ອງໂຕ້ຕອບ ແລະ ຢ່າງຫຼາຍທີ່ສຸດໜຶ່ງຄັ້ງທຸກໆ ສິບວິນາທີ. ເຄື່ອງໝາຍ *ຍັງບໍ່ໄດ້ບັນທຶກ* ຈະຫາຍໄປເອງ.
4. ຖ້າທ່ານຕ້ອງການຢຸດ ກົດສະວິດອີກຄັ້ງໜຶ່ງ. ຂໍ້ຄວາມຄຳແນະນຳຈະບອກວ່າ: *ການບັນທຶກອັດຕະໂນມັດປິດຢູ່. ລະບົບກູ້ຄືນຂໍ້ມູນເມື່ອໂປຣແກຣມຂັດຂ້ອງ ຍັງເຮັດວຽກຢູ່.*

ໃນ Chrome ແລະ Edge ໃນເບື້ອງຕົ້ນ ແອັບໃຫ້ອ່ານໄດ້ພຽງໄຟລ໌ທີ່ທ່ານເປີດເທົ່ານັ້ນ. ສະວິດຈະບໍ່ເຮັດວຽກຈົນກວ່າທ່ານຈະບັນທຶກໜຶ່ງຄັ້ງດ້ວຍ *ບັນທຶກ* (Ctrl+S) ແລະ ບຣາວເຊີໄດ້ໃຫ້ສິດໃນການຂຽນ. ຫຼັງຈາກນັ້ນ ທ່ານສາມາດເປີດມັນໄດ້. ໃນ Firefox ສະວິດຈະຢູ່ເປັນສີເທົາ: ແອັບບໍ່ສາມາດຂຽນລົງໃນໄຟລ໌ຂອງທ່ານທີ່ນັ້ນໄດ້.

## ຂໍ້ຜິດພາດທົ່ວໄປ ແລະ ແອັບເຮັດຫຍັງໃນກໍລະນີນັ້ນ

**ສະວິດເປັນຂອງໂຄງການດຽວ.** ທຸກແຖບມີສະຖານະຂອງຕົນເອງ. ຫຼັງຈາກເປີດໂຄງການ ມັນຈະປິດຢູ່ສະເໝີ ແລະ ແອັບບໍ່ຈື່ໄວ້ສຳລັບຄັ້ງຕໍ່ໄປ.

**ບັນທຶກອັດຕະໂນມັດຂຽນພຽງໄຟລ໌ທີ່ໂຄງການມີຢູ່ແລ້ວເທົ່ານັ້ນ.** ຖ້າທ່ານເລືອກ *ບັນທຶກເປັນ*, ມັນຈະຂຽນລົງໃນໄຟລ໌ໃໝ່ນັບແຕ່ນັ້ນເປັນຕົ້ນໄປ. ແອັບຂຽນພຽງເມື່ອມີການປ່ຽນແປງເທົ່ານັ້ນ.

**ການຂຽນອາດບໍ່ສຳເລັດ.** ຕົວຢ່າງ ຖ້າໄຟລ໌ຫາຍໄປ ຫຼື ຖືກລັອກ ຂໍ້ຄວາມ *ການບັນທຶກອັດຕະໂນມັດບໍ່ສຳເລັດ* ຈະປາກົດພ້ອມກັບເຫດຜົນ. ຖ້າບຣາວເຊີບໍ່ມີສິດໃນການຂຽນ (ຫຼື ບໍ່ມີອີກຕໍ່ໄປ), ແອັບຈະຂ້າມຮອບນັ້ນໂດຍບໍ່ແຈ້ງໃຫ້ຮູ້: ມັນຈະບໍ່ຂໍສິດນັ້ນ.

**ໄຟລ໌ຈະໄດ້ຮັບການປ່ຽນແປງທີ່ທ່ານອາດບໍ່ຢາກເກັບໄວ້ນຳ.** ການບັນທຶກອັດຕະໂນມັດຂຽນສະຖານະຂອງໂຄງການຂອງທ່ານ ຕາມທີ່ມັນເປັນໃນຂະນະນັ້ນ. ຖ້າທ່ານຍົກເລີກບາງສິ່ງດ້ວຍ Ctrl+Z, ໄຟລ໌ຈະໄດ້ຮັບສະຖານະຫຼັງການຍົກເລີກນັ້ນພາຍໃນ ສິບວິນາທີເຊັ່ນກັນ. ຖ້າທ່ານຕ້ອງການເກັບສະບັບເກົ່າໄວ້ ກະລຸນາເຮັດສຳເນົາກ່ອນດ້ວຍ *ບັນທຶກເປັນ*.

**ເມື່ອໂປຣແກຣມຂັດຂ້ອງ ຍັງເສຍຂໍ້ມູນໃນຊ່ວງວິນາທີສຸດທ້າຍ.** ແອັບຂຽນຢ່າງຫຼາຍທີ່ສຸດໜຶ່ງຄັ້ງທຸກໆ ສິບວິນາທີ, ສະນັ້ນສິ່ງທີ່ທ່ານເຮັດໃນຊ່ວງນັ້ນຍັງບໍ່ຢູ່ໃນໄຟລ໌ຂອງທ່ານ. ລະບົບກູ້ຄືນຂໍ້ມູນມີຂີດຈຳກັດດຽວກັນ.

**ຫຼັງກູ້ຄືນໃນບຣາວເຊີ ສະວິດຈະເປັນສີເທົາອີກຄັ້ງ.** ໂຄງການທີ່ທ່ານໄດ້ຄືນມາໃນບຣາວເຊີຫຼັງຈາກໂປຣແກຣມຂັດຂ້ອງ ຈະບໍ່ໄດ້ເຊື່ອມກັບໄຟລ໌ຂອງມັນອີກຕໍ່ໄປ. ກະລຸນາບັນທຶກໜຶ່ງຄັ້ງ ແລະ ສະວິດຈະເຮັດວຽກອີກຄັ້ງ. ເບິ່ງ [ການກູ້ຄືນຫຼັງຈາກໂປຣແກຣມຂັດຂ້ອງ](docs://howto-herstellen-na-een-crash).

**ໂຄງການຈາກຮູບແບບອື່ນບໍ່ມີໄຟລ໌.** ໄຟລ໌ CSV, XML, `.mpp` ຫຼື `.xer` ຈະໄດ້ໄຟລ໌ IFC ພຽງເມື່ອທ່ານບັນທຶກເທົ່ານັ້ນ. ຫຼັງຈາກນັ້ນ ທ່ານສາມາດເປີດການບັນທຶກອັດຕະໂນມັດໄດ້.
