# ການສົ່ງຄຳຕິຊົມ

ເປົ້າໝາຍ: ແຈ້ງຂໍ້ຜິດພາດ ຫຼື ສະເໜີແນວຄວາມຄິດ, ຈະແນບຮູບໜ້າຈໍດ້ວຍກໍໄດ້, ເພື່ອໃຫ້ມັນກາຍເປັນບັນຫາໃນ GitHub.

## ເມື່ອທ່ານຕ້ອງການສິ່ງນີ້

ແຜນງານຄຳນວນບາງຢ່າງທີ່ທ່ານບໍ່ເຂົ້າໃຈ, ປຸ່ມບໍ່ເຮັດຕາມທີ່ມັນຄວນເຮັດ, ຫຼືທ່ານພາດບາງຢ່າງໃນແອັບ. ລາຍງານທີ່ດີຊ່ວຍທີມພັດທະນາຊອກຫາບັນຫາ. ນັ້ນແມ່ນເຫດຜົນທີ່ແອັບໃສ່ເວີຊັນ, ລະບົບປະຕິບັດການ ແລະ ພາສາໄວ້ໃນລາຍງານຂອງທ່ານເອງ. ສິ່ງທີ່ທ່ານອະທິບາຍເອງ ກຳນົດວ່າພວກເຂົາຈະດຳເນີນການໄດ້ບໍ່: ທ່ານເຮັດຫຍັງ, ທ່ານຄາດຫວັງຫຍັງ ແລະ ເກີດຫຍັງຂຶ້ນ.

## ຂັ້ນຕອນ

1. ກົດປຸ່ມ *ສົ່ງຄຳຕິຊົມ* ເທິງສຸດຂອງໜ້າຕ່າງ. ປຸ່ມນັ້ນຢູ່ໃນແຖບຫົວຂໍ້ສະເໝີ. ຂໍ້ຄວາມຂອງມັນປ່ຽນທຸກສິບນາທີ: *ສົ່ງຄຳຕິຊົມ*, *ລາຍງານຂໍ້ຜິດພາດ* ແລະ *ສະເໜີຄຸນສົມບັດໃໝ່*. ມັນເປັນປຸ່ມດຽວກັນສະເໝີ. ໜ້າຕ່າງ *ສົ່ງຄຳຕິຊົມ* ເປີດຂຶ້ນ.
2. ເລືອກ *ຂໍ້ຜິດພາດ (Bug)* ສຳລັບສິ່ງທີ່ເຮັດວຽກບໍ່ຖືກຕ້ອງ, ຫຼື *ຂໍເພີ່ມຄຸນສົມບັດໃໝ່* ສຳລັບແນວຄວາມຄິດ. *ຂໍ້ຜິດພາດ (Bug)* ຖືກເລືອກເປັນຄ່າເລີ່ມຕົ້ນ.
3. ຕື່ມ *ຫົວຂໍ້*. ຖ້າບໍ່ມີຫົວຂໍ້, ປຸ່ມ *ສົ່ງໄປທີ່ GitHub* ຈະເປັນສີເທົາ. ຕື່ມ *ລາຍລະອຽດ* ນຳ, ຕົວຢ່າງ: ທ່ານປ່ຽນໜ້າວຽກໃດ, ສິ່ງທີ່ທ່ານຄາດຫວັງ ແລະ ສິ່ງທີ່ທ່ານເຫັນ.
4. ຖ້າທ່ານຢາກສະແດງບາງຢ່າງ, ເປີດ *ແນບຮູບໜ້າຈໍ*. ແອັບຈະຖ່າຍຮູບແອັບໂດຍບໍ່ມີໜ້າຕ່າງນີ້. ບໍ່ດົນຕໍ່ມາ ທ່ານເຫັນຕົວຢ່າງນ້ອຍ. ດ້ວຍ *ຂຽນໝາຍເຫດໃສ່ຮູບ* ຕົວແກ້ໄຂຈະເປີດຂຶ້ນ, ທີ່ທ່ານໃສ່ລູກສອນ, ສີ່ຫຼ່ຽມ, ເສັ້ນອິດສະຫຼະ ແລະ ຂໍ້ຄວາມໃສ່ຮູບ. ທີ່ນັ້ນທ່ານເລືອກສີ, ຍົກເລີກການກະທຳຄັ້ງສຸດທ້າຍຂອງທ່ານດ້ວຍ *ຍົກເລີກຄຳສັ່ງ* ຫຼື ເລີ່ມໃໝ່ດ້ວຍ *ລຶບລ້າງທັງໝົດ*. ກົດ *ສຳເລັດ* ເມື່ອທ່ານພໍໃຈ.
5. ກົດ *ສົ່ງໄປທີ່ GitHub*.
6. ທ່ານບໍ່ໄດ້ແນບຮູບໜ້າຈໍບໍ? ຫຼັງຈາກນັ້ນ ໜ້າ GitHub ທີ່ທ່ານສ້າງບັນຫາໃໝ່ ເປີດທັນທີໃນບຣາວເຊີຂອງທ່ານ. ດຳເນີນຕໍ່ທີ່ຂັ້ນຕອນ 8.
7. ທ່ານແນບຮູບໜ້າຈໍບໍ? ຫຼັງຈາກນັ້ນ ທ່ານເຫັນ *ເກືອບສຳເລັດແລ້ວ — ຮູບໜ້າຈໍຂອງທ່ານຢູ່ໃນຄລິບບອດແລ້ວ.* ພ້ອມສີ່ຂັ້ນຕອນ. ກົດ *ຕົກລົງ, ໄປທີ່ GitHub*, ກົດໃນຊ່ອງຂໍ້ຄວາມຂະໜາດໃຫຍ່ຂອງໜ້າບັນຫາ, ແລ້ວກົດ Ctrl+V (Cmd+V ໃນ Mac). ຮູບຈະຖືກອັບໂຫລດ ແລະ ປາກົດຢູ່ໃນຂໍ້ຄວາມ.
8. ທີ່ດ້ານລຸ່ມຂອງໜ້າບັນຫາ ກົດ *ສົ່ງບັນຫາໃໝ່*. ພຽງແຕ່ຕອນນັ້ນ ລາຍງານຂອງທ່ານຈຶ່ງຖືກສົ່ງ. ລົງຊື່ເຂົ້າ GitHub ຖ້າທ່ານຍັງບໍ່ໄດ້ເຂົ້າ.

ໃນໜ້າບັນຫາ ຫົວຂໍ້ ແລະ ລາຍລະອຽດຂອງທ່ານຖືກຕື່ມໄວ້ແລ້ວ. ແອັບແນະນຳປ້າຍ *bug* ຫຼື *enhancement* ແລະ ໃສ່ແຖວໜຶ່ງໃຕ້ລາຍລະອຽດຂອງທ່ານ. ແຖວນັ້ນມີປະເພດ, ເວີຊັນຂອງ Open Planner Studio, ລະບົບປະຕິບັດການຂອງທ່ານ ແລະ ພາສາຂອງແອັບ.

## ຂໍ້ຜິດພາດທີ່ອາດເກີດຂຶ້ນ ແລະ ແອັບເຮັດຫຍັງ

**ແອັບບໍ່ສົ່ງຫຍັງດ້ວຍຕົນເອງ.** *ສົ່ງໄປທີ່ GitHub* ພຽງແຕ່ເປີດໜ້າບັນຫາທີ່ຕື່ມໄວ້ແລ້ວ. ຖ້າທ່ານປິດໜ້ານັ້ນໂດຍບໍ່ກົດ *ສົ່ງບັນຫາໃໝ່*, ຍັງບໍ່ມີຫຍັງຖືກແຈ້ງ. ທ່ານຕ້ອງມີບັນຊີ GitHub ສຳລັບເລື່ອງນັ້ນ.

**ລາຍງານຂອງທ່ານຈະໄປຢູ່ໃນ GitHub.** ຢ່າໃສ່ຫຍັງໃນນັ້ນທີ່ທ່ານບໍ່ຢາກແບ່ງປັນ. ຮູບໜ້າຈໍກໍເຊັ່ນກັນ: ຮູບສະແດງທຸກຢ່າງທີ່ເຫັນໄດ້ໃນແອັບໃນຕອນນັ້ນ, ເຊັ່ນ: ຊື່ໜ້າວຽກ ແລະ ຊັບພະຍາກອນຂອງໂຄງການທ່ານ. ແອັບຖ່າຍຮູບໜ້າຈໍໃນຕອນທີ່ທ່ານເປີດ *ແນບຮູບໜ້າຈໍ*. ສະນັ້ນ ໃຫ້ແນ່ໃຈວ່າໜ້າຈໍຖືກຕ້ອງກ່ອນທ່ານເປີດມັນ, ແລະ ເອົາສິ່ງທີ່ທ່ານບໍ່ຢາກສະແດງອອກ.

**ການວາງບໍ່ເຮັດວຽກ.** ຮູບໜ້າຈໍຖືກບັນທຶກເປັນໄຟລ໌ໃນຄອມພິວເຕີຂອງທ່ານນຳ. ໃນແອັບເດັສທັອບ ໜ້າຕ່າງບອກເສັ້ນທາງ: *ວາງບໍ່ໄດ້? ພວກເຮົາບັນທຶກຮູບໜ້າຈໍໄວ້ທີ່* ເສັ້ນທາງນັ້ນ *— ລາກໄຟລ໌ນັ້ນໄປໃສ່ຊ່ອງຂໍ້ຄວາມ.* ໃນບຣາວເຊີ ແອັບດາວໂຫລດຮູບເປັນ `feedback-` ພ້ອມເລກ ແລະ ນາມສະກຸນ `.png`. ທ່ານຊອກຫາມັນໃນໂຟນເດີດາວໂຫລດ ແລະ ລາກມັນໄປໃສ່ຊ່ອງຂໍ້ຄວາມ.

**ການຖ່າຍຮູບໜ້າຈໍລົ້ມເຫຼວ.** ແອັບສະແດງ *ຖ່າຍຮູບໜ້າຈໍບໍ່ສຳເລັດ. ທ່ານຍັງສາມາດສົ່ງຄຳຕິຊົມໂດຍບໍ່ມີຮູບໄດ້.* ຊ່ອງໝາຍຖືກຍົກເລີກ ແລະ ທ່ານສາມາດສົ່ງລາຍງານໂດຍບໍ່ມີຮູບໄດ້.

**ທ່ານພິມຫຼາຍແລ້ວ ແລະ ກົດຂ້າງໜ້າຕ່າງໂດຍບັງເອີນ.** ນັ້ນບໍ່ປິດໜ້າຕ່າງ, ສະນັ້ນຂໍ້ຄວາມຂອງທ່ານຍັງຢູ່. Esc ຫຼື *ຍົກເລີກ* ປິດໜ້າຕ່າງແທ້, ແລ້ວຂໍ້ຄວາມຂອງທ່ານຈະຫາຍໄປ.
