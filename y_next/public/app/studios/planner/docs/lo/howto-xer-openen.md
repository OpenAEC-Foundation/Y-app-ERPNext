# ການເປີດໄຟລ໌ Primavera P6 (.xer)

ເປົ້າໝາຍ: ເປີດແຜນງານຈາກ Primavera P6 ໂດຍກົງໃນແອັບ ໂດຍບໍ່ຕ້ອງສົ່ງອອກເປັນ XML ກ່ອນ.

## ເມື່ອທ່ານຕ້ອງການອັນນີ້

ລູກຄ້າ ຫຼື ຜູ້ຮັບເໝົາຫຼັກເຮັດວຽກໃນ Primavera ແລະ ສົ່ງແຜນງານຂອງເຂົາເປັນໄຟລ໌ `.xer`. ທ່ານຕ້ອງການເບິ່ງ, ຄິດໄລ່ ຫຼື ເພີ່ມຂໍ້ມູນເຂົ້າໄປ. ແອັບອ່ານໄຟລ໌ `.xer` ເທົ່ານັ້ນ: ແອັບບໍ່ຂຽນ `.xer` ແລະ ບໍ່ປ່ຽນໄຟລ໌ຂອງທ່ານເລີຍ. ຈາກໄຟລ໌ນັ້ນ ແອັບເອົາໂຄງສ້າງ WBS ແລະ ໜ້າວຽກທີ່ມີໄລຍະເວລາ, ວັນທີ, ເງື່ອນໄຂ ແລະ ຄວາມຄືບໜ້າ, ສາຍສຳພັນພ້ອມຄ່າ Lag, ປະຕິທິນ ແລະ ຊັບພະຍາກອນພ້ອມການມອບໝາຍຂອງພວກມັນ, ພ້ອມລະຫັດກິດຈະກຳ, ຊ່ອງກຳນົດເອງ (UDFs), ໝາຍເຫດ ແລະ ການຕັ້ງຄ່າການຄິດໄລ່ແຜນງານຂອງ P6. ໜ້າວຽກປະເພດ *ລະດັບຄວາມພະຍາຍາມ* ຈະກາຍເປັນແຮມມັອກ.

## ຂັ້ນຕອນ

1. ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ເປີດ* ຫຼື ກົດ Ctrl+O. ເລືອກໄຟລ໌ `.xer`.
2. ແອັບເປີດແຖບໜຶ່ງອັນສຳລັບແຕ່ລະໂຄງການທີ່ມີໜ້າວຽກ. ໂຄງການທີ່ມີໜ້າວຽກຫຼາຍທີ່ສຸດຈະເປັນແຖບທີ່ເຮັດວຽກຢູ່. ແຖບຈະມີຊື່ວ່າ *ຊື່ໂຄງການ (ລະຫັດໂຄງການ)* ຖ້າລະຫັດໂຄງການ P6 ແຕກຕ່າງຈາກຊື່.
3. ອ່ານຂໍ້ຄວາມຢູ່ດ້ານລຸ່ມ. ຖ້າໄຟລ໌ມີສາມໂຄງການ ຂໍ້ຄວາມອາດເບິ່ງແບບນີ້: *ເປີດໄຟລ໌ XER ສຳເລັດ: ເອກະສານໂຄງການ 3 ລາຍການ.* ຂ້າງລຸ່ມມີແຖວທີ່ອະທິບາຍວ່າແອັບເຮັດຫຍັງແດ່. ເບິ່ງຫົວຂໍ້ດ້ານລຸ່ມ.
4. ກວດວ່າມີແຖບຂໍ້ຄວາມຢູ່ໃຕ້ແຖບເຄື່ອງມືຫຼືບໍ່: *ທ່ານກຳລັງເບິ່ງແຜນງານຕາມທີ່ Primavera ບັນທຶກໄວ້; ການຄິດໄລ່ຄືນໃໝ່ຈະເຮັດໃຫ້ 1 ໜ້າວຽກຖືກຍ້າຍ.* Primavera ບັນທຶກວັນທີທີ່ຄິດໄລ່ເອງຂອງມັນໄວ້ໃນໄຟລ໌. ຖ້າການຄິດໄລ່ຂອງແອັບຕ່າງຈາກວັນທີເຫຼົ່ານັ້ນ ແອັບຈະສະແດງວັນທີຂອງ Primavera ຕາບໃດທີ່ທ່ານບໍ່ປ່ຽນແປງຫຍັງ. ຄວາມໝາຍຂອງສິ່ງນີ້ ແລະ ວິທີສະຫຼັບໄປໃຊ້ການຄິດໄລ່ຂອງແອັບເອງ ແມ່ນຢູ່ໃນ [ວັນທີຕາມທີ່ບັນທຶກໄວ້](docs://uitleg-datums-zoals-opgeslagen). ຂໍ້ຄວາມ *ໄຟລ໌ນີ້ມີການວາງແຜນແບບລາຍຊົ່ວໂມງ.* ອາດປາກົດຂຶ້ນເຊັ່ນກັນ ພ້ອມປຸ່ມ *ເປີດໃຊ້ການວາງແຜນລາຍຊົ່ວໂມງ*. ເບິ່ງ [ການເປີດໃຊ້ການວາງແຜນລາຍຊົ່ວໂມງ](docs://howto-urenplanning-aanzetten).
5. ບັນທຶກໂຄງການຂອງທ່ານດ້ວຍ Ctrl+S. ເນື່ອງຈາກໄຟລ໌ `.xer` ຈະບໍ່ຖືກຂຽນທັບ ແອັບຈະຖາມວ່າໄຟລ໌ IFC ໃໝ່ຄວນຢູ່ບ່ອນໃດ. ແອັບຈະແນະນຳ *ຊື່ໂຄງການ (ລະຫັດໂຄງການ)* ເປັນຊື່ໄຟລ໌.

### ແຖວຢູ່ລຸ່ມຂໍ້ຄວາມ

ແຖວທຳອິດຂອງຂໍ້ຄວາມບອກຈຳນວນແຖບທີ່ເປີດແລ້ວ. ຂ້າງລຸ່ມມີພຽງແຖວທີ່ກ່ຽວຂ້ອງເທົ່ານັ້ນ. ແຖວເຫຼົ່ານີ້ຄວນໄດ້ຮັບຄວາມສົນໃຈຂອງທ່ານ:

- *ໂຄງການນີ້ຄິດໄລ່ຕາມໂປຣໄຟລ໌ Primavera P6. ສາມາດປ່ຽນແປງໄດ້ຜ່ານ ໄຟລ໌ → ຂໍ້ມູນໂຄງການ → ໂປຣໄຟລ໌ການຄິດໄລ່ ແລະ ຕົວເລືອກ.* ແອັບຄິດໄລ່ໂຄງການນີ້ດ້ວຍກົດລະບຽບການຄິດໄລ່ຂອງ Primavera. ດ້ວຍ *ເປີດໂປຣໄຟລ໌ການຄິດໄລ່* ທ່ານຈະໄປຫາການຕັ້ງຄ່າ.
- *ບໍ່ລວມ 1 ໂຄງການແຜນຫຼັກ (baseline).* ແລະ *ສ້າງແຜນຫຼັກ (baseline) ສຳເລັດ 1 ລາຍການ.* ຖ້າໂຄງການໃນ P6 ກຳນົດໂຄງການອື່ນເປັນແຜນຫຼັກຂອງຕົນ ໂຄງການອື່ນນັ້ນຈະບໍ່ເປີດເປັນແຖບຂອງຕົນເອງ. ມັນຈະກາຍເປັນແຜນຫຼັກທີ່ເຮັດວຽກຢູ່ຂອງໂຄງການທີ່ອ້າງເຖິງມັນ.
- *ມີການນຳໃຊ້ແຜນຫຼັກສຳຮອງເພື່ອປ້ອງກັນຂໍ້ຜິດພາດ.* ຖ້າການກຳນົດແຜນຫຼັກຈະເຮັດໃຫ້ບໍ່ມີໂຄງການໃດເປີດເລີຍ, ຖ້າໂຄງການອ້າງເຖິງຕົວເອງ ຫຼື ຖ້າໂຄງການອ້າງເຖິງກັນເປັນວົງ, ແອັບຈະເປີດທຸກໂຄງການແບບງ່າຍໆ ແລະ ບໍ່ສ້າງແຜນຫຼັກໃດເລີຍ.
- *ຮັກສາສາຍສຳພັນພາຍນອກໄວ້ 1 ລາຍການ.* ເປັນສາຍສຳພັນລະຫວ່າງສອງໂຄງການ. ແອັບເກັບມັນໄວ້ເປັນຂໍ້ມູນຕົ້ນສະບັບ ແຕ່ບໍ່ປ່ຽນມັນເປັນສາຍສຳພັນໃນແຜນງານຂອງທ່ານ.
- *1 ໜ້າວຽກສະແດງວັນທີຕາມທີ່ Primavera ບັນທຶກໄວ້ (ບໍ່ໄດ້ຄິດໄລ່ຄືນໃໝ່).* ຈຳນວນໜ້າວຽກທີ່ທ່ານເຫັນໃນມຸມມອງ *ວັນທີຕາມທີ່ບັນທຶກໄວ້*.

ແຖວອື່ນໆເປັນການວິນິດໄສຂອງການອ່ານເອງ: ຈຳນວນໂຄງການທີ່ພົບ, ໂຄງການເປົ່າທີ່ຖືກຂ້າມ, ການອ້າງອີງແຜນຫຼັກທີ່ຄ້າງຢູ່ທີ່ຖືກລະເວັ້ນ, ການເຂົ້າລະຫັດຂໍ້ຄວາມທີ່ບໍ່ແມ່ນ UTF-8 ທຳມະດາ ແລະ ຕົວນັບຜົນທີ່ພົບໃນຕາຕະລາງ, ໃນປະຕິທິນ ແລະ ໃນຕົວເລກ, ສຳລັບຄ່າຊ່ອງທີ່ບໍ່ຮູ້ຈັກ ແລະ ສຳລັບການຕັ້ງຄ່າແຜນງານຂອງ P6 ທີ່ແອັບປ່ຽນເປັນທາງເລືອກທີ່ປອດໄພ. ແຖວເຫຼົ່ານີ້ບໍ່ຮຽກຮ້ອງຫຍັງຈາກທ່ານ. *ອ່ານເພີ່ມເຕີມ* ເປີດຄູ່ມືຊ່ວຍເຫຼືອກ່ຽວກັບການເປີດໄຟລ໌ Primavera.

## ຈຸດທີ່ຕ້ອງລະວັງ ແລະ ສິ່ງທີ່ແອັບເຮັດເມື່ອນັ້ນ

**ບໍ່ແມ່ນທຸກຢ່າງຈະກາຍເປັນແຖບ ຫຼື ສາຍສຳພັນ.** ໂຄງການທີ່ບໍ່ມີກິດຈະກຳຈະບໍ່ເປີດ, ໂຄງການແຜນຫຼັກຈະບໍ່ເປີດເປັນແຖບຂອງຕົນເອງ ແລະ ສາຍສຳພັນລະຫວ່າງສອງໂຄງການຈະບໍ່ກາຍເປັນສາຍສຳພັນໃນແຜນງານຂອງທ່ານ. ແອັບລາຍງານເລື່ອງນີ້ໃນແຖວຢູ່ລຸ່ມຂໍ້ຄວາມ.

**ທຸກແຖບແມ່ນໂຄງການແຍກຕ່າງຫາກ.** ຖ້າທ່ານບັນທຶກແຖບໃດໜຶ່ງ ໄຟລ໌ IFC ຈະເກັບໄຟລ໌ `.xer` ຕົ້ນສະບັບທັງໝົດໄວ້ນຳ. ຖ້າທ່ານເປີດໄຟລ໌ IFC ນັ້ນອີກໃນພາຍຫຼັງ ແອັບຍັງຮູ້ວັນທີຂອງ Primavera. ຖ້າໄຟລ໌ເກັບຕົ້ນສະບັບນັ້ນເສຍຫາຍ ຫຼື ໂປຣແກຣມ IFC ອື່ນຂຽນໄຟລ໌ໃໝ່, ແອັບຈະລາຍງານວ່າ: *ໄຟລ໌ເກັບຕົ້ນສະບັບ XER ໃນໄຟລ໌ນີ້ບໍ່ສາມາດໃຊ້ງານໄດ້ ແລະ ຖືກລະເວັ້ນໄວ້; ຕົວໂຄງການເອງສາມາດເປີດໄດ້ຄົບຖ້ວນ.* ແຜນງານ, ໂປຣໄຟລ໌ການຄິດໄລ່ ແລະ ຂໍ້ມູນໂຄງການທັງໝົດຍັງຄົບຖ້ວນ. ສິ່ງທີ່ຂາດໄປ: ວັນທີທີ່ Primavera ເກັບໄວ້ ແລະ ແຫຼ່ງທີ່ມາຂອງຂໍ້ມູນສຳລັບ AI ແລະ ສ່ວນເສີມ. ເປີດໄຟລ໌ `.xer` ຕົ້ນສະບັບອີກຄັ້ງເພື່ອເອົາໄຟລ໌ເກັບນັ້ນຄືນມາ.

**ການສົ່ງອອກເປັນ CSV, MS Project XML ຫຼື P6 XML ຈະສູນເສຍຂໍ້ມູນ.** ແອັບເຕືອນວ່າ: *ການສົ່ງອອກເປັນ CSV ຈະສູນເສຍຂໍ້ມູນຕົ້ນສະບັບຂອງ XER.* IFC ບໍ່ສູນເສຍຫຍັງເລີຍ.

**ໄຟລ໌ທີ່ແອັບອ່ານບໍ່ໄດ້.** ທ່ານຈະໄດ້ຮັບຂໍ້ຄວາມຜິດພາດ ພ້ອມເຫດຜົນ. ຕົວຢ່າງບາງອັນ:

- *ນີ້ບໍ່ແມ່ນໄຟລ໌ XER ທີ່ຖືກຕ້ອງ ຫຼື ບໍ່ຮອງຮັບ.*
- *ຕາຕະລາງ XER ຂາດຖັນທີ່ຈຳເປັນ.*
- *ໂຄງການ P6 ໃນໄຟລ໌ XER ນີ້ບໍ່ມີກິດຈະກຳໃດເລີຍ.*

ຈາກນັ້ນຈະບໍ່ມີຫຍັງເປີດ. ກວດສອບໄຟລ໌ໃນ P6 ຫຼື ຂໍໃຫ້ຜູ້ສົ່ງສົ່ງອອກໄຟລ໌ໃໝ່ໃຫ້.
