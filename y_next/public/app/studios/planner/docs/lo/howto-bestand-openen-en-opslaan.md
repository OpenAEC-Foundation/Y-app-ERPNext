# ການເປີດ ແລະ ການບັນທຶກໄຟລ໌

ເປົ້າໝາຍ: ເປີດໂຄງການຈາກໄຟລ໌ ແລະ ເກັບການປ່ຽນແປງຂອງທ່ານໄວ້.

## ເມື່ອທ່ານຕ້ອງການສິ່ງນີ້

ທ່ານເລີ່ມວຽກມື້ໃໝ່ດ້ວຍໂຄງການຂອງມື້ວານ, ທ່ານໄດ້ໄຟລ໌ຈາກເພື່ອນຮ່ວມງານ ຫຼື ຈາກແພັກເກດອື່ນ, ຫຼື ທ່ານຢາກບັນທຶກສະພາບໄລຍະກາງກ່ອນທ່ານປ່ຽນສິ່ງໃຫຍ່. ແອັບເກັບຫຍັງໄວ້ໃນໄຟລ໌, ແລະ ເປັນຫຍັງມີແຕ່ IFC ທີ່ເກັບໂຄງການທັງໝົດຂອງທ່ານ, ອະທິບາຍໄວ້ໃນ [ໄຟລ໌ ແລະ ຮູບແບບ](docs://uitleg-bestanden).

## ຂັ້ນຕອນ

### ການເປີດໄຟລ໌

1. ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ເປີດ*, ຫຼື *ໄຟລ໌ › ເປີດ*, ຫຼື ກົດ Ctrl+O (⌘+O ໃນ Mac). *ເປີດ* ຢູ່ແຖບດ້ານເທິງສຸດນຳ. ກຸ່ມ *ໄຟລ໌* ຢູ່ໃນແຖບ *ຕາຕະລາງ* ນຳ.
2. ເລືອກໄຟລ໌. ທ່ານເປີດໄຟລ໌ໄດ້ເທື່ອລະໜຶ່ງ. ໃນແອັບເດັສທັອບ ແລະ ໃນບຣາວເຊີທີ່ມີການເຂົ້າເຖິງໄຟລ໌, ເຊັ່ນ Chrome ແລະ Edge, ໜ້າຕ່າງສະແດງລາຍການປະເພດໄຟລ໌: *ທັງໝົດທີ່ຮອງຮັບ*, *ໄຟລ໌ IFC*, *ໄຟລ໌ CSV*, *ໄຟລ໌ XML*, *ໄຟລ໌ MS Project* ແລະ *ໄຟລ໌ Primavera XER*.
3. ໂຄງການເປີດໃນແຖບໃໝ່. ຖ້າແຖບປັດຈຸບັນຍັງຫວ່າງ ແລະ ບໍ່ໄດ້ປ່ຽນແປງ, ໂຄງການເປີດໃນແຖບນັ້ນ.

ໄຟລ໌ IFC ໃຫ້ຊື່ໄຟລ໌ແກ່ແຖບ. ໂຄງການຈາກຮູບແບບອື່ນໄດ້ຊື່ໂຄງການຂອງມັນເອງ.

ແອັບເປີດ `.ifc`, `.csv`, `.xml` (MS Project XML ຫຼື Primavera P6 XML), `.mpp` ແລະ `.xer`. ສຳລັບສອງຮູບແບບສຸດທ້າຍ ມີຂັ້ນຕອນແຍກຕ່າງຫາກໃນ [ການເປີດໄຟລ໌ MS Project (.mpp)](docs://howto-mpp-openen) ແລະ [ການເປີດໄຟລ໌ Primavera P6 (.xer)](docs://howto-xer-openen).

### ການເປີດໂຄງການຫຼ້າສຸດ

ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ຫຼ້າສຸດ* ແລ້ວກົດໄຟລ໌ໃນລາຍການ, ຫຼື ເລືອກ *ໄຟລ໌ › ຫຼ້າສຸດ*. ລາຍການເກັບໄຟລ໌ສິບອັນສຸດທ້າຍທີ່ທ່ານເປີດ, ບັນທຶກ ຫຼື ສົ່ງອອກ. ແອັບເດັສທັອບສະແດງເສັ້ນທາງຂອງແຕ່ລະໄຟລ໌, ບຣາວເຊີສະແດງແຕ່ຊື່ໄຟລ໌ເທົ່ານັ້ນ.

ຖ້າແອັບອ່ານໄຟລ໌ໃນລາຍການບໍ່ໄດ້ອີກ, ຕົວຢ່າງ ເພາະທ່ານຍ້າຍມັນ, ໄຟລ໌ນັ້ນຫາຍຈາກລາຍການໂດຍບໍ່ມີຂໍ້ຄວາມ. ໃນບຣາວເຊີທີ່ບໍ່ມີການເຂົ້າເຖິງໄຟລ໌, ເຊັ່ນ Firefox, *ຫຼ້າສຸດ* ຈະວ່າງຢູ່ສະເໝີ.

### ການເປີດຕົວຢ່າງ

ເລືອກ *ໄຟລ໌ › ຕົວຢ່າງ* ແລ້ວກົດໂຄງການຕົວຢ່າງ. ມັນເປີດໃນແຖບ, ໂດຍບໍ່ມີໄຟລ໌. ດັ່ງນັ້ນ *ບັນທຶກ* ຈະຖາມວ່າທ່ານຢາກເກັບມັນໄວ້ບ່ອນໃດ.

### ການບັນທຶກ

ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ບັນທຶກ* ຫຼື *ໄຟລ໌ › ບັນທຶກ*, ຫຼື ກົດ Ctrl+S. ສິ່ງທີ່ເກີດຂຶ້ນຂຶ້ນກັບໂຄງການຂອງທ່ານ:

1. ຖ້າໂຄງການມີໄຟລ໌ແລ້ວ, ເພາະທ່ານເປີດໄຟລ໌ IFC ຫຼື ບັນທຶກມາກ່ອນ, ແອັບຂຽນໃສ່ໄຟລ໌ນັ້ນ. ບໍ່ມີໜ້າຕ່າງປາກຂຶ້ນ.
2. ຖ້າໂຄງການຍັງບໍ່ມີໄຟລ໌, ແອັບຖາມວ່າຈະໃຫ້ໄປໄວ້ບ່ອນໃດ. ມັນແນະນຳຊື່ໂຄງການພ້ອມ `.ifc`. ຫຼັງຈາກນັ້ນ, ໄຟລ໌ນັ້ນເປັນໄຟລ໌ຂອງໂຄງການ.
3. ຖ້າບຣາວເຊີຂອງທ່ານບັນທຶກໄດ້ພຽງທາງການດາວໂຫຼດ (ເຊັ່ນ Firefox), ໄຟລ໌ຈະໄປຢູ່ໂຟນເດີດາວໂຫຼດຂອງທ່ານ, ແລະ ທຸກຄັ້ງທີ່ບັນທຶກຈະສ້າງການດາວໂຫຼດໃໝ່. ຄັ້ງທຳອິດໃນເຊດຊັນ ທ່ານເຫັນຂໍ້ຄວາມ *ບັນທຶກເປັນການດາວໂຫຼດ: 'name.ifc' ຢູ່ໃນໂຟນເດີດາວໂຫຼດຂອງທ່ານ. ບຣາວເຊີນີ້ບໍ່ໃຫ້ແອັບຂຽນໄປບ່ອນຂອງຕົນເອງ, ສະນັ້ນທຸກຄັ້ງທີ່ບັນທຶກຈະສ້າງການດາວໂຫຼດໃໝ່. ໃນ Chrome, Edge ຫຼື ແອັບເດັສທັອບ, ບັນທຶກພຽງແຕ່ອັບເດດໄຟລ໌ດຽວກັນ.*
4. ຖ້າບຣາວເຊີບໍ່ສາມາດຂຽນກັບໄປຫາໄຟລ໌ຂອງໂຄງການໄດ້, ແອັບຈະຖາມອີກວ່າຈະໃຫ້ໄປໄວ້ບ່ອນໃດທຸກຄັ້ງທີ່ທ່ານບັນທຶກ. ມັນເບິ່ງຄືກັບ *ບັນທຶກເປັນ*, ແຕ່ນີ້ເປັນຂໍ້ຈຳກັດຂອງບຣາວເຊີ. ຄັ້ງທຳອິດໃນເຊດຊັນ, ຂໍ້ຄວາມ *ບຣາວເຊີນີ້ບໍ່ໃຫ້ແອັບຂຽນກັບໄປຫາ 'name.ifc'.* ອະທິບາຍເລື່ອງນີ້, ພ້ອມອ້າງອີງ [ໄຟລ໌](docs://uitleg-bestanden).

ຫຼັງຈາກບັນທຶກ, ເຄື່ອງໝາຍ *ຍັງບໍ່ໄດ້ບັນທຶກ* ຫາຍໄປ: ຈຸດຢູ່ແຖບ, ເຄື່ອງໝາຍດາວກ່ອນຊື່ໂຄງການດ້ານເທິງ ແລະ ຂໍ້ຄວາມ *ຍັງບໍ່ໄດ້ບັນທຶກ* ທີ່ມຸມຂວາລຸ່ມຂອງແຖບສະຖານະ.

### ການບັນທຶກດ້ວຍຊື່ອື່ນ

ເລືອກ *ໜ້າຫຼັກ › ໄຟລ໌ › ບັນທຶກເປັນ* ຫຼື *ໄຟລ໌ › ບັນທຶກເປັນ*, ຫຼື ກົດ Ctrl+Shift+S. ເລືອກຊື່ ແລະ ບ່ອນ (ໃນ Firefox ແອັບດາວໂຫຼດໄຟລ໌ໃໝ່ແທນ). ຫຼັງຈາກນັ້ນ ໂຄງການເຮັດວຽກກັບໄຟລ໌ໃໝ່ນີ້: *ບັນທຶກ* ຄັ້ງຕໍ່ໄປຂຽນໄປທີ່ນັ້ນ. ໄຟລ໌ເກົ່າຢູ່ຄືເດີມ, ຄືກັບຕອນທີ່ທ່ານບັນທຶກຄັ້ງສຸດທ້າຍ.

### ການປິດໂຄງການ

ກົດເຄື່ອງໝາຍ × ຢູ່ແຖບ, ຫຼື ເລືອກ *ໄຟລ໌ › ປິດໂຄງການ*. ຖ້າໂຄງການມີການປ່ຽນແປງທີ່ທ່ານບໍ່ໄດ້ບັນທຶກ, ແອັບຖາມ: *ການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ: 'name' ມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ.* ທ່ານເລືອກ *ຍົກເລີກ* (ໂຄງການຍັງເປີດຢູ່), *ບໍ່ບັນທຶກ* (ໂຄງການປິດ ແລະ ການປ່ຽນແປງຂອງທ່ານຫາຍໄປ) ຫຼື *ບັນທຶກ* (ບັນທຶກກ່ອນ ແລ້ວປິດ). ຖ້າທ່ານປິດແອັບທັງໝົດໃນແອັບເດັສທັອບ (ດ້ວຍປຸ່ມປິດ, Alt+F4 ຫຼື ເມນູຂອງລະບົບປະຕິບັດການ), ແອັບຖາມແບບນີ້ສຳລັບທຸກໂຄງການທີ່ມີການປ່ຽນແປງ. *ຍົກເລີກ*, ຫຼື ການບັນທຶກທີ່ລົ້ມເຫຼວ, ຢຸດການປິດ. ຫຼັງຈາກການປິດປົກກະຕິແບບນີ້, ແອັບລຶບສຳເນົາກູ້ຄືນຂອງເຊດຊັນນັ້ນ, ດັ່ງນັ້ນໜ້າຕ່າງກູ້ຄືນຈະປາກຂຶ້ນພຽງແຕ່ຫຼັງຈາກແອັບຢຸດເຮັດວຽກກະທັນຫັນຈິງ. ຖ້າໂຄງການມີການປ່ຽນແປງ ແລະ ທ່ານປິດແຖບ ຫຼື ໜ້າຕ່າງບຣາວເຊີ, ບຣາວເຊີຂໍໃຫ້ຢືນຢັນ.

## ຂໍ້ຄວນລະວັງ ແລະ ສິ່ງທີ່ແອັບເຮັດຫຼັງຈາກນັ້ນ

**ໄຟລ໌ IFC ທີ່ເປີດແລ້ວ ເປັນໄຟລ໌ຂອງໂຄງການຂອງທ່ານທັນທີ.** *ບັນທຶກ* ຂຽນທັບໄຟລ໌ນັ້ນ, ເຖິງແມ່ນມາຈາກໂປຣແກຣມອື່ນ. ຖ້າທ່ານຢາກເກັບຕົ້ນສະບັບໄວ້, ເລືອກ *ບັນທຶກເປັນ* ກ່ອນ.

**ຮູບແບບອື່ນບໍ່ຖືກຂຽນທັບເລີຍ.** ໄຟລ໌ `.csv`, `.xml`, `.mpp` ຫຼື `.xer` ບໍ່ມີໄຟລ໌ຂອງມັນເອງຫຼັງຈາກເປີດ. *ບັນທຶກ* ຂຽນໄຟລ໌ IFC ໃໝ່ ແລະ ປ່ອຍໄຟລ໌ເດີມໄວ້ຄືເດີມ.

**ໃນ Firefox ທຸກໆການບັນທຶກສ້າງໄຟລ໌ໃໝ່.** ແອັບບໍ່ສາມາດຂຽນເຂົ້າໄຟລ໌ຂອງທ່ານຢູ່ບ່ອນນັ້ນ. ມັນດາວໂຫຼດໄຟລ໌ໃໝ່ທຸກຄັ້ງ, ໂດຍໃຊ້ຊື່ໂຄງການເປັນຊື່ໄຟລ໌ ບໍ່ແມ່ນຊື່ຂອງໄຟລ໌ທີ່ທ່ານເປີດ.

**Chrome ແລະ Edge ຂໍອະນຸຍາດ.** ຕອນບັນທຶກຄັ້ງທຳອິດຂອງໄຟລ໌ທີ່ທ່ານເປີດ, ບຣາວເຊີຖາມວ່າແອັບຂຽນໄຟລ໌ນັ້ນໄດ້ບໍ. ຖ້າທ່ານປະຕິເສດ, ແອັບເປີດໜ້າຕ່າງທີ່ທ່ານເລືອກໄຟລ໌ໃໝ່. ໃນ Chrome ແລະ Edge ທ່ານກໍໄດ້ໜ້າຕ່າງນັ້ນເຊັ່ນກັນ ຖ້າການຂຽນໄຟລ໌ເດີມລົ້ມເຫຼວ, ຕົວຢ່າງ ເພາະໄຟລ໌ຫາຍໄປ ຫຼື ຖືກລັອກ.

**ການບັນທຶກອາດລົ້ມເຫຼວ.** ຖ້າການບັນທຶກເອງສົ່ງຂໍ້ຜິດພາດ, ແອັບລາຍງານ *ບັນທຶກບໍ່ສຳເລັດ*, ພ້ອມເຫດຜົນ. ໂຄງການຂອງທ່ານຍັງເປີດຢູ່ ແລະ ຍັງຖືກໝາຍວ່າ *ຍັງບໍ່ໄດ້ບັນທຶກ*.
