# タスクの選択、削除、元に戻す

目的: タスクを選択し、削除し、誤った操作を取り消します。

## いつ必要か

スケジュールのほぼすべての操作は、選択したタスクに対して行われます。たとえば、削除、コピー、インデント、マイルストーンの設定と解除です。仕事がなくなったときや、スケジュールを見直したときに、タスクを削除します。アプリは削除時に確認を求めないため、*元に戻す* が安全策になります。

## 手順

### タスクを選択する

- **一つのタスク。** タスクテーブルの行、または Gantt のバーをクリックします。
- **複数のタスク。** Ctrl+クリック（Mac では ⌘+クリック）で、タスクを選択に追加するか、選択から外します。タスクテーブルでは、Shift+クリックで、アクティブなタスクからクリックしたタスクまでのすべてのタスクを選択します。
- **表示されているすべてのタスク。** フォーカスがタスクテーブルまたは Gantt にある状態で Ctrl+A を押します。フィルターで非表示になっているタスクは対象外です。折りたたまれたフェーズ内のサブタスクも対象外です。
- **Gantt で囲んで選択。** Ctrl を押したまま、何もない背景の上をドラッグします。囲みに触れた行のすべてのタスクが選択されます。バーが囲みの横にあっても選択されます。囲みの高さだけが影響し、時間軸は影響しません。マウスボタンを離した後で Ctrl を離すと、既存の選択に追加されます。それ以外の場合は、既存の選択を置き換えます。Ctrl なしでこのドラッグを行うと、既定の設定ではタイムラインがスクロールします。
- **何も選択しない。** Esc を押すか、Gantt の何もない背景をクリックします。

サマリータスクを選択しても、そのサブタスクは一緒に選択されません。削除とコピーでは、サブタスクも一緒に対象になります。

### タスクを削除する

タスクを選択し、次のいずれかの方法を選びます。

- *ホーム › 編集 › 削除*。同じボタンは *テーブル* タブにもあります。
- Delete キーまたは Backspace キーは、フォーカスがタスクテーブルにない場合に使えます。そのため、先に Gantt のバーをクリックします。
- 右クリックメニューの *削除*。クリックしたタスクが選択に含まれている場合は、選択全体に適用されます。含まれていない場合は、そのタスクだけに適用されます。
- *プロパティ* パネルの上部にある小さなごみ箱アイコン（ツールチップ *タスクを削除*）。これは、パネルに表示されているタスクを削除します。

アプリは確認を求めません。複数のタスクを一度に削除すると、*元に戻す* の一回の操作になります。

一緒に消えるものは次のとおりです。削除したサマリータスクのすべてのサブタスク、削除したタスクとの間のすべての関係、およびそれらのタスクのリソースの割り当てです。サマリータスクの最後のサブタスクを削除すると、そのサマリータスクは通常のタスクとして残ります。*WBS auto* が有効な場合、アプリはツリーの番号を振り直します。その後、スケジュールは最新ではなくなります。*自動計算* が有効でない場合は、**計算**（F5）を押します。

### 折りたたみと展開

サマリータスクには、タスクテーブルでその名前の前に三角形のマークがあります。それをクリックすると、サブタスクを非表示にしたり、表示したりします。*表示 › アウトライン › 折りたたむ* と *展開* を使うと、選択したサマリータスクに対して操作します。何も選択していない場合は、すべてのサマリータスクに対して操作します。サマリータスクの右クリックメニューにも *折りたたむ* と *展開* があります。グループ化された表示では、ボタンはグループに対して動作します。

アプリは、折りたたみと展開の状態を開いているドキュメントごとに保持します。これは *元に戻す* の対象ではなく、プロジェクトファイルにも保存されません。

### 元に戻すとやり直す

- *ホーム › 編集 › 元に戻す* と *やり直し*（*テーブル* タブにもあります）、タイトルバーの矢印、または元に戻すには Ctrl+Z、やり直すには Ctrl+Y または Ctrl+Shift+Z を使います。
- *元に戻す* の後で新しい操作をすると、*やり直し* はできなくなります。

*元に戻す* は、プロジェクトデータ（タスク、関係、リソース、カレンダーなど）の変更と、レイアウトの適用を対象とします。タスクテーブルの列の変更も操作として記録されます。列の追加、削除、移動、サイズ変更、自動調整、固定、および列のレイアウトを既定値へリセットすることが該当します。これらの列の操作はタスクテーブル自体に属し、一つのドキュメントではなくアプリ全体に適用されます。アプリは、ドキュメントごとに直近百件の操作を保持します。非常に大きなプロジェクトでは、件数が減ります。

## 注意点とアプリの動作

**タスクテーブルでの Delete は、タスクを削除しません。** フォーカスがタスクテーブルにある場合、Delete キーまたは Backspace キーは、選択したセルの内容を消去します。名前や期間など、必須または計算されるセルの場合、アプリは消去を拒否し、タスクテーブルの下にメッセージを表示します。たとえば名前の場合は *この値は必須で、空にはできません。* と表示されます。その場合、他の選択したセルも含めて、何も消去されません。Gantt のバーをクリックするか、*削除* を使います（Gantt がない *テーブル* タブでは、*テーブル › 編集 › 削除* または右クリックメニューを使います）。

**フェーズ全体が一度に消えます。** サマリータスクを削除すると、そのサブタスク、関係、割り当ても一緒に削除されます。*元に戻す*（Ctrl+Z）を使うと、すべてが戻ります。関係と割り当ても含まれます。

**元に戻らないもの。** 選択、折りたたみと展開、および *フィルター/グループ化/並べ替え中は使用できません* の帯にある *クリア* ボタンは、*元に戻す* の対象ではありません。*クリア* の後に Ctrl+Z を押すと、クリアではなく、その前の操作を取り消します。

**他のタスクが依存しているタスクを削除する。** そのタスクとの間の関係も消えます。そのタスクにだけ接続されていたタスクは接続が外れます。**計算** の後、それらのタスクは自身の計画された開始日に戻ります。必要な場合は、新しい関係を追加します。詳しくは [関係の追加](docs://howto-relaties-leggen) を参照してください。
