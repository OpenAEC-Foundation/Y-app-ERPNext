# リソースカレンダーを設定する

目標: リソースが利用できる日を記録します。こうすると、ヒストグラム、過剰割り当て、山崩しは、この情報を使って計算されます。

## 必要になるとき

レンガ積みの班は、月曜日から木曜日までだけ稼働します。クレーンは、8月の最初の 2 週間は別のプロジェクトで使われます。下請け業者には、固定の稼働日が 4 日あります。専用のカレンダーがない場合、アプリはリソースがプロジェクトカレンダーの稼働日に稼働すると想定します。

リソースカレンダーは、タスクの日付を一切変更しません。リソースが利用できる日を決めるだけです。タスクがリソースの稼働しない日に作業する場合、その日のキャパシティは 0 になり、その日は過剰割り当てとして数えられます。タスク自体を別の日に実行したい場合は、そのタスクに専用のカレンダーを割り当ててください（[カレンダーを作成して割り当てる](docs://howto-kalender-maken-en-toewijzen)）。この違いは[カレンダーと稼働日](docs://uitleg-kalenders)で説明しています。

## 手順

### 新しいリソースカレンダーを作成する

1. *リソース › 管理 › リソース* を選択します。リソースパネルが開きます。リソースがまだない場合は、*プロジェクトに新規リソース* で作成します。
2. リソースの行を探します。*カレンダー* 列では既定が *プロジェクトカレンダー* です。その場合、リソースはプロジェクトカレンダーに従います。
3. その一覧で *+ リソースカレンダー* を選択します。*リソースカレンダー* ウィンドウが開きます。このウィンドウには、カレンダーフォームと同じ項目があります: *名前*、*稼働日*、稼働時間、そして *祝日* です。新しいカレンダーは標準カレンダーのコピーとして作成され、名前は *リソースカレンダー* です。
4. リソースに合う名前をカレンダーに付けます。例: *Crew Mon–Thu*。次に *稼働日* を設定します。*稼働日* の下で金曜日をクリックして、オフにします。*祝日* の一覧には、*祝日を追加* で祝日や稼働停止日を入れます。
5. *適用* をクリックします。カレンダーは、リソースライブラリに入り、リソースに割り当てられます。この操作は 1 回で完了し、*元に戻す* で取り消せます。*キャンセル* を選択すると、何も作成されません。

### 既存のカレンダーを選択または調整する

*カレンダー* 列で、一覧からカレンダーを選択します。*プロジェクトカレンダー* を選ぶと、リソースの専用カレンダーは再び解除されます。選択したカレンダーを調整する場合は、一覧の横の鉛筆のアイコンをクリックします（*編集…*）。現在のカレンダーを使って *リソースカレンダー* ウィンドウが開きます。

### 結果を確認する

1. ステータスバーに *古くなっています — 再計算してください（F5）* と表示される場合は、**計算**（F5）を押します。
2. *リソース › ヒストグラム › ヒストグラム* を選択し、ヒストグラムの左側の一覧でリソースをクリックします。リソースが稼働しないのに、スケジュールに割り当てられている日は赤で表示されます。その日にマウスを合わせると、例えば *カレンダー「Crew Mon–Thu」によりこの日は稼働しません* と表示されます。
3. *リソース › 山積み（超過割り当て）* に、過剰割り当てのリソース数が表示されます。また、ステータスバーには、例えば *1 件のリソースが過剰割り当て* と表示されます。

## よくある問題と、そのときのアプリの動作

**数えるのは日だけで、時間は数えません。** リソースカレンダーは、リソースが稼働する日を決めます。その日に利用できる単位数は、リソースの *最大単位数* から決まります。カレンダーの稼働時間からは決まりません。

**山崩しでは必ず解決できるとは限りません。** タスクのすべての日がリソースの稼働日に当たる期間がない場合、移動しても効果がありません。*リソース › 山崩し › 山崩し…* を選択し、*計算* をクリックします。その場合、タスクは *残っている競合* の下に表示され、理由は *このリソースはこのタスクが必要とするすべての日に稼働していません — 移動では解決できません。* と表示されます。その後、タスクを別のリソースに割り当てるか、タスクに専用のカレンダーを割り当ててください。

**共有のカレンダー。** 一覧には、プロジェクトのすべてのカレンダーが表示されます。プロジェクトカレンダーとタスクのカレンダーも含まれます。そのようなカレンダーを鉛筆のアイコンで調整すると、そのカレンダーを使うタスクのスケジュールも変わります。ステータスバーには *古くなっています — 再計算してください（F5）* と表示されます。代わりに、リソース用の専用カレンダーを作成してください。

**過剰割り当ては、必ずしもカレンダーが原因ではありません。** 毎日稼働するリソースでも、過剰割り当てになることがあります。ツールチップがカレンダーに言及するのは、その日がリソースの稼働日でない場合だけです。
