# MS Project ファイル (.mpp) を開く

目標: Microsoft Project のスケジュールを、先に書き出さずにアプリで直接開きます。

## 必要なとき

請負業者、コンサルタント、またはクライアントが、スケジュールを `.mpp` ファイルで送ってきます。そのスケジュールを表示、計算、またはさらに編集したい場合に使います。アプリは MS Project 2010 から 2021 までの `.mpp` ファイルを読み込みます。読み込みのみを行います。`.mpp` への書き込みは行わず、ファイルを変更することもありません。アプリは、ファイルからスケジュールそのものを取り込みます。取り込むのは、構造と期間と制約を持つタスク、ラグ付きの関係、カレンダー、リソース、割り当て、進捗です。アプリは、MS Project が自ら計算した日付とフロートも読み込みます。ただし、それらは *記録された日付* ビューでのみ使い、入力としては決して使いません。

## 手順

1. *ホーム › ファイル › 開く* を選択するか、Ctrl+O を押します。`.mpp` ファイルを選択します。
2. プロジェクトは、新しいタブで開きます。まだ空で変更されていない場合は、現在のタブで開きます。プロジェクトにはファイルがありません。後で *保存* を選択すると、新しい IFC ファイルが作成されます。
3. 下部のメッセージを読みます: *このプロジェクトは Microsoft Project として計算されます。ファイル → プロジェクト情報 → 計算プロファイルとオプション で変更できます。* アプリは、このプロジェクトを MS Project の計算ルールで計算します。計算プロファイルは *Microsoft Project* です。*計算プロファイルを開く* を選択すると、その設定に移動します。*詳細を見る* を選択すると、計算プロファイルについてのヘルプが開きます。
4. リボンの下にメッセージが表示されているか確認します: *ファイルに記録されている日付を表示しています。再計算すると 4 件のタスクがずれます。* その場合、それらのタスクでは、アプリの結果が MS Project が保存した日付と異なります。その場合、手順 3 のメッセージの下にも次の行が表示されます: *ファイルに記録された日付をそのまま表示しているタスク: 4 件（再計算していません）*。その意味と、アプリ自身の計算に切り替える方法は [記録された日付](docs://uitleg-datums-zoals-opgeslagen) に記載されています。
5. *このファイルには時間単位の計画が含まれています。* というメッセージと *時間計画を有効にする* ボタンが表示される場合、ファイルには時間単位のデータが含まれています。[時間計画を有効にする](docs://howto-urenplanning-aanzetten) を参照してください。

ファイルに分割、山崩し、またはリソース主導の計画のタスクが含まれる場合、別のメッセージも追加されます。例: *この MS Project ファイルには、分割・山崩し・リソース主導で計画されたタスクが 3 件含まれています。そのまま読み込まれ、表示されます。* タスクが一つだけの場合は、メッセージの言い回しが変わります。

## 落とし穴と、その場合のアプリの動作

**すべてが引き継がれるわけではありません。** アプリは、MS Project のベースライン、コストと単価、メモ、カスタムフィールドを引き継ぎません。MS Project で自分で入力した WBS は引き継がれます。それ以外の場合、アプリは構造に従ってタスクに番号を付けます。

**MS Project 2007 以前のファイル。** アプリはこのファイルを拒否し、次のように報告します: *この .mpp ファイルは古い形式（Project 2007 以前）を使用しています。MS Project で XML としてエクスポートし（ファイル → 名前を付けて保存 → XML）、そのファイルを開いてください。* メッセージの下に、アプリは英語で技術的な理由を追加します。

**パスワード付きのファイル。** アプリは次のように報告します: *この .mpp ファイルはパスワードで保護されています。MS Project で XML としてエクスポートし（ファイル → 名前を付けて保存 → XML）、そのファイルを開いてください。* ここでも、メッセージには英語の技術的な理由が付きます。

**実際には `.mpp` ではないファイル。** *ファイルを開けませんでした* と表示され、技術的な理由が付きます。

**XML で開くと計算が異なります。** `.mpp` の代わりに MS Project の XML エクスポートを開くと、アプリは計算プロファイル *Open Planner Studio* で計算します。*Microsoft Project* に関するメッセージは表示されません。その場合、日付は `.mpp` ファイルの場合と異なる結果になることがあります。

**編集すると、MS Project の制御が解除されます。** MS Project の日付ウィンドウによって計画されたタスクを編集すると、アプリはプロジェクトごとに一度、次のように報告します: *この編集の後、MS Project の時間配分はもう 2 件のタスクを制御していません。元の配分はファイルに保存されたままです。* タスクが一つだけの場合は、メッセージの言い回しが変わります。

**保存しても `.mpp` は上書きされません。** プロジェクトにはファイルがありません。*保存* を選択すると、新しい IFC ファイルの保存先を尋ねられます。
