# 制約または期限を設定する

目的: タスクに日付の合意を記録します。スケジュールがそれを考慮するか、守れていないことを表示します。

## 必要になる場面

レンガは6月21日にならないと届かないため、れんが積みは前倒しで開始できません。そのため **制約** *指定日以降に開始 (SNET)* を使います。屋根は建設業の祝日の前に完成している必要があります。計画どおりに進まない場合は警告を受け取りたい。そのため **期限** を使います。コンクリート打設は、生コンクリート工場が約束したため、ある日に固定されています。そのため *指定日に開始* を使います。どの種類をいつ使うか、そしてアプリがそれをどう扱うかは、[制約と期限](docs://uitleg-constraints) で説明しています。

## 手順

*プロパティ* パネルで制約と期限を設定します。

1. タスクを選択します。*プロパティ* パネルが表示されていない場合は、*表示 › パネル › プロパティ* で表示します。
2. *制約* で種類を選択します。例: *指定日以降に開始 (SNET)*。
3. *できるだけ早く (ASAP)* と *できるだけ遅く (ALAP)* 以外のすべての種類では、*制約日* 欄が表示されます。日、月、年の三つの欄に日付を入力し、Enter を押します。例: 21、06、2027。欄がいっぱいになると、アプリは次の欄へ自動的に移動します。種類を選ぶと、すでに日付が入っています。それは前の制約の日付か、なければタスクの元の計画された開始日です。パネルに表示される開始日と異なる場合があります。そのため、必ず自分が意図する日付を入力してください。
4. 先行タスクより前であっても、タスクを日付に固定したい場合は、*指定日に開始 (MSO)* または *指定日に終了 (MFO)* を選び、*必須（ピン留めロジック）* にチェックを入れます。これはハード制約です。本当に固定されている日付にだけ使用してください。
5. もう一つの制限が必要な場合は、例えば、タスクを6月14日より前に開始できず、6月17日までに終了させる必要がある場合、*副制約* で種類を選び、*副日付* を入力します。この欄は、日付を持つすべての制約で表示されます。ただし、ハード制約の場合を除きます。MSO と MFO では副制約は許可されていません。その場合、アプリは副制約を赤で表示します。
6. 期限を設定するには、*期限* 欄に制約日と同じ方法で入力します。期限は制約とは別のものです。同じタスクに両方を設定できます。
7. **計算** (F5) を押します。例えば *ホーム › スケジュール › 計算* から実行します。それまでは、ステータスバーに *古くなっています — 再計算してください（F5）* と表示されます。

同じ欄は *タスクの編集* ウィンドウにもあります。タスクを右クリックし、*編集...* を選ぶと開きます。*保存* で確定します。

テーブルでは列を使って作業します。テーブルのヘッダーにある **+** をクリックし、*制約* の下で、列 *制約の種類*、*制約日*、*期限* を選びます（ほかに *ハード制約*、*副制約の種類*、*副制約日* もあります）。セルをダブルクリックして編集します。一覧から種類を選び、ハイフン付きで日付を入力します。例: 21-06-2027。*ハード制約* は、MSO と MFO の場合にのみ変更できます。

タスクに先行タスクがある場合は、*指定日以降に開始 (SNET)* の近道があります。*開始* 欄（*プロパティ* パネル、*タスクの編集*、またはテーブル）に新しい開始日を入力するか、Gantt のバーを移動するだけです。アプリはそれを自動的に *指定日以降に開始 (SNET)* の制約に変換し、その旨を知らせます。

## 結果を確認する

- Gantt では、バーの上に小さなひし形が表示されます。開始の制約の場合は開始側に、終了の制約の場合は終了側に表示されます。色は、SNET と FNET が青、SNLT、FNLT、MSO、MFO が紫、制約違反の場合は赤です。ハード制約にはピンが付きます。期限は、期限日の上に表示される下向きの矢印です。期限内に終了していれば緑、遅れていれば赤です。
- 制約違反または期限超過は、*警告* パネル（*計画 › スケジュール › 警告*）と、ステータスバーに表示されます。その場合、タスクとその先行タスクの *トータルフロート* はマイナスになります。
- 上限（*指定日以前に開始 (SNLT)*、*指定日以前に終了*）または期限がある場合、警告がないことは、スケジュールがその日付を守っていることを意味します。

## 制約または期限を削除する

*制約* で、もう一度 *できるだけ早く (ASAP)* を選びます。これにより副制約も削除されます。期限を削除するには、三つの欄を空にして Enter を押します。その後、**計算** を押します。

## 注意点とアプリの動作

**フェーズの制約。** フェーズ（サマリータスク）に設定した制約や期限は効果がありません。タスク自体に設定してください。

**すでに開始しているタスク。** タスクに実績開始日または進捗がある場合、その実績開始日はそのまま残ります。*指定日以降に開始 (SNET)* で後の日付を設定しても、タスクは移動しません。

**別の制約がある状態で開始日を入力する。** タスクに先行タスクがあり、すでに別の制約がある場合（例: *できるだけ遅く (ALAP)*）、アプリは入力された開始日を適用しません。メッセージには制約の名前が表示されます。開始日を移動したい場合は、その制約を変更してください。

**週末の日付。** 土曜日、日曜日、祝日や休業日の日付は、稼働日としてカウントされます。下限（*指定日以降に開始 (SNET)*、*指定日以降に終了*）の場合は次の稼働日として、上限（*指定日以前に開始 (SNLT)*、*指定日以前に終了*）の場合は前の稼働日として扱われます。

**許可されていない副制約。** アプリは、無効な組み合わせを理由とともに赤で表示します。例: *主制約と副制約は同じ側を境界にできません。* 副制約は、ASAP、ALAP、MSO、MFO、ハード制約と一緒には使用できません。

**ハード制約。** 初めてオンにすると、アプリはハード制約が関係を上書きすることを警告します。その場合、タスクは先行タスクより前であっても、その日付に置かれます。それらの先行タスクは負のフロートになります。

**設定後に何も変わらない。** 制約は **計算** の後にのみ有効になります。上限（*指定日以前に開始 (SNLT)*、*指定日以前に終了*）がバーに影響しない場合は、正常です。上限はタスクを移動しません。日付を守れない場合は、負のフロートになります。
