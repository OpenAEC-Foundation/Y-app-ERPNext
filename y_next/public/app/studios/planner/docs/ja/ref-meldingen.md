# 通知と警告

アプリは次の三か所で状況を知らせます。下部のステータスバー、右側の列にある *警告* パネル、そして画面下部に短時間表示される通知です。この記事では、各場所に何が表示されるか、いつ表示されるか、そして何ができるかを説明します。スケジュールがクリティカルである理由や過剰割り当ての理由は[クリティカルパスとフロート](docs://uitleg-kritiek-pad)に記載されています。過剰割り当ての解消は[過剰割り当ての解消](docs://howto-overbezetting-oplossen)に、関係の作成は[関係の作成](docs://howto-relaties-leggen)に記載されています。

## 三つの違い

- **ステータスバー** — カウンターを表示する固定の行です。カウンターは前回の計算の結果です。次に計算するまで表示されたままです。
- **警告パネル** — カウンターの元になる一覧です。前回の計算で見つかったすべての項目を表示します。項目をクリックすると、タスク、関係、またはリソースへ移動します。前回の計算から導き出されるため、何も保存されません。
- **通知** — 直前の操作に関する短いメッセージです（保存の失敗、関係の拒否、インポートの読み込み完了など）。通知は再び消え、警告パネルには表示されません。

## ステータスバー

下部のバーには、左から右へ次の項目が表示されます：

- **タスク:** — リーフタスクの数です（サマリータスクは数えません）。
- **マイルストーン:** — マイルストーンの数です。
- **クリティカルパス: N 件のタスク、N 稼働日** — クリティカルタスクの数とプロジェクトの期間です。計算後にのみ表示されます。
- **終了:** — 計算によるプロジェクト終了日です。計算後にのみ表示されます。空のプロジェクトには終了日がありません。
- **N 件の期限超過**、**N 件の制約違反**、**N 件の順序外進捗の関係** および **N 件の過剰割り当てのリソース** — 警告マーク付きのボタンです。カウンターが 0 より大きく、計算がある場合にのみ表示されます。クリックすると *警告* パネルが開きます（ツールチップ: *警告パネルを開く（詳細とナビゲーション）*）。*IFC* または *レポート* タブを表示している場合、右側の列はそこにないため、アプリは同時に *ホーム* へ切り替わります。*過剰割り当てのリソース* のカウンターは、リソースと割り当ての変更後にも更新されます。ほかのカウンターは *計算* の後にのみ変わります。ステータスバーに表示されるのは四つのカウンターだけです。パネルに追加で表示される項目（切り詰められたリード、無視された関係、終了ドライバーのないハンモック、打ち切られた終了日、スケジュールエラー）は、ステータスバーには含まれません。
- **古くなっています — 再計算 (F5)** — 警告マーク付きの表示です（ツールチップ: *スケジュールが古くなっています — 再計算してください（F5）*）。スケジュールに影響する変更をして、まだ再計算していない場合にすぐ表示されます。*自動計算* がオンの場合は表示されません。ただし、計算でエラーが出た場合は表示されたままです。
- **選択: N 件のタスク** — 選択されているタスクの数です。選択がある場合にのみ表示されます。
- **スケール:** と **ズーム: Npx/日** — タイムラインのタイムスケールとズームレベルです。スケールはズームから決まります。
- **未保存** — ドキュメントに、ファイルに保存されていない変更がある間、表示されます。
- **AI** — 色付きの点と文字 AI です。AI モードがオンの場合にのみ表示されます。ツールチップには *AI ブリッジ:* と、*オフ*、*ポート N で稼働中*、*ポート N は使用中です*、または *エラー* が表示されます。クリックすると *AI* タブが開きます。
- **デバッグターミナル** — ターミナルのボタンです。デバッグターミナルが有効な場合にのみ表示されます。ボタンでターミナルを表示または非表示にします（*デバッグターミナルを表示* / *デバッグターミナルを非表示*）。

## 警告パネル

- **開く** — *計画 › スケジュール › 警告*、*表示 › パネル › 警告*、またはステータスバーのカウンターです。パネルは右側の列にあり、*プロパティ* とリソースドックの下に表示されます。折りたたまれた列は展開されます。既定では閉じており、セッションをまたいで記憶されません。ほかのパネルの下にある場合は、端をドラッグして高さを変えられます。その高さは記憶されます。右上の×ボタン（*警告を閉じる*）で閉じます。
- **見出し行** — *エラー N 件、警告 N 件*。まだ何も計算されていない場合は、*まだ計算されていません — 計算 (F5) を押してチェックを実行してください。* と表示されます。
- **計算** — 見出し行にあるボタンです。スケジュールが古い場合、またはまだ計算されていない場合に表示されます。リボンの *計算* と同じ動作をします。
- **見出し行の警告マーク** — スケジュールが古い場合に表示されます。ツールチップは *スケジュールが古くなっています — この一覧は前回の計算結果です。再計算 (F5) してください。* です。一覧は隠れず、古いとマークされるだけです。
- **空の一覧** — *警告はありません。スケジュールはすべてのチェックに合格しています。*
- **一行** — 上に場所（タスク、関係、リソース、またはプロジェクト）、その下に説明が表示されます。エラーには八角形の記号、警告には三角形の記号が付きます。タスクは `WBS名` と表示されます。関係は `先行タスク → 後続タスク (FS+2d)` と表示され、種類とラグも含まれます。場所をクリックすると、その場所へ移動します（ツールチップ: *移動先: …*）。下記も参照してください。アクティブなタスクの行（関係の場合は後続タスク）、またはヒストグラムで選んだリソースの行は強調表示されます。
- **順序** — エラーが先に表示されます。その後、下記の一覧の順に種類ごとに並びます。種類の中では、プロジェクト内の順です（関係の場合は後続タスクの順、リソースの場合はリソース一覧の順）。前回の計算後に削除されたタスク、関係、またはリソースは一覧から消えます。

### 警告の種類

- **スケジュールエラー** — *スケジュールを計算できませんでした: …* 理由は後ろに続きます。下記を参照してください。クリックすると、循環の場合はアプリが循環内のすべてのタスクを選択し、最初のタスクへ移動します。ほかのエラーでは移動先がないため、その行はボタンではありません。
- **期限超過** — *期限 {date} を超過 — 最早終了 {date}*。タスクには期限がありますが、計算結果がそれを満たしていません。クリックするとタスクへ移動します。修正するには、ロジックまたは期間を調整するか、期限を変更します。
- **制約違反** — *制約 {type and date} がロジックによって上書きされています（負のフロート）*。制約は、ロジックを壊さずに満たせません。フロートは負の値です。クリックするとタスクへ移動します。[制約](docs://uitleg-constraints)も参照してください。
- **順序外進捗** — *順序違反: 後続タスクの進捗が関係と矛盾しています*。後続タスクの進捗が関係の種類に合いません。たとえば、終了-開始の関係で、先行タスクがまだ終わっていないのに後続タスクがすでに進行中の場合です。クリックすると両方のタスクが選択され、後続タスクがアクティブになります。実績日または関係を確認してください。
- **リード切り詰め** — *リードがプロジェクト開始で切り詰められました — 関係が完全には守られていません*。関係のリード（負のラグ）が、プロジェクト開始日より前に及んでいます。クリックすると両方のタスクが選択されます。
- **関係の無視** — *関係を無視: 先行または後続が存在しないか、リーフタスクではありません*。計算はこの関係を使いません。クリックすると、まだ存在するタスクが選択されます。[関係](docs://uitleg-relaties)も参照してください。
- **終了ドライバーのないハンモック** — *終了ドライバーのないハンモック（FF/SF の先行なし）: 期間はゼロになります*。クリックするとタスクへ移動します。[ハンモックタスク](docs://howto-hammock)も参照してください。
- **終了日の打ち切り** — *終了日が打ち切られました: カレンダーにこのタスクの作業可能な期間がありません*。計算が、検索できる日数の上限に達しました。たとえば、カレンダーに非稼働日が非常に長く続いている場合です。クリックするとタスクへ移動します。[カレンダーと稼働日](docs://uitleg-kalenders)も参照してください。
- **過剰割り当て** — *N 日間過剰割り当て（first – last）*。すべての日が非稼働日の場合は *リソースはカレンダーによりこれらの日には作業しません* が追加されます。一部の日だけの場合は、*そのうち N 日はリソースがカレンダーにより作業しません* と表示されます。クリックすると、そのリソースに割り当てられたタスクが選択され、ヒストグラムがオンになり、そのリソースが選択されます。*テーブル*、*IFC*、または *レポート* から開いた場合は、アプリは *リソース* へ移動します。[リソースパネル](docs://ref-resourcepaneel)も参照してください。

### スケジュールエラーの理由

- *タスク間に循環依存があります: {path}* — 関係が循環を作っています。タスクはこのパスに含まれます。関係を一つ逆にするか、削除します。
- *カレンダーに稼働日が設定されていません* — カレンダーに稼働日を少なくとも一つ設定します。[カレンダーの時間帯](docs://ref-kalenders)を参照してください。
- *タスク「{task}」の日単位の期間が無効です* および *タスク「{task}」の時間単位の期間が無効です* — タスクの期間が有効な数値ではありません。
- *時間タスク「{task}」のカレンダーに有効な稼働時間がありません* — 時間単位のタスクが、稼働時間のないカレンダーにあります。
- *タスク「{task}」の開始日が無効です* — タスクの開始日が有効ではありません。

## 通知

通知は画面の下部に表示されます。テーブル、バックステージ、プレゼンテーションモードにも表示されます。通知は *エラー* または *情報* です。エラーは、クリックして消すまで表示されたままです。情報は 5 秒後に消えます。スタックが変わるたびに、タイマーは最初から数え直されます。通知をクリックすると、その通知は閉じます（ツールチップ *通知を閉じる*）。同時に表示されるのは最大 3 件です。4 件目が来ると、最も古い情報が先に消えます。情報がない場合は、最も古い通知が消えます。そのため、エラーが情報によって押し出されることはありません。スタックは、開いているダイアログのボタンや固定されたアクションバーを避けて移動します。

- **カウンター ×N** — 固定のキーを持つ通知は、繰り返しを 1 行にまとめ、カウンターを表示します。例えば、何度も戻ってくる保存エラーや、繰り返し拒否された関係などです。すべての通知がこれを行うわけではありません。
- **詳細を見る** — 一部の通知には、*詳細を見る* リンクや独自のトピック（例：*作業ルールの説明*）があります。これは、バックステージ › ヘルプのガイドへのリンクです。
- **アクションボタン** — 計算プロファイルに関する通知には、*計算プロファイルを開く* ボタンがあります。このボタンでプロジェクト情報を開きます。

以下の一覧は一部の通知を、トピックごとにまとめたものです。特に記載がない場合、その通知は情報です。

### 保存、開く、復元

- **保存に失敗** (エラー) — *保存できませんでした* と、その下に理由が表示されます。保存、名前を付けて保存、およびレポートのエクスポート時に表示されます。
- **ダウンロードとして保存** (情報) — *ダウンロードとして保存しました: '{name}' がダウンロードフォルダーに保存されました。…* *名前を付けて保存* およびエクスポート時に、環境によってアプリがユーザーの選んだ場所へ直接書き込めない場合に表示されます。2 つのダウンロードが続けて行われると、1 行にまとめられます。
- **ダウンロードとして保存（説明）** (情報) — *ダウンロードとして保存しました: '{name}' はダウンロードフォルダーにあります。このブラウザーでは、アプリが独自の場所に書き込むことはできません。…* ダウンロードでしか保存できないブラウザーで *保存* を使うと表示されます。セッションごとに 1 回表示され、ファイルの説明へのリンクが付きます。
- **ブラウザーは書き戻しません** (情報) — *このブラウザーでは、アプリが '{name}' に書き戻すことはできません。…* ファイルを持つプロジェクトを *保存* したときに、ブラウザーが保存先を改めて尋ねる必要がある場合に表示されます。セッションごとに 1 回表示され、ファイルの説明へのリンクが付きます。
- **自動保存に失敗** (エラー) — *自動保存に失敗しました* と理由が表示されます。ファイルへの自動保存とクラッシュ復元の両方に適用されます。
- **ライブラリを保存できませんでした** (エラー) — *ライブラリを保存できませんでした*。リソースライブラリを保存するときに表示されます。
- **ファイルを開く操作に失敗** (エラー) — *ファイルを開けませんでした* と理由が表示されます。例えば、最近使ったファイルや読み込んだファイルの場合です。
- **古い形式または保護された .mpp** (エラー) — *この .mpp ファイルは古い形式です（Project 2007 以前）…* または *この .mpp ファイルはパスワードで保護されています…* が表示されます。どちらも、MS Project で XML としてエクスポートし、そのファイルを開くよう案内します。
- **無効な XER ファイル** (エラー) — *XER…* で始まる文のいずれか（例：*これは有効または対応済みの XER ファイルではありません。* や *XER ファイルに重複したテーブルがあります。*）が表示され、理由が追加されます。
- **IFC を読み込めませんでした** (エラー) — *IFC を読み込めませんでした* と理由が、IFC ビューに表示されます。
- **復元** (エラー) — *復元したファイルを読み込めませんでした*、*復元に失敗しました*、および *N 件の復旧ファイルを読み込めなかったため、スキップされました。* が表示されます。予期せぬ終了の後で復元するときに表示されます。
- **ブランチをテンプレートとして保存** (情報) — *ブランチをテンプレート「{name}」として保存しました*。
- **拡張機能からのメッセージ** (情報、拡張機能がエラーを報告した場合はエラー) — *拡張機能 {name}: {message}*。拡張機能は 10 秒あたり新しいメッセージを最大 3 件まで表示できるため、スタックがいっぱいになることはありません。拡張機能のガイドのステップが失敗した場合は、*拡張機能 {name} のステップでエラーが発生しました。ガイドは続行します。* と表示されます。拡張機能のプロジェクトファイルを開けない場合は、*拡張機能 {name} のプロジェクトファイル {file} を開けませんでした。* と表示されます。どちらもエラーです。
- **途中で変更が入りました** (情報) — *AI アシスタントまたは拡張機能による変更が途中で入りました。…* タスクダイアログをキャンセルしたときに、その間に AI または拡張機能が何かを変更していた場合に表示されます。その変更より前のタスク編集は元に戻されず、*元に戻す* の下に通常の手順として残ります。

### 計算

- **スケジュールを計算できませんでした** (エラー) — *スケジュールを計算できませんでした* の下に理由が表示されます（*スケジュールエラーの理由* を参照）。*計算* 時、文書を切り替えたとき、およびファイルを開いたときに表示されます。
- **状態日を今日に設定** (情報) — *状態日がまだありませんでした。進捗は状態日までで測るため、今日（{date}）に設定しました。計画 → 状態日で変更できます。* 状態日がないプロジェクトで進捗を入力したときに表示されます。
- **完了済みの作業より短い期間は不可** (情報) — 「{name}」はすでに {N}% 完了しています。完了済みの作業より短い期間にはできません。期間は変更されていません。

### 関係と階層

- **関係を作成** (情報) — *関係を作成しました: {predecessor} → {successor}*。
- **関係を拒否** (情報) — *この関係はすでに存在します*、*タスクとその自身の(祖先)サマリータスクとの間の関係は許可されません。*、または *この関係はスケジュールに循環を発生させるため（{cycle}）、作成されませんでした。* が表示されます。循環にはタスクの名前が含まれるため、どの関係を先に削除または反転すべきかがわかります。
- **移動を拒否** (情報) — *この移動はスケジュールに循環を発生させます（{cycle}）。サマリータスクの関係はそのサブタスクにも適用されます。何も移動されませんでした。*
- **移動後に関係が外れる** (情報) — *移動後、N 件の関係がタスクをその自身の上位サマリータスクに結び付けています。これらは計算に含まれなくなりました。*
- **挿入時に関係をスキップ** (情報) — *N 件の関係は作成されませんでした：無効な関係…*。貼り付けまたはブランチの挿入時に表示されます。
- **インポート後に計算されない関係** (情報) — *N 件の関係が計算に含められませんでした。先行タスク列と後続タスク列を確認してください。*
- **インポート後の重複 ID** (情報) — *このファイルで ID が重複しているオブジェクト: N 件。それぞれに独自の ID が割り当てられました…*

### タスクの編集

- **開始日を制約として記録** (情報) — 「{name}」には先行タスクがあります。新しい開始日を制約「指定日以降に開始 (SNET)」{date} として設定しました。再計算（F5）後、このタスクはその日より前には開始しません。先行タスクがあるタスクの開始日を変更したときに表示されます。タスクにすでにこの制約があった場合は、制約を移動したことが通知に書かれます。複数のタスクを一度に変更した場合は、件数が表示されます。
- **開始日を適用しませんでした** (情報) — 「{name}」の新しい開始日は適用されませんでした。タスクには先行タスクと制約 {type} {date} があり、これらが開始日を決めます。開始日を移動するには、その制約を変更してください。
- **マイルストーンへの変換を拒否** (情報) — *リソースの割り当てがあるタスク N 件はマイルストーンにできません。先に割り当てを削除してください。* または *サブタスクを持つサマリータスク N 件はマイルストーンにできません。* が表示されます。タスクダイアログ、プロパティパネル、コンテキストメニュー、テーブルで変換したときに表示されます。
- **割り当てをサブタスクへ移動** (情報) — *N 件の割り当て（{resources}）を「{phase}」から新しいサブタスク「{child}」に移動しました。サマリータスク自体は割り当てを持ちません。* 割り当てのあるタスクにサブタスクが追加されたときに表示されます。
- **マイルストーン指定を解除** (情報) — *N 件のマイルストーンにサブタスクができ、サマリータスクになりました。マイルストーンの指定を解除しました。*
- **サマリータスクへの変換を拒否** (情報) — *「{phase}」はサマリータスクにできません：…* と理由が表示され、*何も変更されませんでした。* が表示されます。
- **貼り付け時にセルをスキップ** (情報) — *N 件の読み取り専用セルをスキップしました（例：自動採番の WBS コードや計算列など）。*
- **貼り付け時に参照をクリア** (情報) — *この文書に存在しない参照 N 件をクリアしました（元の文書のタスクカレンダー、カスタムタスク種類、アクティビティコード、カスタムフィールド）。*
- **作業ルールが期間を調整** (情報) — *カレンダー変更後、作業ルールにより N 件のタスクの期間が調整されました（作業は維持、1日の時間数が変更）。* *作業ルールの説明* へのリンク付きで表示されます。

### Primavera (XER)

- **XER ファイルを開きました** (情報) — *XER ファイルを開きました: プロジェクト文書 N 件。* ファイルごとに 1 件の通知です。ファイルが複数のプロジェクトを開く場合でも同じです。通知には *詳細を見る* リンクと、その下に詳細行が表示されます。常に *検出したプロジェクト: N* が表示されます。数が 0 より大きい場合にのみ、*空のプロジェクトをスキップ: N*、*除外したベースラインプロジェクト: N*、*具体化したベースライン: N*、*無効なベースライン参照を無視: N*、*保護的なベースラインのフォールバックを使用しました。*、および *外部関係を保持: N* が表示されます。UTF-8 以外のエンコーディングの場合のみ、*選択したテキストエンコーディング: {encoding}。* が表示されます。さらに、数が 0 より大きい場合は、*パーサーの検出事項: N*、*カレンダーの検出事項: N*、*数値形式の問題: N*、*列挙値のフォールバック: N*、および *安全なフォールバックを使った P6 計画設定: N* が表示されます。
- **Primavera が記録した日付** （同じ通知内の詳細行） — *Primavera が記録した日付をそのまま表示しているタスク: N 件（再計算していません）*、または、モードが有効になっていない場合は *ファイルに記録された日付と異なるタスク: N 件（表示できます）* が表示されます。
- **XER ソースアーカイブを使用できません** (情報) — *このファイルの XER ソースアーカイブは使用できないため除外しました。プロジェクト自体はすべて開かれています。* と、理由（例：*理由: チェックサムがソースバイトと一致しません。アーカイブが破損しています。*）および影響（*スケジュール、計算プロファイル、および IFC のすべてのプロジェクトデータは完全です。…*）とともに表示されます。以前に保存された XER ソースアーカイブを使用できない IFC ファイルを開いたときに表示されます。
- **エクスポートで XER 情報が失われる** (情報) — *{format} へのエクスポートでは XER のソース情報が失われます。* XER ファイルにしか存在しないデータを持つプロジェクトを、IFC 以外の形式へ正常にエクスポートした後に表示されます。*詳細を見る* リンク付きです。

### インポート、エクスポート、計算プロファイル

- **ファイル内の日付どおり** (情報) — *ファイルに記録された日付をそのまま表示しているタスク: N 件（再計算していません）。* または *ファイルに記録された日付と異なるタスク: N 件（表示できます）。* 記録された日付を持つファイルを開いたときに表示されます。
- **作業と作業ルールを表示** (情報) — *このファイルには保存済みの作業または独自の作業ルールが含まれています。このプロジェクトでは作業ルールと残作業が表示されます。*
- **MS Project の計画を読み込み** (情報) — *この MS Project ファイルには、分割・山崩し・リソース主導で計画されたタスクが N 件含まれています。そのまま読み込まれ、表示されます。*
- **中断をエクスポートしなかった** (情報) — *中断のあるタスク N 件は中断なしでエクスポートされました。MS Project/P6 では中断を作業配分としてしか扱えません。* MS Project または Primavera へのエクスポート時に表示されます。
- **プロジェクト開始日を変更** (情報) — *プロジェクト開始日を変更しました。先行タスクも制約もないタスクの起点 N 件を新しい開始日に合わせて移動しました。*
- **日付ウィンドウが制御しなくなった** (情報) — *MS Project の日付ウィンドウは、この編集の後、N 件のタスクを制御しなくなりました。…* 文書ごとに 1 回表示されます。
- **山崩し遅延を丸めた** (情報) — *山崩しは、MS Project の分単位の山崩し遅延（タスク N 件分）を整数の稼働日に丸めます。* 文書ごとに 1 回表示されます。
- **計算プロファイルを適用** (情報) — *このプロジェクトは {profile} として計算されます。ファイル → プロジェクト情報 → 計算プロファイルとオプション で変更できます。* ボタン *計算プロファイルを開く* 付きで表示されます。プロファイルを適用した後、必要な場合は *適用後に N 件のタスクが移動しました。* が続きます。
