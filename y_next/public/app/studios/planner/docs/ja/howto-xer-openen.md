# Primavera P6 ファイル (.xer) を開く

目的：Primavera P6 のスケジュールを、先に XML へエクスポートせずに、アプリで直接開きます。

## この機能が必要な場合

顧客または元請け業者は Primavera で作業し、スケジュールを `.xer` ファイルとして提供します。それを表示したり、計算したり、追加したりしたくなります。アプリは `.xer` ファイルを読み取るだけです。`.xer` への書き込みは行わず、お使いのファイルを変更することもありません。ファイルからは、WBS の構造と、期間、日付、制約、進捗を持つタスク、ラグ付きの関係、カレンダー、割り当て付きのリソースを読み取ります。さらに、アクティビティコード、カスタムフィールド（UDF）、メモ、P6 のスケジュール設定も読み取ります。タイプが *工数量ベース* のタスクは、ハンモックになります。

## 手順

1. *ホーム › ファイル › 開く* を選択するか、Ctrl+O キーを押します。`.xer` ファイルを選択します。
2. アプリは、タスクを持つプロジェクトごとにタブを一つ開きます。タスクが最も多いプロジェクトが、アクティブなタブになります。P6 のプロジェクト ID が名前と異なる場合、タブ名は *プロジェクト名（プロジェクト ID）* になります。
3. 下部のメッセージを読みます。三つのプロジェクトがあるファイルの場合、次のように表示されることがあります：*XER ファイルを開きました: プロジェクト文書 3 件。* その下には、アプリが行ったことを説明する行があります。詳しくは下の見出しを参照してください。
4. リボンの下に帯状のメッセージがあるか確認します：*Primavera が記録したスケジュールを表示しています。再計算すると 1 件のタスクがずれます。* Primavera は、自身が計算した日付をファイルに記録します。アプリの計算がそれらと異なる場合、変更しなければ、アプリは Primavera の日付を表示します。その意味と、アプリ自身の計算への切り替え方は [記録どおりの日付](docs://uitleg-datums-zoals-opgeslagen) に記載されています。メッセージ *このファイルには時間単位の計画が含まれています。* が、ボタン *時間計画を有効にする* と一緒に表示されることもあります。詳しくは [時間計画を有効にする](docs://howto-urenplanning-aanzetten) を参照してください。
5. Ctrl+S でプロジェクトを保存します。`.xer` ファイルは上書きされないため、アプリは新しい IFC ファイルの保存先を尋ねます。ファイル名として *プロジェクト名（プロジェクト ID）* を提案します。

### メッセージの下の行

メッセージの最初の行には、開いたタブの数が示されます。その下には、該当する行だけが表示されます。特に注意が必要な行は次のとおりです：

- *このプロジェクトは Primavera P6 として計算されます。ファイル → プロジェクト情報 → 計算プロファイルとオプション で変更できます。* アプリは、このプロジェクトを Primavera の計算ルールで計算します。*計算プロファイルを開く* を選ぶと、その設定に移動します。
- *除外したベースラインプロジェクト: 1* と *具体化したベースライン: 1*。 P6 のプロジェクトが別のプロジェクトをベースラインとして指定すると、そのもう一方のプロジェクトは独自のタブとしては開きません。それは、そのプロジェクトを参照している側の有効なベースラインになります。
- *保護的なベースラインのフォールバックを使用しました。* ベースラインを指定すると、どのプロジェクトも開けなくなる場合、プロジェクトが自分自身を参照する場合、またはプロジェクト同士が循環して参照し合う場合は、アプリは単にすべてのプロジェクトを開き、ベースラインを作成しません。
- *外部関係を保持: 1*。二つのプロジェクト間の関係です。アプリはそれをソースデータとして保持しますが、スケジュールの関係にはしません。
- *Primavera が記録した日付をそのまま表示しているタスク: 1 件（再計算していません）*。 *記録どおりの日付* ビューで表示されるタスクの数です。

それ以外の行は、読み取り自体の診断です。見つかったプロジェクトの数、スキップした空のプロジェクト、無視した参照先のないベースライン参照、UTF-8 以外のテキストエンコーディング、テーブル、カレンダー、数値での検出件数、不明なフィールド値、アプリが安全な選択肢に置き換えた P6 のスケジュール設定などです。これらの行で操作は必要ありません。*詳細を見る* を選ぶと、Primavera ファイルを開くことに関するヘルプが開きます。

## 注意点と、その場合にアプリが行うこと

**すべてがタブや関係になるわけではありません。** タスクのないプロジェクトは開かず、ベースラインのプロジェクトは独自のタブとしては開かず、プロジェクト間の関係はスケジュールの関係にはなりません。アプリは、その内容をメッセージの下の行で知らせます。

**どのタブも、それぞれ独立したプロジェクトです。** 一つ保存すると、IFC ファイルには元の `.xer` が完全な形で残ります。後でその IFC ファイルを開き直しても、アプリは Primavera の日付をまだ把握しています。そのソースアーカイブが壊れている場合、または別の IFC プログラムがファイルを書き換えた場合、アプリは次のように知らせます：*このファイルの XER ソースアーカイブは使用できないため除外しました。プロジェクト自体はすべて開かれています。* スケジュール、計算プロファイル、すべてのプロジェクトデータは揃っています。不足しているのは、Primavera が保存していた日付と、AI と拡張機能向けのソースの出所情報です。アーカイブを取り戻すには、元の `.xer` をもう一度開いてください。

**CSV、MS Project XML、または P6 XML へのエクスポートでは、データが失われます。** アプリは次のように警告します：*CSV へのエクスポートでは XER のソース情報が失われます。* IFC では何も失われません。

**アプリが読み取れないファイル。** 理由を示すエラーメッセージが表示されます。次に例を示します：

- *これは有効または対応済みの XER ファイルではありません。*
- *XER テーブルに必須列がありません。*
- *この XER ファイルの P6 プロジェクトにはアクティビティがありません。*

その場合、何も開きません。P6 でファイルを確認するか、送り主に新しいエクスポートを依頼してください。
