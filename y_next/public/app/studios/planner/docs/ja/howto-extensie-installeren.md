# 拡張機能のインストールと管理

目的：拡張機能をインストールし、許可の確認内容を読み、あとで拡張機能を無効にするか削除します。

## この操作が必要な場合

拡張機能を使うと、新しいバージョンを待たずにアプリに機能を追加できます。たとえば、拡張機能は *ファイル › インポート* に表示されるインポート形式を追加したり、リボンにボタンを置いたり、PDF エクスポート用のフォントを提供したりできます。公式カタログでは、拡張機能を次のカテゴリに分けています：*インポート/エクスポート*、*計画*、*レポート*、*ユーティリティ*、*フォント*、*その他*。

インストールする前に、よく考えてください。拡張機能は、アプリ自体と同じ権限で動作するプログラムコードです。アプリはその権限を制限できません。そのため、アプリはインストールのたびに許可を求めます。その質問に表示される内容は、以下で説明します。

## 手順

### カタログから拡張機能をインストールする

1. *ファイル › 拡張機能* を選択します。
2. *参照* タブを選択します。アプリは *カタログを読み込み中*... と表示している間に、カタログを取得します。カタログの内容は、それを管理する OpenAEC Foundation が決めます。この内容は変わることがあります。
3. *拡張機能を検索*... フィールドで拡張機能を検索します。検索対象は、名前、説明、作成者、タグです。
4. 各カードには、名前、バージョン、カテゴリ、説明、作成者が表示されます。*インストール* をクリックします。
5. *拡張機能をインストールしますか？* ウィンドウが開きます。内容を読み、次の手順を確認してください。
6. *インストール* をクリックして続行します。*インストールしない* を選ぶと、何も起こりません。Esc キーを押すか、ウィンドウの外側をクリックすることも拒否とみなされます。その場合、アプリはエラーメッセージを表示しません。

インストール後、拡張機能はすぐに有効になります。*参照* のカードには、*インストール済み* と表示されます。拡張機能が追加する内容は、アプリ内で確認できます。たとえば、リボンに新しいボタンが表示されたり、*ファイル › インポート* にインポート形式が表示されたりします。一部の拡張機能は、メッセージも表示します。そのメッセージは、接頭辞 *拡張機能* のあとに拡張機能の名前が続くことで見分けられます。

### ファイルから拡張機能をインストールする

拡張機能をファイルで受け取った場合は、次の手順でインストールします。

1. *ファイル › 拡張機能* を選択します。
2. 右上で、ZIP ファイルの場合は *ZIP* を、個別の JavaScript ファイルの場合は *JS* をクリックします。
3. ファイルを選択します。上記と同じく、*拡張機能をインストールしますか？* ウィンドウが開きます。

ZIP ファイルには、`manifest.json` と拡張機能の本体ファイルを含める必要があります。すでにインストールされている拡張機能をインストールすると、新しいバージョンが古いバージョンを置き換えます。アプリがファイルをインストールできない場合（たとえば ZIP ファイルが壊れている場合）は、何も起こりません。ZIP と JS では、アプリはエラーメッセージを表示せず、拡張機能は一覧に表示されません。ただし、理由はデバッグターミナルに表示されます。デバッグターミナルをオンにするには、*設定 › プロジェクト › 設定* の *詳細設定* タブで *デバッグターミナルを有効にする* を選び、ステータスバーの *デバッグターミナルを表示* ボタンで開きます。そこには、たとえば次のように表示されます：*[Extensies] ZIP-installatie mislukt: Error: Geen manifest.json gevonden in ZIP*（アプリでは、この技術的なテキストはオランダ語で表示されます。）

### 許可の確認内容を読む

この質問には、判断が必要な内容が表示されます。

- *作成者* と *リポジトリ* には、拡張機能の作成者と、ソースコードの場所が表示されます。
- *入手元* には、ファイルの入手元が表示されます：*オンライン拡張機能カタログから*、*このコンピューター上の ZIP ファイルから*、または *このコンピューター上の JavaScript ファイルから*。その下には、ファイルが検証されたかどうかが表示されます。カタログの場合は、*カタログのチェックサムでダウンロードを検証しました。* と表示されます。カタログにチェックサムがない場合は、赤字で *カタログにチェックサムがありません。このダウンロードは検証されていません。* と表示されます。ご自身で選んだファイルの場合は、*このファイルはご自身で選択したもので、照合できる外部の情報源はありません。* と表示されます。
- *同意する内容* には、次の文が表示されます：*拡張機能は Open Planner Studio 自身と同じ権限で動作するプログラムコードで、それを制限する仕組みはありません。作成者を信頼できる拡張機能だけをインストールしてください。* その下には、お使いのプラットフォームでそれが何を意味するかが表示されます。デスクトップアプリでは、*デスクトップアプリでは、ユーザーフォルダー内のあらゆる場所のファイルの読み書きに加え、プロジェクト・設定・クリップボードへのアクセスが含まれます。* と表示されます。ブラウザーでは、*ブラウザーでは、保存済みのプロジェクトと設定、アクセスを許可したファイル、およびネットワークへのアクセスを意味します。* と表示されます。
- *この拡張機能が使用すると申告している項目* には、作成者が申告した権限が小さなラベルで表示されます。これは作成者の申告であり、制限ではありません：*これは作成者による申告であり、制限ではありません。コードはそれ以上のことも実行できます。* ラベルがない場合は、*申告なし。* と表示されます。これは、拡張機能が何もできないという意味ではありません。ラベルがなくても、拡張機能はスケジュールのデータを読み取って変更したり、メッセージを表示したりできます。

ラベルの意味は次のとおりです：

- *リボン*：拡張機能はリボンにボタンを配置します。
- *イベント*：拡張機能は、アプリ内のイベントを受け取ります。
- *バックステージ*：拡張機能は、*ファイル › インポート* にインポート形式を追加します。
- *PDF フォント*：拡張機能は、PDF エクスポート用のフォントを提供します。
- *インポートソース*：拡張機能は、インポートする各ファイルの元のバイト列をすべて読み取ることがあります。たとえば、加工されていない Primavera ファイルです。これには、プロジェクトに反映されないフィールドも含まれます。このウィンドウでも、その点が説明されます。
- *ヘルプ*：拡張機能は、ヘルプ記事を追加したり、同梱のプロジェクトを新しいドキュメントとして開いたり、アプリの一部を示すガイドを表示したりすることがあります。このウィンドウでも、その点が説明されます。
- *ファイルシステム* と *ネットワーク*：これらは、作成者が意図する内容を示すだけです。アプリには、これらの機能はありません。

### 拡張機能を無効化、再有効化、または削除する

1. *ファイル › 拡張機能* を選択し、*インストール済み* タブを選択します。各拡張機能には、名前、バージョン、カテゴリ、説明、作成者が表示されたカードがあります。
2. カードのスイッチで、拡張機能を無効にする（*無効化*）か、再び有効にする（*有効化*）かを選びます。無効にすると、拡張機能が追加したボタンやインポート形式は表示されなくなります。ただし、拡張機能はインストールされたままです。アプリを再起動しても、無効のままです。有効な拡張機能は、アプリの起動時に自動的に開始します。
3. *削除* をクリックします。ボタンが *確認* に変わり、説明として *もう一度クリックすると完全に削除されます* と表示されます。もう一度クリックすると、拡張機能を削除します。アプリは、拡張機能が保存した設定も削除します。

## 注意点と、その場合にアプリが行うこと

**カタログが読み込まれません。** *カタログを読み込めませんでした：* のあとに技術的な理由が表示され、*再試行* ボタンが表示されます。インターネットに接続されていないことが原因の場合があります。

**カタログのカードの下に *インストールに失敗しました。* と表示されます。** ダウンロードまたはインストールに失敗しました。たとえば、チェックサムが一致しなかったことが原因です。その場合、何もインストールされていません。これは、質問を拒否した場合とは異なります。拒否した場合は、エラーメッセージは表示されません。

**一覧の上に *スキップしたカタログ項目: 1* と表示されます。** カタログに、アプリで使えない項目が含まれていました。ほかの拡張機能は、通常どおりインストールできます。

**拡張機能が起動しません。** カードには、エラーメッセージが表示されます。たとえば、拡張機能に Open Planner Studio の新しいバージョンが必要だという内容です。その場合、現在のバージョンも表示されます。または、拡張機能自身が出したエラーです。どちらの場合も、拡張機能は有効になりません。アプリを更新するか、拡張機能を削除してください。

**カードに *隔離* と表示される場合。** アプリは、保存された拡張機能を使えませんでした。名前の下に *理由：* と、その原因が表示されます。*保存先から削除* を選ぶと、カードを整理できます。

**拡張機能を自分で作成する場合。** 拡張機能の作成者向けガイド（マニフェスト、API、権限）は、GitHub のリポジトリ `OpenAEC-Foundation/open-planner-studio` の `docs/extensions.md` というファイルにあります。

**拡張機能はプロジェクトに属しません。** 拡張機能はアプリに保存されます。デスクトップアプリでは、このコンピューターに保存されます。ブラウザーでは、そのブラウザーのストレージに保存されます。拡張機能は、すべてのプロジェクトに適用されます。プロジェクトファイルには含まれません。ブラウザーでサイトデータを消去すると、拡張機能も消えます。
