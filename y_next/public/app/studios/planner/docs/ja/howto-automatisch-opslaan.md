# 自動保存を有効にする

目標: アプリが作業中にプロジェクトファイルを更新するため、Ctrl+S を何度も押す必要がありません。

## いつ使うか

一つのスケジュールで長時間作業する場合や、保存を忘れがちな場合に、ディスク上または共有フォルダー上のファイルを最新の状態に保ちたいときに使います。自動保存は、クラッシュ復元の代わりにはなりません。クラッシュ復元は常に有効で、自動保存とは別に動作します。違いは[ファイルと形式](docs://uitleg-bestanden)で確認できます。

## 手順

1. プロジェクトにまだファイルがない場合は、まず *ホーム › ファイル › 名前を付けて保存* で一度保存します。ファイルがないあいだ、*自動保存* スイッチはグレーで、ツールヒントには *自動保存を使うには、先にこのプロジェクトを保存してください。* と表示されます。
2. 画面左上の上部バーで、*自動保存* スイッチをクリックします。オンのときは、ツールヒントに *自動保存はオンです。変更はこのファイルに書き込まれます。* と表示されます。
3. 作業を続けます。プロジェクトに変更があると、アプリはウィンドウを表示せずに、ファイルへ書き込みます。書き込みは最大で十秒に一度です。その後、*未保存* マーカーは自動的に消えます。
4. 停止する場合は、スイッチをもう一度クリックします。その場合、ツールヒントには *自動保存はオフです。クラッシュ復元は常に有効です。* と表示されます。

Chrome と Edge では、最初は開いたファイルを読み取るだけです。ブラウザーが書き込みを許可し、*保存*（Ctrl+S）で一度保存するまで、スイッチは何もしません。その後、スイッチをオンにできます。Firefox では、スイッチはグレーのままです。アプリはそこではファイルに書き込めません。

## 注意点と、そのときのアプリの動作

**スイッチは一つのプロジェクトに属します。** 各タブには、それぞれ独自の状態があります。プロジェクトを開くと、スイッチは常にオフです。アプリは次回のためにその状態を記憶しません。

**自動保存は、プロジェクトがすでに持つファイルにのみ書き込みます。** *名前を付けて保存* を選ぶと、それ以降は新しいファイルに書き込みます。アプリは変更がある場合にのみ書き込みます。

**書き込みに失敗することがあります。** たとえばファイルが消えた場合やロックされている場合は、理由とともに *自動保存に失敗しました* というメッセージが表示されます。ブラウザーに書き込みの許可がない（またはもうない）場合、アプリはその回を黙ってスキップします。許可を求めることはありません。

**ファイルには、残したくない変更も書き込まれます。** 自動保存は、その時点のプロジェクトの状態を書き込みます。Ctrl+Z で何かを元に戻すと、ファイルにも十秒以内に元に戻した状態が書き込まれます。古いバージョンを残したい場合は、先に *名前を付けて保存* でコピーを作成してください。

**クラッシュ時には、それでも直前の数秒分が失われることがあります。** アプリは最大で十秒に一度書き込むため、その間に行った作業はまだファイルに入っていません。クラッシュ復元にも同じ制限があります。

**ブラウザーでの復元後、スイッチは再びグレーになります。** クラッシュ後にブラウザーで取り戻したプロジェクトは、もうそのファイルと結び付いていません。一度保存すると、スイッチは再び動作します。詳しくは、[クラッシュ後の復元](docs://howto-herstellen-na-een-crash)を参照してください。

**別の形式のプロジェクトにはファイルがありません。** CSV、XML、`.mpp`、または `.xer` のファイルは、保存したときにはじめて IFC ファイルになります。その後、自動保存をオンにできます。
