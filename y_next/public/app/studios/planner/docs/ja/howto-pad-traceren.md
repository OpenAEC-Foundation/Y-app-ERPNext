# パスのトレース

目的: タスクの前後にあるタスクのつながりを見えるようにします。これにより、どの関係がタスクの日付を決めているか、遅れたときに何が一緒に動くかがわかります。

## いつ使うか

屋根工事は三週間後にしか始まりません。どのタスクがそれを決めているかを知りたいとします。または、れんが職人が一週間遅れるとします。その後に続くどのタスクが一緒に動くかを見たいとします。関係が数十あるスケジュールでは、線だけを見てもわかりません。**パストレース**を使うと、アプリは選択したタスクの**先行タスク**（前に来るタスク。直接でも、他のタスクを経由する場合でも）と、**後続タスク**（後に来るタスク）に色を付けます。それ以外のタスクは薄く表示されます。

## 手順

1. パスを表示したいタスクを、タスクテーブルまたは Gantt のバーで選択します。複数のタスクを選択すると、アプリは最初に選択したタスクからトレースします。
2. タスクより前のすべてを表示するには、*計画 › パストレース › 先行タスク* を選択します。タスクより後のすべてを表示するには、*計画 › パストレース › 後続タスク* を選択します。両方のボタンを同時にオンにできます。同じ二つのボタンは *テーブル* タブの *パストレース* グループにもあります。
3. 両方向を一度に表示したい場合は、Gantt またはタスクテーブルでタスクを右クリックし、*パスをトレース* を選択します。
4. 結果を Gantt とタスクテーブルで確認します。読み方は下で説明します。
5. オンになっているボタンをもう一度クリックするか、タスクを右クリックして *パスのトレースを停止* を選択するか、Esc キーを押すと停止します。Esc キーで選択も解除されます。

トレース中に別のタスクを選択すると、パスは新しい選択に従います。

## 結果の読み方

- 先行タスクは金色、後続タスクは紫色で表示されます。Gantt ではバーの色が変わります。タスクテーブルでは、行の左側に帯が表示されます。先行タスクは実線、後続タスクは破線の帯です。選択したタスクには枠線が付きます。
- 色が濃い部分（タスクテーブルでは太い帯と太字の文字）は、**駆動関係**の連鎖を示します。駆動関係とは、実際に日付を決める関係のことです。その意味は [関係とラグ](docs://uitleg-relaties) で説明しています。
- パスの外にあるすべてのタスクは薄く表示されます。パスに属さない関係線は、さらに薄く、点線で表示されます。

## 注意点とアプリの動作

**タスクが選択されていません。** タスクが選択されていないと、トレースするものがありません。ボタンはオンでも、画面は変わりません。先にタスクを選択してください。

**駆動関係の連鎖は強調されません。** 強調は直前の計算に基づきます。スケジュールがまだ計算されていない場合、または計算でエラーが出た場合は、アプリはすべての先行タスクと後続タスクを同じ強さで色付けします。**計算**（F5）を押してください。例えば *ホーム › スケジュール › 計算* から実行し、パスをもう一度確認します。変更後は、ステータスバーに *古くなっています — 再計算してください（F5）* と表示されている間、強調は前回の計算のままです。

**フェーズに対する関係。** トレースは、設定した関係に従います。フェーズ（サマリータスク）からの関係、またはフェーズへの関係は、フェーズ自体をつなぎます。計算では、その関係はフェーズ内のすべてのタスクに適用されます。しかし、パストレースはフェーズ内のタスクまでは続きません。フェーズ自体に別のタスクへの関係がある場合、そのフェーズの中のタスクをトレースすると、その関係は表示されません。その場合は、フェーズ自体を選択してください。

**選択した方向だけ。** *先行タスク* だけがオンの場合、タスクの後に来るものは表示されません。逆も同様です。
