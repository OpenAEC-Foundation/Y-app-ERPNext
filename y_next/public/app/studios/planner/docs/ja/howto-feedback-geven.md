# フィードバックの送り方

目的: エラーを報告したり、アイデアを伝えたりします。必要ならスクリーンショットも付けます。こうすると、内容が GitHub の issue として登録されます。

## こんなときに使います

スケジュールが計算した結果が理解できないとき、ボタンが正しく動かないとき、またはアプリに必要な機能がないと感じるときです。よい報告は、開発者が問題を見つけるのに役立ちます。そのため、アプリ自体が報告にバージョン、オペレーティングシステム、言語を自動的に追加します。ご自身で書く内容によって、開発者が対応できるかどうかが決まります。何をしたか、何を期待したか、何が起きたかを書いてください。

## 手順

1. ウィンドウ上部の *フィードバックを送る* ボタンを選択します。このボタンは常にタイトルバーにあります。ボタンの文字は 10 分ごとに変わります: *フィードバックを送る*、*バグを報告*、*新機能を提案* のいずれかです。ボタン自体は常に同じです。*フィードバックを送信* ウィンドウが開きます。
2. 期待どおりに動かない場合は *バグ* を、アイデアの場合は *機能リクエスト* を選択します。*バグ* が既定で選択されています。
3. *タイトル* に入力します。タイトルがないと、*GitHub に送信* ボタンはグレーになります。*説明* にも入力してください。例: 変更したタスク、期待したこと、実際に見えたこと。
4. 何かを見せたい場合は、*スクリーンショットを添付* をオンにします。そのとき、アプリはこのウィンドウを除いた画面の画像を撮ります。少しすると、小さなプレビューが表示されます。*注釈を付ける* を選択すると、エディターが開きます。そこで、画像に矢印、四角、フリーハンドの線、テキストを追加できます。色も選べます。直前の操作は *元に戻す* で取り消せます。最初からやり直す場合は *すべてクリア* を選択します。納得したら *完了* を選択します。
5. *GitHub に送信* を選択します。
6. スクリーンショットを添付しなかった場合は、新しい issue を作成する GitHub ページがすぐにブラウザーで開きます。手順 8 に進みます。
7. スクリーンショットを添付した場合は、まず *もう少しで完了です — スクリーンショットはクリップボードにコピーされています。* と、四つの手順が表示されます。*OK、GitHub へ移動* を選択します。issue ページの大きなテキスト領域内をクリックし、Ctrl+V（Mac では Cmd+V）を押します。画像がアップロードされ、テキストに表示されます。
8. issue ページの下部にある *新しい issue を送信* を選択します。その時点で初めて報告が送信されます。まだの場合は、GitHub にサインインします。

issue ページには、タイトルと説明がすでに入力されています。アプリはラベルとして *bug* または *enhancement* を提案します。また、説明の下に一行を追加します。その行には、種類、Open Planner Studio のバージョン、オペレーティングシステム、アプリの言語が書かれています。

## 注意点とアプリの動作

**アプリは自動では何も送信しません。** *GitHub に送信* を選択すると、入力済みの issue ページが開くだけです。*新しい issue を送信* を選択せずにページを閉じると、何も報告されていません。そのためには GitHub のアカウントが必要です。

**報告は GitHub に公開されます。** 共有したくない内容は書かないでください。スクリーンショットも同じです。画像には、そのとき画面に見えているものがすべて写ります。たとえば、プロジェクトのタスク名やリソースです。アプリは *スクリーンショットを添付* をオンにした瞬間にスクリーンショットを撮ります。そのため、オンにする前に画面が正しいか確認し、見せたくないものは画面から外してください。

**貼り付けができません。** スクリーンショットは、お使いのコンピューター上のファイルとしても保存されます。デスクトップアプリでは、ウィンドウにパスが表示されます: *貼り付けできませんか？ スクリーンショットは次の場所にも保存しました:* そのパス *— そのファイルをテキスト領域にドラッグしてください。* ブラウザーでは、アプリが画像を `feedback-` と番号と `.png` という名前でダウンロードします。ダウンロードフォルダーで見つけて、テキスト領域にドラッグします。

**スクリーンショットの撮影に失敗します。** 次のメッセージが表示されます: *スクリーンショットの撮影に失敗しました。スクリーンショットなしでもフィードバックを送信できます。* チェックボックスがオフになり、画像なしで報告を送信できます。

**長い文章を入力したあとに、誤ってウィンドウの横をクリックすることがあります。** それではウィンドウは閉じないため、入力したテキストは残ります。Esc または *キャンセル* を押すとウィンドウは閉じます。その場合、入力したテキストは消えます。
