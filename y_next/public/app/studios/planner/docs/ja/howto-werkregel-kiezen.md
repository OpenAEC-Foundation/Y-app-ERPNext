# 作業ルールの選び方

目標：タスクごとに、期間、単位数、または作業を変更したときに、アプリが何を調整するかを設定します。調整するのは、期間、単位数、作業のいずれかです。

## 必要になる場合

タスクにリソースを割り当てました。アプリに、自分の計算方法どおりに計算させたいとします。例：クレーンを一日借りていて、その日は固定です。もう一つの例：れんが積みに 160 時間かかることがわかっています。二人の代わりに三人で、どのくらいの期間がかかるかを見たいとします。この二つの状況には、異なる作業ルールが必要です。

ルールは、別の量を変更したときに、期間、単位数、作業のどれが一緒に動くかを決めます。背景と作業例は [作業ルール：期間、単位数、作業](docs://uitleg-werkregels) にあります。

## 手順

### 作業ルールを表示する

作業ルールは初期状態では表示されません。一度だけオンにします：

1. *設定 › プロジェクト › 設定* を選びます。タブ *計画* を選びます。
2. 見出し *計算* の下で、*作業ルールと作業を表示* にチェックを入れます。
3. *閉じる* で、ウィンドウを閉じます。

これはアプリの設定です。プロジェクトファイルの設定ではありません。ファイルにすでに作業ルールや保存された作業がある場合（たとえば MS Project または Primavera P6 のファイル）、この設定がなくても、アプリはそのファイルの作業ルールを表示します。ファイルで自分が作業ルールを選んだ場合も同じです。その場合、設定をオフにしても、そのファイルでは表示がオンのままになります。表示は、ファイルを開いている間はオンのままです。再度開いたあとも、ファイルに作業ルールまたは保存された作業がある限りオンのままです。

### ルールを選ぶ

1. タスクを選択します。*プロパティ* パネルは右側にあります。見えない場合は、*表示 › パネル › プロパティ* でオンにします。
2. *作業ルール* で、五つの選択肢のいずれかを選びます：*プロジェクトの既定（固定期間・固定単位）*、*固定期間・固定単位*、*固定期間・固定作業*、*固定作業*、または *固定単位*。*プロジェクトの既定* を選ぶと、タスクはプロジェクトの既定に従います。
3. ドロップダウンの下に、アプリがどれを保護するかを表示します。例：*保護：作業（期間は単位数に従います）*。

*プロジェクトの既定* は最初の選択肢で、タスクの既定値です。かっこ内のルールは、プロジェクトに現在設定されている既定です。アプリには、この既定を変更するボタンはありません。既定は、インポート（たとえば MS Project または Primavera P6 からのインポート）か、MCP 接続で決まります。一つのタスクだけ別のルールにしたい場合は、ここで選びます。

テーブルでも作業ルールを選べます。タスクテーブルのヘッダーの右にある **+** をクリックします（*列を追加*）。*計画* の下で、*作業ルール* 列を選びます。

割り当てのないタスクでは、まとめるものがないため、ルールは何もしません。先にリソースを割り当ててください（[曲線を使ったリソースの割り当て](docs://howto-resource-toewijzen) を参照）。

### 作業を確認して変更する

割り当てのあるタスクでは、*プロパティ* パネルの *割り当て* ブロックに、*単位/日* の隣に *作業（残）* 列が表示されます。これは、そのリソースの残作業を時間で示します。列の上の小さな南京錠は、ルールが何を固定しているかを示します。*固定期間・固定単位* と *固定単位* では *単位/日* に、*固定期間・固定作業* と *固定作業* では *作業（残）* に南京錠が付きます。

作業を自分で変更する場合は、欄に時間を入力して Enter を押します。アプリは 0 以下の値を受け付けません。その場合、欄は前の値に戻ります。

### 結果を確認する

ルールを選んでも、まだ数値は変わりません。作業を保護するルールでは、アプリは現在の作業を固定するだけなので、*作業（残）* に保存された値があります。次の変更で初めて、ルールがどの値を一緒に動かすかを決めます。たとえば *単位/日* を変更して、期間と作業にどう影響するかを確認します。

この変更でタスクの期間が変わると、ステータスバーに *古くなっています — 再計算してください（F5）* と表示されます。**計算**（F5）を押します。たとえば *ホーム › スケジュール › 計算* から実行できます。新しい日付が表示されます。*自動計算* がオンの場合（同じ *計画* タブ、見出し *計算*）、アプリが自動で実行します。

## どのルールが合うか

- **固定期間・固定単位** は、期間が取り決めで、単位数を自分が入力する場合に合います。作業は、この二つから決まります。これが既定です。一日だけ借りたクレーンはここに当てはまります。日は固定で、その日に何台のクレーンを置くかは自分で決めます。
- **固定期間・固定作業** は、タスクを固定期間内に終える必要があり、作業量がわかっている場合に合います。期間が変わると、アプリが単位数を調整します。
- **固定作業** は、作業時間がわかっていて、人数によって期間がどう変わるかを見たい場合に合います。二人の代わりに三人で行う 160 時間のれんが積みは、ここに当てはまります。練習用プロジェクトの plastering には、このルールが設定されています。
- **固定単位** は、単位数が固定で（たとえばクレーン一台）、作業量によって期間が決まる場合に合います。

## 落とし穴とアプリの動作

***作業ルール* 欄が表示されません。** この場合、*作業ルールと作業を表示* の設定がオフで、ファイルにまだ作業ルールがないか、マイルストーン、フェーズ、ハンモック、または期間の種類が *経過時間* のタスクを選択しています。そこには作業ルールはありません。通常のタスクを選択してください。

**自分が変えていないのに期間が変わります。** *固定作業* と *固定単位* では、期間は単位数と作業から決まります。どちらか、またはリソースの人数を変えると、アプリは期間を調整します。その際、期間は稼働日単位で切り上げられます。時間単位のタスクでは、アプリは分単位で切り上げます。

**作業が単位数 × 期間と正確に一致しません。** 丸めが原因で起こることがあります。*作業（残）* の隣に警告マークが表示されます：*単位 × 期間と一致しません*。ヒストグラムは保存された作業に従います。

**資材は数えられません。** 資材リソースの場合、*作業（残）* にはダッシュが表示されます。資材が期間を決めることはありません。

**進捗のあるタスク。** ルールは残りの部分に対して働きます。そのため *作業（残）* には、まだ行う必要がある分だけが表示されます。

**元に戻す。** ルールを選ぶこと、およびルールが計算する変更はすべて、*元に戻す*（Ctrl+Z）で一回で戻せます。そのあとルールは解除されますが、*作業ルール* 欄は表示されたままです。
